- id: pc01
  title: 精炼贝叶斯均衡要求1（每个信息集必须有推断）
  type: rule
  source_chapter: 4.1 精炼贝叶斯均衡概述
  source_quote: |
    "要求1：在每一信息集中，应该行动的参与者必须对博弈进行到该信息集中的哪个节有一个推断。
    对于非单节信息集，推断是在信息集中不同节点的一个概率分布；对于单节的信息集，参与者的推断
    就是到达此单一决策节的概率为1。"
  summary: |
    检验规则之一：均衡对象中必须包含推断（belief）。非单节信息集=信息集内各节点上的概率分布
    （各概率非负、和为1）；单节信息集=到达概率为1。
    作用：把"信念"提高到与战略同等的地位（克雷普斯-威尔逊的关键创新），为要求3/4及第4.4节
    再精炼提供载体。适用一切动态博弈；要求1本身不对推断的合理性设限（理性约束由要求3/4承担）。
  tags: [game-theory, perfect-bayesian-equilibrium, beliefs]
  task_ids: [task-07, task-04]

- id: pc02
  title: 精炼贝叶斯均衡要求2（序贯理性）
  type: rule
  source_chapter: 4.1 精炼贝叶斯均衡概述
  source_quote: |
    "要求2：给定参与者的推断，参与者的战略必须满足序贯理性（sequentially rational）的要求。
    即在每一信息集中应该行动的参与者……对于给定的该参与者在此信息集中的推断，以及其他参与者
    随后的战略……必须是最优反应。"
  summary: |
    检验规则之二：在每个信息集（不只均衡路径上）给定推断与各方后续战略，行动及其后的完整计划
    必须是最优反应。与子博弈精炼的区别：不要求信息集是某个子博弈的起点，且以推断为条件。
    应用示例（图4.1.1）：给定任意推断p，选L'的期望收益2−p恒大于R'的1−p，故要求2排除
    依赖不可信威胁的均衡(R,R')。等价于排除始于任何信息集的严格劣战略。

- id: pc03
  title: 精炼贝叶斯均衡要求3（路径上推断=贝叶斯法则×均衡战略）
  type: rule
  source_chapter: 4.1 精炼贝叶斯均衡概述
  source_quote: |
    "要求3：在处于均衡路径之上的信息集中，推断由贝叶斯法则及参与者的均衡战略给出。"
    （均衡路径定义：按均衡战略进行时以正概率达到的信息集。）
  summary: |
    检验规则之三：先判定信息集是否处于均衡路径（按均衡战略以正概率到达），路径上的推断被强制
    等于贝叶斯法则与均衡战略共同决定的后验。
    推论：混同均衡中接收者推断必须等于先验；若偏离以混合概率q1、q2进行，则推断p=q1/(q1+q2)。
    信号博弈中的对应物即"信号要求3"（pc09）。

- id: pc04
  title: 精炼贝叶斯均衡要求4（路径外推断尽量由均衡战略决定）
  type: rule
  source_chapter: 4.1 精炼贝叶斯均衡概述
  source_quote: |
    "要求4：对处于均衡路径之外的信息集，推断由贝叶斯法则以及可能情况下的参与者的均衡战略决定。"
  summary: |
    检验规则之四：路径外推断须由贝叶斯法则与均衡战略决定，限定语"可能情况下"是因均衡战略可能
    对路径外节点不给任何概率。

- id: pc05
  title: PBE定义与均衡概念退化关系
  type: principle
  source_chapter: 4.1 精炼贝叶斯均衡概述
  source_quote: |
    "定义 满足要求1到4的战略和推断构成博弈的精炼贝叶斯均衡。""精炼贝叶斯均衡在非完全信息静态
    博弈中即等同于贝叶斯纳什均衡，在完全信息动态博弈……中等同于子博弈精炼纳什均衡，在完全信息
    静态博弈中等同于纳什均衡。"
  summary: |
    均衡=战略+推断的联合体。选均衡概念的判定规则：按博弈类型（信息×时序）选概念——
    完全信息静态→纳什均衡；完全信息动态→子博弈精炼；不完全信息静态→贝叶斯纳什；
    不完全信息动态→精炼贝叶斯（要求1-4）。
    边界：较强概念只在与复杂博弈结合时才与较弱概念不同，对简单博弈无区别——即用强概念不会
    错杀简单博弈的均衡；后续博弈（continuation game）可始于任何完全信息集，比子博弈更广。

- id: pc06
  title: PBE一般不能沿博弈树逆向归纳求解
  type: principle
  source_chapter: 4.1 精炼贝叶斯均衡概述
  source_quote: |
    "要求2决定了参与者在一个给定信息集的行动部分依赖于参与者在该信息集的推断……这一循环推论
    意味着沿博弈树从后向前逆向推导（一般情况下）将不足以计算出精炼贝叶斯均衡。"
  summary: |
    求解方法论边界：与子博弈精炼可用逆向归纳不同，PBE中行动依赖推断、推断依赖上游行动、
    上游行动又依赖后续战略（含该信息集的行动），循环自洽。
    因此求解程序必须是"猜测战略→由要求3/4定推断→检验各方最优反应"的联合验证，而非一次性的
    从末端往前推导。
  tags: [game-theory, solution-method, perfect-bayesian-equilibrium]

- id: pc07
  title: 信号博弈定义四步时序
  type: checklist
  source_chapter: 4.2.A 信号博弈的精炼贝叶斯均衡
  source_quote: |
    "1.自然根据特定的概率分布p（ti），从可行的类型集T={t1,…,tn}中赋予发送者某种类型ti……
    2.发送者观测到ti，然后从可行的信号集M……中选择一个发送信号mj；3.接收者观测到mj（但不能
    观测到ti）……选择一个行动ak；4.双方收益分别由us（ti,mj,ak）和ur（ti,mj,ak）给出。"
  summary: |
    信号博弈标准结构清单：知情方（发送者S）先行动发信号，不知情方（接收者R）观测信号后行动。
    要点：p(ti)>0且Σp(ti)=1；发送者纯战略=类型→信号函数m(ti)，接收者纯战略=信号→行动函数a(mj)；
    T/M/A可为连续区间；信号集可依赖类型、行动集可依赖信号。
    应用套壳：斯彭斯（类型=生产能力，信号=教育，行动=工资）；Myers-Majluf（类型=现存资产
    盈利能力，信号=承诺的股权份额，行动=投资与否）；Vickers货币政策（类型=通胀态度，信号=
    一期通胀，行动=二期通胀预期）。

- id: pc08
  title: 信号要求1、2R、2S（推断存在与双方最优化）
  type: rule
  source_chapter: 4.2.A 信号博弈的精炼贝叶斯均衡
  source_quote: |
    "信号要求1 在观测到M中的任何信号mj之后，接收者必须对哪些类型可能会发送mj持有一个推断……
    u（ti|mj）≥0且Σu(t_i|m_j)=1。信号要求2R……a*(mj)必须使接收者的期望效用最大化。
    信号要求2S……发送者选择的信号m*(ti)必须使发送者的效用最大化。"
  summary: |
    信号博弈版要求1/2。信号要求1：每个信号mj后接收者有推断u(ti|mj)，非负、对T求和为1。
    信号要求2R：a*(mj)=argmax_{ak∈A} Σ_{ti∈T} u(ti|mj)·UR(ti,mj,ak)。

    边界：发送者行动于单节信息集（完全知道全过程），故推断对发送者退化，无需附加条件；
    两企业竞争出价时（4.2.B）式(4.2.1)可替代2R。

- id: pc09
  title: 信号要求3（路径上后验=贝叶斯公式）
  type: rule
  source_chapter: 4.2.A 信号博弈的精炼贝叶斯均衡
  source_quote: |
    "信号要求3 对每一M中的mj，如果在T中存在ti使得m*(ti)=mj，则接收者在对应于mj的信息集中
    所持有的推断必须决定于贝叶斯法则和发送者的战略：u(ti|m_j)=p(ti)/Σ_{ti∈Tj}p(ti)。"
  summary: |
    令Tj={ti: m*(ti)=mj}（发送信号mj的类型集合）。若Tj非空（信号在路径上），后验=
    该类型先验除以发送该信号类型的先验之和。
    推论：混同均衡中所有信息集都在路径上，后验=先验；分离均衡中后验退化为0/1。
    若Tj为空（信号在路径外），要求3不适用；纯战略PBE定义=满足信号要求(1)(2R)(2S)(3)的
    m*、a*、u三元组。

- id: pc11
  title: 斯彭斯单交叉条件（低能力信号边际成本更高）
  type: principle
  source_chapter: 4.2.B 就业市场信号
  source_quote: |
    "斯彭斯的模型中最关键的假定是较低能力的工人发出同样的信号要比较高能力工人花费的成本高，
    更为精确地，较低能力工人受教育的边际成本要高于较高能力工人：对所有e ce（L,e）＞ce（H,e）。"
  summary: |
    斯彭斯四步时序：自然定能力η∈{H,L}（P(H)=q）→工人选教育e≥0→两企业观测e（非η）竞争出价
    →工人接受较高工资。收益：工人w−c(η,e)；企业y(η,e)−w；未雇到为0。
    分离得以可能的唯一关键假定（单交叉/排序条件）：∀e，ce(L,e)>ce(H,e)；图形表述=低能力
    无差异曲线比高能力陡峭。教育不必提高生产率，信号照样有效（Spence 1973/1974）。
    e可解释为在校表现（绕开中途被雇的动态问题）；Noldeke-Van Damme(1990)证明更丰富的
    动态博弈经再精炼后唯一均衡与简单博弈一致，故e也可不严格地视为在校时间。

- id: pc12
  title: 竞争市场工资=期望产出（4.2.1）
  type: calculation
  source_chapter: 4.2.B 就业市场信号
  source_quote: |
    "为最大化其期望收益……市场的工资要约将等于教育水平为e的工人的期望产出：
    w(e)=μ(H|e)·y(H,e)+[1−μ(H|e)]·y(L,e)。（4.2.1）"
  summary: |

- id: pc16
  title: 杂合均衡公式组（4.2.8-4.2.10）
  type: calculation
  source_chapter: 4.2.B 就业市场信号（图4.2.9）
  source_quote: |
    "μ(H|e_h)=q/[q+(1−q)π].（4.2.8）……为使低能力工人愿意随机选择分离结果e*(L)或混同结果eh，

  summary: |

- id: pc30
  title: 要求5（路径外推断：劣信号赋零概率）
  type: rule
  source_chapter: 4.4 精炼贝叶斯均衡的再精炼
  source_quote: |
    "要求5：在可能的情况下，在每一参与者均衡路径之外的推断中，如果一个节点只有在另一参与者
    选择始于某些信息集的严格劣战略时，才能够到达，则应认定到达这一节点的概率为0。"
  summary: |

- id: pc31
  title: 信号要求6（Cho-Kreps直观标准：均衡劣信号赋零概率）
  type: rule
  source_chapter: 4.4 精炼贝叶斯均衡的再精炼
  source_quote: |
    "信号要求6（'直观标准'，赵和克雷普斯，1987）：如果mj之后的信息集处于均衡路径之外，且mj为
    类型ti的均衡劣信号，则（在可能的情况下）接收者的推断μ(ti|mj)中分配给类型ti的概率应该
    等于0。"
  summary: |
    定义"均衡劣信号"：ti发mj的最高可能收益 max_a US(ti,mj,a) < U*(ti)（其在该均衡下的
    均衡收益）。直观标准：路径外信号若对ti均衡劣，则后验中ti概率为0。
    与要求5的关系：劣信号必为均衡劣信号，故要求6严格强于要求5并使其多余。
    逻辑名称：前向归纳——解释背离时假定背离者理性且此举对其有利（"啤酒或热狗"博弈中
    粗暴型的表白："选啤酒不能提高软弱型收益，但若你信我是粗暴型，我能获益"）。
    存在性：Cho-Kreps借Kohlberg-Mertens证明所有信号博弈都存在满足要求6的PBE。
    检验程序：对每个候选均衡，逐一考察路径外信号mj——找出"发mj只可能对自己有利"的类型，
    令其余类型后验为0，再检验接收者反应是否反过来破坏原均衡。
