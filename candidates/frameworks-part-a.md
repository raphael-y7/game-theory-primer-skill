  type: procedure

- id: fa09
  title: 混合战略纳什均衡求解（最优反应对应法）
  type: procedure
  source_chapter: 1.3.A 混合战略 / 1.3.B 纳什均衡的存在性
  source_quote: |
    "在两个参与者标准式博弈G={S1，S2；u1，u2}中，混合战略(P1*，P2*)是纳什均衡的充要条件为：每一参与者的混合战略是另一参与者混合战略的最优反应。"

    当博弈无纯战略NE（猜硬币）或需完备均衡清单时的求解程序。

  source_quote: |

- id: fa12
  title: 混合战略的净化（私人信息再解释程序）
  type: procedure
  source_chapter: 3.2.A 再谈混合战略
  source_quote: |
    "完全信息博弈的混合战略纳什均衡（几乎总是）可以解释为与之密切相关、存在一小点非完全信息的博弈中的纯战略贝叶斯纳什均衡。"
  summary: |
    把完全信息博弈的混合战略NE重读为纯战略BNE的构造程序（Harsanyi净化）。
    步骤：1) 给原博弈关键收益加微小私人扰动（如+t，t均匀分布于[0,x]，x很小，且扰动独立）；2) 猜阈值战略：类型超过临界值选一个纯战略、否则选另一个（如克里斯tc>c选歌剧）；3) 对给定阈值计算每方各行动的期望收益，由无差异条件解出临界值c、p的联立方程；4) 解出阈值并把阈值换算成行动概率(x-c)/x；5) 令x→0做极限检验：行为概率应收敛于原混合均衡概率（性别战收敛到2/3）。
    判定标准：净化成功的判据=非完全信息消失时，纯战略BNE的行为趋于原博弈混合战略NE的行为。
    边界：结果"几乎总是"成立（忽略极罕见例外）；均匀分布只是为了可解，思路对一般小扰动分布适用；混合战略的实质是"对手不确定我选什么"，而非必然掷骰子。

- id: fa13
  title: 一级密封拍卖线性均衡求解（猜线性法）
  type: procedure
  source_chapter: 3.2.B 拍卖一种
  source_quote: |
    "我们假设该问题的一组线性均衡解b1（v1）=a1+c1v1……但应注意我们不是限制了参与者的战略空间……这样的线性均衡解不仅存在，而且是惟一的。"
  summary: |
    一级密封拍卖（估价独立均匀[0,1]、风险中性、同时密封出价、价高者付己价）的BNE求解模板。
    步骤：1) 标准化：行动=出价b，类型=估价v，收益=(v-b)·Prob{胜}；2) 猜测线性战略b(v)=a+cv——注意不是限制战略空间，只是寻找线性均衡；3) 对给定对手战略写最优反应问题 max(v-b)·(b-aj)/cj（均匀分布下胜率=出价的线性函数）；4) 一阶条件给出最优反应的斜率1/2、截距aj/2；5) 联立解出ai=aj=0、ci=cj=1/2，即b(v)=v/2；6) 排除非线性情形（aj≥1与最优性矛盾；0<aj<1必使最优反应前平后斜，非线性）。
    判定标准：均衡出价=估价之半；基本权衡=出价越高中标概率越大、但中标后收益越低。
    边界：线性均衡依赖估价均匀分布——换任何其他分布线性均衡不存在；该方法无法回答是否存在其他均衡；n个投标人的对称均衡为b(v)=(n-1)v/n（习题3.6）。

- id: fa14
  title: 对称贝叶斯纳什均衡的微分方程法
  type: procedure
  source_chapter: 附录3.2.B
  source_quote: |
    "在参与者战略严格递增及可微的假定下，我们证明惟一的对称贝叶斯纳什均衡就是本节推导出的线性均衡。我们所运用的技术方法可十分容易地扩展到较广类型的估价分布，以及两个以上投标者的情况。"
  summary: |
    当"猜线性"失效（估价非均匀分布、或需证明均衡唯一性）时，求/证对称BNE的一般技术路线。
    步骤：1) 设双方采用同一严格递增可微战略b(·)；2) 用反函数b⁻¹(bi)表示"对手出bi时必有的估价"，均匀分布下胜率=b⁻¹(bi)；3) 写FOC：-b⁻¹(bi)+(vi-bi)·d/dbi[b⁻¹(bi)]=0；4) 施加对称性要求bi=b(vi)：反函数项化为vi、导数项化为1/b'(vi)，得一阶ODE：b'(v)·v+b(v)=v；5) 两边积分（左边恰为d[b(v)·v]/dv）得b(v)·v=v²/2+k；6) 用经济学边界条件定常数——无人出价高于自己估价且出价非负→b(0)=0→k=0→b(v)=v/2。
    判定标准：对称均衡=单一战略是其自身最优反应；边界条件来自理性（不亏本出价）而非数学假定。
    边界：结论限于"严格递增+可微"战略类内；方法可推广到较广估价分布与n≥2投标人，是处理一般分布拍卖的标准入口。

  title: 双向拍卖线性均衡推导模板
  type: procedure
  source_chapter: 3.2.C 双向拍卖
  source_quote: |
    "在线性均衡中，当且仅当vb＞vs+（1/4）时才会有交易发生……不存在这样的贝叶斯纳什均衡：交易当且仅当有效率时将会发生。"
  summary: |
    买卖双方各有私人估价（独立均匀[0,1]）时，双向拍卖（同时报价，pb≥ps则以中价成交）的线性BNE推导模板。
    步骤：1) 写双方战略pb(vb)、ps(vs)与成交概率、期望成交价（含条件期望E[ps|pb≥ps]）；2) 设一方线性ps=as+cs·vs，则ps在区间[as,as+cs]上均匀分布；3) 对手最优化问题中的成交概率化为(出价-下限)/跨度，FOC显示最优反应仍线性：pb=(2/3)vb+as/3、ps=(2/3)vs+(ab+cb)/3；4) 系数匹配解出pb(vb)=(2/3)vb+1/12、ps(vs)=(2/3)vs+1/4；5) 由两式推出成交条件：仅vb>vs+1/4成交。
    判定标准：与单一价格均衡（对任意x：vb≥x且vs≤x才以x成交）比较效率——线性均衡漏掉所有价值<1/4的交易但不含几乎无价值的交易，期望福利更优；Myerson-Satterthwaite：线性均衡在所有BNE中期望获益最高，且不存在"当且仅当有效率(vb≥vs)才成交"的双方自愿机制。
    边界：交易区间小于3/4是双向私人信息下的固有损失；同构应用：企业知工人边际产出m、工人知机会成本v的雇佣谈判（霍尔-拉齐尔），m≥v未必达成雇佣。

- id: fa16
  title: 显示原理的使用方式（机制搜索压缩）
  type: framework
  source_chapter: 3.3 显示原理
  source_quote: |
    "定理（显示原理）任何贝叶斯博弈的任何贝叶斯纳什均衡，都可以重新表示为一个激励相容的直接机制。"
  summary: |
    私人信息下做机制设计/评估时，把无穷机制空间压缩到可解类别的两步杠杆。
    步骤：1) 把任何候选机制（拍卖变体、底价、进入费、失败者付费、概率分配等）抽象为直接机制：每个参与者惟一行动=声明自己的类型τi；按声明组合(τ1,…,τn)决定分配概率qi(τ)与转移支付xi(τ)；2) 设计{x,q}使实话实说成为BNE——即激励相容（IC）：每种真实类型下，报实类型是声明空间中的最优选择；3) 依据显示原理论证完备性：任何博弈的任何BNE都可重新表示为IC直接机制（构造新收益v*(τ,t)=ui[s*(τ),t]，均衡行动按声明代入原均衡战略执行）；4) 于是最优机制搜索只需在IC直接机制类中进行（如Myerson最优拍卖、Myerson-Satterthwaite不可能定理）。
    判定标准：IC+参与约束（每种类型愿参加，均衡收益≥拒绝参加收益）共同刻画可行机制。
    边界：显示原理只压缩搜索空间、不改变均衡结果集合；结论以贝叶斯纳什均衡为载体，扩展到动态贝叶斯博弈"十分简单"但需另行表述。
