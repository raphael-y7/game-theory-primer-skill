# cap.gibbons-game-theory.incentive-schemes

## R 原文依据

> "工人i选择努力程度e_i，从而使得额外努力的边际负效用g′(e_i)，等于增加努力的边际收益，后者又等于对优胜者的奖励工资w_H−w_L，乘以因努力程度提高而使获胜概率的增加。"（2.2.D）

> "(w_H−w_L)∫f(ε_j)²dε_j=g′(e*)。……当ε服从方差为σ²的正态分布时，则有∫f(ε_j)²dε_j=1/(2σ√π)，它随σ的增加而下降。"（2.2.D）

> "从而最优选择下的努力程度满足一阶条件g′(e*)=1，将其代入（2.2.6）则意味着最优激励w_H−w_L满足(w_H−w_L)∫f(ε_j)²dε_j=1。"（2.2.D）

> "企业必须向工人支付的，不仅足以补偿工人自我雇佣时的机会收入以及努力工作带来的负效用w_0+e，还包含工资升水(1−δ)e/[δ(1−p)]。"（2.3.D）

> "（2.3.5）和（2.3.7）合并为 y−e≥w_0+[(1−δ)/(δ(1−p))]e。……要使合作能够得以维持，贴现因子δ的值必须足够大。"（2.3.D）

## I 自述

激励结构两类模板，共同前提是**努力不可观测、产出（或其信号）可观测**，差别在付薪基准：锦标赛按**相对排名**付薪，效率工资按**绝对工资+解雇威胁**付薪。

**模板一：锦标赛（2.2.D，拉齐尔-罗森1981）**。两工人产出y_i=e_i+ε_i（ε独立同分布、均值0、密度f），老板只能按产出排名付w_H/w_L。工人努力FOC（2.2.5）：(w_H−w_L)·∂Prob{y_i(e_i)>y_j(e_j*)}/∂e_i=g′(e_i)；对称纳什均衡（2.2.6）：**(w_H−w_L)∫f(ε)²dε=g′(e\*)**。设计三步：①参与约束（2.2.7）½w_H+½w_L−g(e\*)≥U_a取等，得（2.2.8）w_L=2U_a+2g(e\*)−w_H；②老板最大化e\*−g(e\*)（期望利润2e\*−2U_a−2g(e\*)）⇒g′(e\*)=1；③代回（2.2.6）得**最优奖金差 w_H−w_L=1/∫f²dε**，与(2.2.8)联立拆出w_H、w_L。正态噪声（方差σ²）下∫f²=1/(2σ√π)，故奖金差=2σ√π（两式代入所得），随σ线性放大、e\*随σ下降——噪声越大竞赛越靠运气，须更大差距补回激励。（转写稿公式图内工资印作ω，即正文w，本卡统一写作w。）

**模板二：效率工资（2.3.D，夏皮罗-施蒂格利茨1984）**。阶段博弈（企业开工资→工人接受→选努力）的子博弈精炼解"使人失望"：w=0、自我雇佣——一次性激励必败。无限重复中触发结构：历史"高工资、高产出"则企业永付w\*、工人努力；任何偏离后永久w=0、自我雇佣。偷懒以概率p被抓住（低产出是偷懒无可辩驳的证据）。努力现值V_e=(w\*−e)/(1−δ)；偷懒现值V_s=[(1−δ)w\*+δ(1−p)w_0]/[(1−δp)(1−δ)]。V_e≥V_s即不偷懒条件（2.3.5）：**w\*≥w_0+[(1−pδ)/(δ(1−p))]e=w_0+e+[(1−δ)/(δ(1−p))]e**，其中**工资升水=(1−δ)e/[δ(1−p)]**：p→1（偷懒难被发现）升水急剧增大，p减小时升水上升；δ越大升水越小。p=0时退化为w\*≥w_0+e/δ（转写稿该处两窄行式标【辨识存疑】，按其自述"它的确是（2.3.5）中p=0时的情况"取修正读法）。企业条件（2.3.7）y−w\*≥0；合并可行性**y−e≥w_0+[(1−δ)/(δ(1−p))]e ⇒ δ须足够大**。前提假定y−e＞w_0＞py。

## A1 书中案例

**worked_example 1：两工人工作竞赛的最优奖金设计（2.2.D）**
结构：老板先定w_H、w_L；两工人观测后同时选努力e_1、e_2；产出y_i=e_i+ε_i；老板收益y_1+y_2−w_H−w_L。
- 工人期望收益最大化（2.2.4）化简为max(w_H−w_L)Prob{y_i(e_i)>y_j(e_j\*)}+w_L−g(e_i)；一阶条件（2.2.5）：边际负效用g′(e_i)=奖金差×获胜概率的边际增加。
- 贝叶斯法则展开获胜概率为∫[1−F(e_j\*−e_i+ε_j)]f(ε_j)dε_j；对称均衡e_1\*=e_2\*=e\*下得（2.2.6）(w_H−w_L)∫f²=g′(e\*)。
- 反向解第一阶段：参与约束（2.2.7）取等⇒（2.2.8）w_L=2U_a+2g(e\*)−w_H；期望利润化为2e\*−2U_a−2g(e\*)⇒老板只需最大化e\*−g(e\*)⇒g′(e\*)=1；代回（2.2.6）：(w_H−w_L)∫f²=1，即**最优奖金差=1/∫f²dε**；正态下方差σ²⇒奖金差=2σ√π，噪声越大差距越大。
- 原文自认忽略：不对称均衡与角点解e_1=e_2=0；破坏行为（习题2.8：y_i=e_i−½s_j+ε_i时最优奖励差应小于不考虑破坏的情形）。

**worked_example 2：效率工资的升水条件与可行性（2.3.D）**
结构：产出高y/低0；努力成本e；偷懒以p的概率得高产出；低产出=偷懒铁证⇒开除后永远w=0（自我雇佣收入w_0）；假定y−e＞w_0＞py。
- 阶段博弈解"使人失望"（w=0+自我雇佣）⇒转无限重复：企业战略=历史"高工资、高产出"则付w\*否则付0；工人战略=同样历史下努力，w≠w\*但w≥w_0时接受工资但偷懒。
- V_e=(w\*−e)/(1−δ)；V_s=w\*+δ{pV_s+(1−p)w_0/(1−δ)}=[(1−δ)w\*+δ(1−p)w_0]/[(1−δp)(1−δ)]。
- V_e≥V_s⇒（2.3.5）w\*≥w_0+[(1−pδ)/(δ(1−p))]e：工资须覆盖机会收入w_0、努力负效用e与升水(1−δ)e/[δ(1−p)]；p接近1升水急剧增大，p=0时w\*≥w_0+e/δ（按修正读法）。
- 企业侧（2.3.7）y−w\*≥0；合并y−e≥w_0+[(1−δ)/(δ(1−p))]e⇒δ足够大。子博弈精炼：序贯阶段博弈的子博弈还始于工人观测工资之后，按历史归两类（高工资高产出/其他）逐类验证；"永远自我雇佣"是永久性的。
- 原文延伸：多工人/多企业的劳动力市场使企业不愿重新谈判、解雇威胁可信（日本大企业低流动率佐证）；被解雇者另有不差去处⇒不存在努力均衡（Bulow-Rogoff国家债务同构）。

## A2 触发与投资映射

### 触发场景
- 解读上市公司管理层薪酬结构（奖金差、期权、相对业绩条款）或券商/基金内部考核机制（排名、分成、末位淘汰）。
- 设计或评估考核规则：产出可观测但努力不可观测（投研质量、销售业绩），须用相对排名或高薪威胁激励。
- 判断"高薪+严淘汰"组织（投行、私募）的努力均衡是否可持续：解雇惩罚是否真实、被解雇者的外部选项价值几何。

### 语言信号
- 中文："奖金差距""排名考核""末位淘汰""相对收益排名""激励相容""高薪养廉""铁饭碗""跳槽无忧""大锅饭""赛马机制""能上能下""押注排名"。
- 英文："tournament / rank-order pay"、"prize spread"、"efficiency wage"、"shirking"、"no-shirking condition"、"wage premium"、"monitoring probability"、"outside option"、"pay for relative performance"。

### 相邻区分
- 与 repeated-game-cooperation：效率工资是触发战略在**序贯阶段博弈+单向雇佣**上的特例（合作=努力、惩罚=开除）；本卡聚焦激励参数（奖金差/升水）的求解与解读，不处理对称合作的门槛。
- 与 commitment-credibility：承诺卡问"宣布的规则/政策可不可信"；本卡问"给定努力不可观测，报酬结构该怎么定、公告的激励怎么解读"。
- 与 signaling-equilibrium：信号卡处理报酬/股利作为**对外信息传递**（让市场推断类型）；本卡处理**机制内激励**（让代理人改变行动），方向相反。
- 与 double-auction-linear-eq：霍尔-拉齐尔版雇佣谈判是双边私人信息下的**交易机制**（成交/工资），效率工资是单方私人**行动**下的激励，两类"雇佣摩擦"勿混用。

### 投资场景映射
1. **券商研究员/基金经理锦标赛机制**：卖方新财富排名、相对收益榜单都是锦标赛模板——奖金差=上榜与落榜的报酬差，σ=评比噪声（运气占比）。噪声大的年份（风格错配、板块轮动）按模板奖金差须更大才能维持努力；排名靠后的理性反应是加大跟踪误差/押注高波动博排名（模板忽略的角点行为在现实中的对应物）——解读榜单行为先估σ。
2. **管理层薪酬激励解读**：把高管薪酬拆成"固定w_L+绩效w_H"读作锦标赛/计件：奖金差够不够对照1/∫f²（业绩噪声越大需要的差距越大）；只有期权无下行惩罚=只拿走了w_H−w_L的上半截，激励不对称→鼓励押注项目。用效率工资读"高薪+并购后高流失"：被解雇高管另有无损去处（Bulow-Rogoff逻辑）时，解雇威胁失效，高薪买不到努力。
3. **"高薪+严淘汰"组织的努力均衡**：投行/私募的高薪对应升水(1−δ)e/[δ(1−p)]：监督越松（p小）所需升水越高；解雇惩罚有效的前提是被解雇后"去处更差"——景气下行（外部选项变差）时同等薪酬买到更多努力，景气上行时激励失灵、人才流失，可作组织质量拐点的判断参数。
4. **薪酬公告的解读纪律**：激励模板的结论是均衡努力e\*，不是"公告薪酬=未来业绩"；看到天价激励方案先查参与约束与可行性（y−e＞w_0＞py类：扣除激励成本后生意本身是否值得做），再谈激励强度。

## E 执行步骤

1. **判定激励结构类型**：确认①努力是否可观测/可写入合同；②付薪基准是相对排名还是绝对水平；③关系是一次性还是重复。→ *完成标准*：归入锦标赛/效率工资/混合/不适用四选一。*判停点*：努力可直接写入合同（产出与努力一一对应且可司法执行）→ 两种模板多余，按直接计件分析。
2. **锦标赛路径**：估噪声分布（密度f与方差σ）→算∫f²→奖金差=1/∫f²→用参与约束取等拆w_H、w_L→核g′(e\*)=1对应的最优努力是否可达。→ *完成标准*：奖金差数值+σ敏感性方向+"运气占比"判断。*判停点*：工人对报酬方差明显敏感（风险厌恶）→ 线性效用假定失效，模板只给方向不给数值。
3. **效率工资路径**：定p（偷懒被发现概率）、w_0（外部选项）、e、y、δ代理变量→算升水(1−δ)e/[δ(1−p)]→核（2.3.5）与可行性y−e≥w_0+[(1−δ)/(δ(1−p))]e。→ *完成标准*：升水三分解（机会收入+努力补偿+升水）+可行性判定（δ够大与否）。*判停点*：被解雇者另有不差去处（w_0被外部工资托底）→ 惩罚失效、不存在努力均衡，转声誉机制分析。
4. **均衡可信性核查**：解雇/降薪惩罚是否会被重新谈判（单一关系 vs 有劳动力市场/多员工支撑）；锦标赛是否存在不对称均衡、角点解（都不努力）与破坏空间。→ *完成标准*：惩罚支撑结构一句话说明+角点/破坏风险评级。
5. **输出激励解读**：三档结论（激励充分/临界/失灵）+最敏感参数（σ、p、w_0、δ之一）+条件式表述。→ *完成标准*：结论含"在……参数范围内成立"的限定。
- **输入输出契约**：输入=付薪结构（排名/绝对）、可观测信号（产出/业绩指标）、噪声度量（σ或离散误差率）、监督概率p、外部选项w_0、贴现δ代理变量；中间产物=奖金差或升水的分解式、参与约束与可行性核对、惩罚可信性评级；输出=激励充分性三档判定+参数敏感方向+行为预测（趋同/押注/努力方向）。禁止输出：把奖金差/升水公式当精确定价；对一次性关系套用效率工资；忽略破坏与角点均衡直接断言"激励有效"。

## B 边界

1. **一次性激励失效（ce12）**：效率工资的全部激励来自无限重复+触发式解雇威胁；阶段博弈子博弈精炼解是w=0、自我雇佣——努力不可观测、产出合同难以司法执行时，任何"单期奖金制度"都破产。把模板用于一次性关系（短期外包、一锤子买卖）是越界使用。
2. **再谈判瓦解解雇威胁（ce10）**：单一企业-单一工人模型中，"永远自我雇佣"惩罚同时惩罚企业（失去劳动力），双方都想回到高工资均衡——原文自认"可以有很多理由对这种永远自我雇佣的合理性提出疑问"；惩罚可信性靠劳动力市场（多工人使企业不愿重谈、多企业互不雇佣被解雇者）外生支撑，模型本身不提供。
3. **锦标赛忽略不对称均衡与角点解（原文明示）**：求解只取对称内点均衡；e_1=e_2=0（都不努力）可以是均衡；破坏行为（习题2.8）使最优奖励差应更小——只按模板算奖金差而不查破坏空间会高估激励强度。
4. **风险中性+可加负效用假定**：u(w,e)=w−g(e)对工资线性（工人风险中性）；锦标赛把报酬方差强加给工人，风险厌恶下奖金差设计完全不同；δ、p、U_a、σ等参数外生给定且现实难测（全书批判点：只能间接估计）。
5. **作者盲点**：1992年成书，行为激励（公平感、内在动机、相对排名的心理成本）未进入模型；"产出可观测/努力不可观测"的二分在管理层多维度真实努力面前两头都不干净；多轮锦标赛（晋级结构）仅以罗森(1986)文献一笔带过未展开。
