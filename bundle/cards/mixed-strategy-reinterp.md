# 混合战略的正确解读：对手的不确定性（1.3.A）与净化正式化（3.2.A）

## R — 原文依据

1.3.A末："应该强调的是，这样一个混合战略纳什均衡并不是建立在任何参与者扔硬币、掷骰子或其他随机选择行为的基础之上"。3.2.A："混合战略纳什均衡的重要特征，不是参与者j随机地选择一个战略，而是参与者i不能确定j的选择，这种不确定性既可产生于随机因素，又可能（更为合理地）因为一小点儿私人信息。"

## I — 方法论自述

混合战略的博弈论含义不是"对手在掷骰子"，而是**你对他行动的不确定性**：

- **本体论（1.3.A/1.3.B）**：j的混合战略代表i对j将选择哪个纯战略的不确定性。棒球例：投球手基于以往投球成功率（私人信息）实际选的是纯战略，击球手知道其选择规则却观测不到成功率，只能推断为混合战略(1/2,1/2)——"混合"存在于观测者的推断中。
- **正式化（3.2.A，豪尔绍尼1973净化）**：完全信息博弈的混合战略纳什均衡（几乎总是）可以解释为与之密切相关、存在一小点非完全信息的博弈中的**纯战略**贝叶斯纳什均衡；j的混合战略=i对j私人信息（类型）的不确定性。
- **预测含义一：均衡中随机化不可预测**。猜硬币里任何可利用的规律都会立刻被对手利用：对手以q＞1/2偏重某面，你便总出另一面；只有(1/2,1/2)使双方期望收益与行动无关、无规律可用。故"我看穿了对手下一步"与均衡矛盾。
- **预测含义二：均衡概率由收益决定**。你的混合概率由**对手的**无差异条件解出——猜硬币的1/2来自±1对称收益；性别战的2/3来自(2,1)/(1,2)收益结构；改收益参数即改概率（比较静态）。
- **存在性含义**：纳什定理保证有限博弈存在均衡（可能混合）——"划线法无解"不等于"博弈无解"，只是无纯战略解。
- **应用姿态**：把观察到的对手"随机化/反复无常"翻译为信息结构问题（对方掌握了你看不到的东西），而非物理随机或非理性；进而问"他可能知道什么"，并检查己方行为有无可利用规律。

## A1 — 书中案例

**worked_example 1：猜硬币——不可预测性的逻辑（1.3.B）**
输入：±1收益猜硬币，参与者1推断2以q出正面。执行：1出正面期望1−2q、出背面期望2q−1；q＜1/2时1总出正面（即利用了2的偏向），q＞1/2时总出背面。结论：任何q≠1/2都给对手可乘之机，唯q=1/2使双方期望收益与行动选择无关——均衡概率不是"掷骰子频率"而是"让对手无规律可用的收益平衡点"。

**worked_example 2：性别战——概率由收益决定（1.3.B）**
输入：收益(歌剧,歌剧)=(2,1)、(拳击,拳击)=(1,2)、错开=(0,0)。执行：克里斯选歌剧期望2q、拳击期望1−q，无差异2q=1−q⇒q=1/3（帕特出歌剧的概率由**克里斯的**收益决定）；对称地r=2(1−r)⇒r=2/3。结论：混合NE=帕特(1/3,2/3)、克里斯(2/3,1/3)，各方以2/3概率打自己偏好结果——数字2/3完全由收益矩阵算出，与双方的"性格""习惯"无关。

**worked_example 3：净化——混合战略的贝叶斯推导（3.2.A）**
输入：性别战加私人信息——双方都选歌剧时克里斯收益为2+tc、都选拳击时帕特收益为2+tp；tc、tp相互独立~U[0,x]（x为很小的正数，分布形状不敏感）。执行：猜阈值纯战略——克里斯在tc超过临界值c时选歌剧、帕特在tp超过临界值p时选拳击；无差异联立(3.2.1)(3.2.2)：tc＞x/p−3=c、tp＞x/c−3=p⇒p=c且p²+3p−x=0。结论：选偏好结果的概率=1−(−3+√(9+4x))/(2x)，x→0时趋于2/3——纯战略BNE收敛于原混合均衡；"混合"被还原为对私人信息的不确定性。

**worked_example 4：棒球投球手——推断即混合（1.3.A）**
输入：投手基于以往成功率决定投快球还是曲线球；击球手了解其选择方式但观测不到成功率。执行：击球手推断投手投两类球的概率相等，把该推断记为投手的混合战略(1/2,1/2)。结论：投手实际从不掷骰子，"混合战略"只是击球手（信息劣势方）推断的忠实表示。

## A2 — 触发与投资映射

### 触发场景
- 观察到交易对手/管理层行为"无规律""反复无常"，需要判断这是噪音、非理性，还是均衡性质；
- 自己面对"该不该规律化操作"的决策（大单拆分、申报节奏、披露时点）；
- 求解收益矩阵时划线法无双划线格（无纯NE），需要解读混合均衡含义而非只报数字；
- 听到"庄家动作无法预测/主力随机洗盘"类说法，需要用博弈论校准其成立条件与适用边界。

### 语言信号
- 中文：随机化、不可预测、混合战略、无差异、概率、洗盘/出货、反常行为、看不穿的对手、信息不对称、他一定知道什么、规律被反噬。
- 英文：mixed strategy / randomization / unpredictable / indifference condition / private information / purification (Harsanyi 1973) / belief about opponent's action / no pure equilibrium / unpredictable equilibrium behavior。

### 与相邻能力的区分
- **nash-equilibrium-solver**：本卡不做求解，概率数字从该卡的无差异法来；本卡负责解读（信息结构、可检验含义）。
- **bayesian-nash-solver**：净化的正式机制（类型→战略、期望收益FOC）是BNE框架的应用；本卡只取其解释含义，不解BNE。
- **game-type-classifier**：无纯NE时先判类——猜硬币式严格对抗才必然混合；协调类博弈（性别战）主要问题是多重均衡而非混合。
- **iesda-procedure**：混合层占优检验（图1.3.1：B劣于T/M各1/2的混合）在该卡执行；但"混合战略=推断"这一本体论定位归本卡。
- **repeated-game-cooperation / reputation-mechanism**：长期关系中"看似随机"的行为可能是声誉或惩罚机制的一部分（KMRW伪装合作），先查重复结构再套混合解读。

### 投资场景映射
1. **跟风盘与主力的混合战略**：主力（拉抬/出货）对散户（追入/回避）近似猜硬币结构——均衡中主力行为不可预测；"主力今天很反常"的正确解读是"你处于信息劣势侧"（他掌握你看不到的成本/筹码/期限信息），而非主力失灵；同时你的申报节奏、拆单方式本身也应无可利用规律，否则被对手盘/算法反向收割（可剥削性=偏离混合均衡）。
2. **机构调仓前的多空博弈推演**：多空对峙若无纯NE（双方都想后发制人），推演结论不是"谁赢"的点预测，而是对手的混合概率分布+己方各行动的期望收益；该概率由对手的收益结构（持仓成本、赎回压力、考核期限）反推——对手收益参数变化时概率如何移动（比较静态）比点预测更可靠。
3. **竞拍/打新出价解读**：对手估价是私人信息，你观测到的"出价无规律"实为纯战略BNE（净化视角）——对手并非掷骰子而是按自身类型（估值）行事；工作重心应放在估计对手类型分布上，而非猜测其单次出价。
4. **龙虎榜/大宗交易行为解读**：交易对手"既买又卖、看似矛盾"，先查类型差异（不同期限/成本/约束的投资者在同一均衡中行动不同），再谈噪音；均衡概率由市场制度参数（费用、持仓期限、披露规则）内生决定，可从制度变化反推行为概率的移动方向。
5. **管理层沟通与信息披露节奏**：管理层在"透露/隐藏"上的随机化（有时详述有时沉默）可读为市场对其私人信息不确定性的均衡反映；追问"什么类型的消息会改变其无差异条件"比逐次猜测更有信息量。

## E — 执行步骤

1. **确认解读前提**：该博弈无纯NE（或对手行为在均衡中本就混合），已从nash-equilibrium-solver卡取得混合概率。
   判停点：存在唯一纯NE→无需混合解读；行为"随机"但博弈有纯NE→先查是否偏离均衡（行为/噪音层），不归本卡。
2. **翻译为信息结构**：回答"对方可能知道什么我不知道的？"——列出候选私人信息（成本、持仓、期限、指令约束、内部进度）。
   完成标准：至少一个可检验的私人信息假设（能指出"若为真会观察到什么"）。
3. **推导可检验含义（比较静态）**：均衡概率由收益结构决定→分析收益参数变化时概率的移动方向（如对手拉升成本上升→其"拉抬"均衡概率下降）。
   约定：只做定性方向判断；未估计收益函数时不给概率点预测，概率保留分数形式（1/2、1/3、2/3）。
4. **校准己方策略**：检查自己的行动序列（下单节奏、披露口径）是否含可被对手利用的规律；有则按混合均衡原则随机化或阻断观测。
   完成标准：己方策略在对手无差异条件下不可被单一应对策略剥削。
5. **输出解读**：一段话交付——对手行为=对私人信息的理性反应+均衡中不可预测+己方应对清单。
   判停点：若发现行为可用纯战略均衡+信息差异完全解释→改走信号/声誉框架（signal相关卡），混合解读降为辅助。

输入契约：已解出的混合均衡（或2×2收益矩阵）+对手收益结构的定性认知。
输出契约：对手行为解读（信息结构+不可预测性说明）+比较静态方向清单+己方校准清单。禁止输出："对手下一步会做X"式点预测。

## B — 边界

1. **ce06 混合≠掷骰子**：把均衡概率误读为"对手真在掷骰子"、进而以为可据此预测其下一步，是本卡首要禁忌；性别战净化例中x→0时行为收敛于2/3，说明行为可完全由纯战略（类型阈值）生成，"混合"只存在于信息劣势方的推断中——解读市场对手时把混合均衡翻译成信息结构，而非物理随机化。
2. **ce24 混合层漏检**：只在纯战略层做占优/最优反应检验会漏——图1.3.1中B劣于T/M各1/2的混合（期望3/2＞1）；图1.3.2中1/3＜q＜2/3时B是对手混合战略的最优反应，却不是对手任何纯战略的最优反应——混合层是分析的基本层，"纯战略层讲不通"不等于"博弈讲不通"。
3. **净化的适用范围（3.2.A原文边界）**：结论是"几乎总是"可净化（忽略极罕见的例外）；均匀分布只为可解、形状不敏感，但推导依赖线性收益结构；收益函数测不准的现实场景（投资者面对管理层）中净化只是解释框架，不是估计工具。
4. **作者盲点**：1992年成书——实验证据显示真人无法精确随机化、也常偏离均衡概率，书中"对手收益决定你的概率"以收益结构近似共同知识为前提；对收益本身测不准、或对手非理性程度可观测的场景，书中未处理，使用时须标注"条件性剧本"而非点预测。
