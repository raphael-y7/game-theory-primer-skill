# 标准式建模三要素

## R — 原文依据

1.1.A："博弈的标准式表述包括：（1）博弈的参与者，（2）每一参与者可供选择的战略集，（3）针对所有参与者可能选择的战略组合，每一个参与者获得的收益。"正式定义："在一个n人博弈的标准式表述中，参与者的战略空间为S1，…，Sn，收益函数为u1，…，un，我们用G={S1，…，Sn；u1，…，un}表示此博弈。"1.2.A以古诺模型示范"把问题的非标准描述转化为博弈的标准式"的完整程序。

## I — 方法论自述

标准式是博弈的"户口本"：三要素齐备，博弈才可解。建模四步：

1. **识别参与者**：谁在做决策（企业、工会、政府、投资者）；"自然"只负责抽类型或生成随机变量，不作为战略参与者（走贝叶斯框架时另行处理）。
2. **列战略空间Si**：战略=完整行动方案；连续变量写区间。判据是"全部可行选项"——如古诺Si=[0,∞)，不必人为设上限，因为Q≥a时P(Q)=0，超高产量自然落选。
3. **定收益ui**：每个战略组合下各方的收益（利润、效用、刑期皆可），ui(s1,…,sn)依赖**全部**参与者的选择。
4. **两人博弈画双变量矩阵**：习惯上横行参与者的收益放在前面、列参与者的收益放在后面。

三条口径：
- "同时选择"＝选择时不知他人选择，不要求物理同时——分开关押的囚徒可以在任何时间做选择；
- 战略空间须含全部可行选项，遗漏则无法计算最优反应、NE概念无从使用；
- 标准式也可表示序贯博弈（战略=完整应变计划），但动态分析惯用扩展式（extensive-form-modeling卡）。

产出试金石：三要素齐备后先查是否囚徒困境结构——只要收益数字满足T＞R＞P＞S（T=单方背叛所得、R=双方合作所得、P=双方背叛所得、S=被背叛所得），"招认"类背叛战略即严格占优，可直接进入剔除程序。

## A1 — 书中案例

**worked_example 1：囚徒困境的标准化（1.1.A）**
输入：语言描述——两嫌疑人被捕、分开关押；都不坦白各判1个月；都坦白各判6个月；一方招认而另一方不坦白，招认方马上获释、另一方判9个月（罪行6个月加干扰司法3个月）。执行：参与者={囚徒1,囚徒2}；战略空间={沉默,招认}；收益以"刑期取负"填双变量矩阵：沉默/沉默=(-1,-1)、沉默/招认=(-9,0)、招认/沉默=(0,-9)、招认/招认=(-6,-6)，行方收益在前。结论：G={S1,S2;u1,u2}三要素齐备；沉默对每人都是严格劣战略（对方任一选择下招认都更高），(招认,招认)成为唯一结果候选。

**worked_example 2：古诺模型的标准化（1.2.A）**
输入：非正式描述"两企业同时定产、市场出清价P(Q)=a−Q、单位成本cq"。执行：参与者=两企业；战略空间Si=[0,∞)（产量连续可分割；因Q≥a时P=0，超大产量不会被选，无需截断）；收益=利润πi(qi,qj)=qi[a−(qi+qj)−c]。结论：三要素齐备后NE条件化为各自最优化问题，解得q1*=q2*=(a−c)/3。

**worked_example 3：贝特兰德模型的标准化（1.2.B）**
输入：同行业改为"企业选择价格"，需求qi(pi,pj)=a−pi+bpj（b＞0，互为替代品）。执行：战略空间换成价格Si=[0,∞)，收益πi=[a−pi+bpj][pi−c]。结论：均衡p1*=p2*=(a+c)/(2−b)。原书特别提醒：古诺与贝特兰德是**两个不同的博弈**（战略空间、收益、行为皆不同），但用的是同一个均衡概念NE——"古诺均衡/贝特兰德均衡"之称不指新的均衡概念。

## A2 — 触发与投资映射

### 触发场景
- 新闻、研报或访谈里的互动描述（价格战、控制权之争、联合拿地）需要变成可解的模型；
- 检验一份"博弈分析"是否成立：三要素有没有写全（尤其收益函数）；
- 需要确认各方"选项清单"是否遗漏（战略=完整方案，不是单步动作）；
- 做竞争格局判断之前，先固定参与者与收益口径。

### 语言信号
- 中文：参与者/局中人、战略/策略/方案/选项、收益/支付/利润/得失、标准式/战略式/矩阵/支付矩阵、同时决定、建模。
- 英文：players / strategy set / strategy space / payoff / utility / normal form / strategic form / bimatrix / payoff matrix / simultaneous moves / model the game。

### 与相邻能力的区分
- **game-type-classifier**：先判类再建模；判为动态且需要显式时序/信息集时改用 extensive-form-modeling（扩展式五要素），标准式只在其战略层使用。
- **nash-equilibrium-solver / iesda-procedure**：G写出后的求解归这两卡；本卡不求解。
- **bayesian-nash-solver**：不完全信息时标准式扩为四要素G={A;T;p;u}（类型-推断框架），归该卡。
- **mixed-strategy-reinterp**：战略层遗漏混合可能会导致求解漏检，与该卡互为提醒。

### 投资场景映射
1. 两龙头价格战：把"市占率、单位毛利、降价幅度"翻译成收益矩阵，先固定谁在行、谁在列；
2. 控制权之争：参与者=争夺方与关键股东，战略=增持/联手/要约，收益=控制权价值减取得成本；
3. 同行同时竞标（土地、牌照、并购标的）：战略=报价，收益=中标概率×中标价值−成本；若估值互为私人信息→升格为贝叶斯四要素；
4. 审读研报的博弈章节：缺收益定义的"博弈分析"不可复核，先退回本卡补全三要素再评价其结论。

## E — 执行步骤

1. **列参与者**：谁有决策权。
   完成标准：参与者互斥、完备；"自然/市场"的作用（抽随机变量、出清价格）单列说明，不计入战略参与者（或转贝叶斯框架）。
2. **列战略空间**：每方全部可行方案。
   完成标准：覆盖完整（连续变量写区间并论证为何不需截断，如古诺[0,∞)）、互斥；核对"同时"口径（选择时互不知情即可）。
   判停点：某方选项无法枚举或信息结构未定→退回 game-type-classifier。
3. **定收益函数**：每个战略组合下每方的收益。
   完成标准：矩阵每格双变量齐全、各方收益同尺度可比（都用利润或都用效用）；参数式写出（如πi=qi[a−(qi+qj)−c]）。
   判停点：收益写不出或各方目标不明→先问，不代拟。
4. **结构复查与交接**：矩阵是否囚徒困境型（T＞R＞P＞S口径）；是否把"换战略变量"（产量↔价格）误当成新均衡概念。
   约定：两人矩阵横行参与者收益在前、列参与者在后；结论同时给出G的记号式与矩阵。

输入契约：语言描述+各方目标（利润/效用/刑期口径任一，保持一致）；缺目标函数→先问。
输出契约：G={S1,…,Sn;u1,…,un}完整表述+双变量矩阵+三条口径自查记录+困境型判别；整体交接给求解卡。

## B — 边界

1. **ce24 混合层漏检**：战略空间只列纯战略、检验也只在纯层做，会漏"纯战略被混合战略严格占优"的情形——图1.3.1中B不被T、M任一纯战略严格占优，却被"T、M各1/2"以期望收益3/2＞1严格占优。建模完成后，剔除与检验须在混合层完整执行。
2. **ce05 存在性边界**：战略空间无限（古诺、贝特兰德）时不在纳什定理覆盖内，均衡存在性须靠逐例构造证明（原书沿古诺思路）；建模时顺手写"由纳什定理必存在均衡"是误用。
3. **建模假设的自洽性**：贝特兰德线性需求qi=a−pi+bpj在现实中并不存在，仅当b＜2才有经济意义（1.2.B）——写出收益函数后要做自洽检验，勿把方便的函数形式当事实。
4. 动态问题硬套标准式会丢时序与信息结构；动态中战略是"覆盖每一种情况的完整应变计划"，需扩展式才能显式列出（extensive-form-modeling）。
5. 作者盲点：原书默认"收益函数可写出"；投资者面对管理层时，对手的收益（动机函数）常常测不准——此时应声明收益为假设而非事实，结论降格为条件性剧本。
6. 相邻易混概念：标准式≠矩阵本身（矩阵只是n=2的可视化）；"静态"≠物理同时；古诺均衡/贝特兰德均衡是博弈名，不是新的均衡概念。
