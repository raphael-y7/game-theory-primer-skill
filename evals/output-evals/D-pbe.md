# 任务3：用要求1-4检验回购信号剧本（强/弱类型×回购/不回购×投资/不投资）

依据能力卡 `cap.gibbons-game-theory.pbe-verification`，仅按卡内 E 段程序执行。

## 步骤1 画树、列信息集（卡E.1）

自然以 1/2、1/2 选强/弱 → 发送者观测类型（发送者两个**单节**信息集：强型节、弱型节）→ 发送者选 回购/不回购 → 接收者观测信号（不知类型）：
- I_回购 = {强→回购，弱→回购}（2节，非单节）；
- I_不回购 = {强→不回购，弱→不回购}（2节，非单节）；
→ 接收者选 投资/不投资，博弈结束。
存在非单节信息集 → 不退回逆向归纳/子博弈精炼卡，本卡接管。✓

## 步骤2 提出候选战略、划分路径（卡E.2）

候选（剧本）：σ_S(强)=回购，σ_S(弱)=不回购；σ_R(回购)=投资，σ_R(不回购)=不投资。
路径划分：I_回购 以概率 ½×1=1/2 到达 → **均衡路径上**；I_不回购 以概率 ½ 到达 → **均衡路径上**。
**关键划分结果：两信号都以正概率发出，两个信息集全在均衡路径上——本剧本作为分离均衡不存在路径外信息集。**

## 步骤3 要求3核验（卡E.3）

μ(强|回购) = P(强)σ(回购|强) / [P(强)σ(回购|强)+P(弱)σ(回购|弱)] = (½·1)/[(½·1)+(½·0)] = 1 → **μ(弱|回购)=0**。
μ(强|不回购) = (½·0)/[(½·0)+(½·1)] = 0 → μ(弱|不回购)=1。
剧本的推断"见到回购⇒弱类型概率为0"= μ(弱|回购)=0：与要求3的计算值一致，**但它位于均衡路径之上，是由要求3（贝叶斯法则×均衡战略）唯一钉死的路径推断，而非要求4管辖的路径外自由推断——剧本把它标注为"路径外推断"属于误标。**

## 步骤4 要求1+2核验（卡E.4）

**要求1（推断存在）**：接收者在 I_回购、I_不回购 均持有推断（各节概率 (1,0) 与 (0,1)，非负、和为1）✓；发送者两信息集为单节（类型已知），到达概率1 ✓。

**要求2（序贯理性）**——任务未给收益数值，验证输出为"通过条件"（四条不等式构成的闭环；偏离者的偏离收益按偏离信息集处由要求3钉死的推断与接收者的序贯理性反应计算）：
- 接收者在 I_回购（μ(强)=1）：投资最优 ⟺ u_R(强,回购,投资) ≥ u_R(强,回购,不投资)（投资强类型不吃亏）；
- 接收者在 I_不回购（μ(强)=0）：不投资最优 ⟺ u_R(弱,不回购,不投资) ≥ u_R(弱,不回购,投资)（投资弱类型亏损）；
- 强类型发回购：u_S(强,回购,投资) ≥ u_S(强,不回购,不投资)——若强类型偏离到不回购，I_不回购 处推断仍由要求3定为 μ(强)=0，接收者（据上式）不投；
- 弱类型不回购：u_S(弱,不回购,不投资) ≥ u_S(弱,回购,投资)——若弱类型偏离到回购，I_回购 处推断仍为 μ(强)=1，接收者（据第一式）投资；此即"弱类型不模仿"的 IC：回购成本须类型依存（弱>强，单交叉），弱类型花真金白银模仿强类型不划算。

标准解读（投资只有强类型可盈利、回购对弱类型成本更高）下四式全成立 → 逐信息集无偏离动机 → 要求2通过（条件于上述不等式；若任一不成立，剧本在该处出局）。

## 步骤5 要求4核验（卡E.5）

路径外信息集集合 = ∅ → **要求4在此空转**：没有可自由指定的推断，也没有"自由推断"警告项。卡I"要求4对信号博弈没有意义（发送者总在单节信息集行动）"在发送者侧成立；接收者侧本剧本因两信号都被使用而无路径外集。

## 最终答案

- 要求1 ✓（推断齐备）；要求3 ✓（μ(弱|回购)=0、μ(强|不回购)=0，均由贝叶斯×均衡战略算出）；要求2 ✓（条件于四条不等式：接收者"投资强有利/投资弱亏损"+发送者侧"回购成本类型依存、弱类型模仿不划算"）；要求4 空转（无路径外信息集）。**判定：剧本满足要求1-4，构成 PBE（要求2为条件性通过）。**
- **约束该推断的是要求3，不是要求4**：剧本所称"路径外推断：见到弱类型发回购的概率为0"实际位于均衡路径之上（强类型以概率1发回购，I_回购 以概率1/2到达），由要求3唯一钉死、无任何自由度；要求4在本剧本中无事可做。
- 警告/边界（卡B2 ce15、E.5判停点）：若换到"混同于不回购"类候选，回购信号才真正路径外；此时"回购⇒强类型"的推断在纯战略偏离下不受要求4约束（"可能情况下"的限定语）→ 属自由推断，此类均衡结论必须加警告标签并转信号要求5/6再精炼。不可把本剧本中由要求3支撑的路径推断与那种路径外自由推断混为一谈。
