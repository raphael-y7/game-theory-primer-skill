# 任务1｜古诺均衡 + 贝特兰德（同质）均衡 — 按纳什均衡求解卡执行

**所用卡**：`nash-equilibrium-solver.md`（E段执行步骤；I段连续型一阶条件法；A1 worked_example 1/2；B1存在性）

## E-1 确认输入G
- 参与者：企业1、企业2。
- 古诺博弈：战略空间 qi ∈ [0, ∞)，同时选产量；需求 P(Q)=100−Q（Q=q1+q2，Q≥100时P=0），边际成本 c=10，无固定成本。参数范围 c＜a：10＜100 ✓。
- 贝特兰德博弈（产品同质）：战略空间 pi ≥ 0，同时选价；同质 → 定价低者独占全部需求 D(p)=100−p，同价均分（份额惯例只影响销量分配，不影响利润水平）。
- 收益函数齐备（πi = qi·(P−c)）。连续型 → 走E-3；无离散矩阵，E-2划线法跳过。

## E-3 连续型一阶条件法

### （一）古诺
收益函数（企业1，企业2对称）：

π1(q1,q2) = q1[100−(q1+q2)−10] = q1(90−q1−q2) = 90q1 − q1² − q1q2

一阶条件：∂π1/∂q1 = 90 − 2q1 − q2 = 0

**最优反应函数**：R1(q2) = (90−q2)/2 = (a−c−q2)/2　（卡内 I 段：Ri(qj)=(a−qj−c)/2），对称地 R2(q1) = (90−q1)/2。

约定核对（E-3）：
- 凹性：∂²π1/∂q1² = −2 ＜ 0 ✓；
- 边界：内点解要求 q2 ＜ a−c = 90；均衡处 q2=30＜90 ✓（q2≥90时最优反应为0，此处不触发）。

联立：由对称性 q1=q2=q：q = (90−q)/2 ⇒ 3q = 90 ⇒ **q1* = q2* = 30**。
解代回自洽（E-3完成标准）：R1(30) = (90−30)/2 = 30 ✓。

价格与利润：
- Q* = 30+30 = 60，**P* = 100−60 = 40**
- **π1 = π2 = 30×(40−10) = 900**；核对卡内闭式 (a−c)²/9 = 90²/9 = 8100/9 = 900 ✓

垄断对照（卡内 worked_example 1 校验项）：qm=(a−c)/2=45、Pm=55、πm=(a−c)²/4=2025；古诺总产量 60＞45、价格 40＜55 ✓。

### （二）贝特兰德（产品同质）
卡内口径提示（worked_example 2 结论注释）：差异化产品公式 p*=(a+c)/(2−b) 依赖需求设定 qi=a−pi+b·pj，**同质特例不能套用该式**（E-3约定"换设定须重推"）；卡内明示：同质特例（习题1.7）均衡价 **p* = c**。重推：

同质产品 → 消费者只买低价者。
1. 若某家 pi ＞ c：对手降价至 pi−ε（仍＞c）即夺走全部需求 → 当前方有削价动机 → 非NE。
2. 若某家 pi ＜ c：每单位亏损(p−c)＜0，提价至c严格改善 → 非NE。
3. 候选 p1*=p2*=c=10：单方提价 → 销量为0、利润0（与原利润相同，无改善）；单方降价至10以下 → 毛利为负 → 恶化。**无单方有利偏离 → 是NE**（E-6偏离检验完成）。

均衡结果：P=10，总需求 Q = 100−10 = 90；同价均分各销45，**π1=π2 = 45×(10−10) = 0**（分配惯例不影响利润为0的结论）。

## E-5 存在性与完备性
连续无限战略空间，纳什定理不适用（卡内 B1/ce05：1.2节类博弈"不在此列"，存在性靠构造而非定理）→ 靠构造自洽：
- 古诺：两条反应函数为斜率−1/2的直线，内部交点唯一(30,30)；边界区无第二交点（q1=0 ⇒ R2(0)=45 ⇒ R1(45)=22.5≠0）。**唯一NE**。
- 贝特兰德同质：上述1、2类论证排除一切 p＞c、p＜c 组合，**唯一NE p*=c**。
- 无混合战略事项（连续战略空间；卡内混合程序针对有限博弈）。均衡唯一 → 无"均衡选择未决"标注事项。

## E-6 输出与偏离检验
**均衡清单**：

| 博弈 | 均衡 | 价格 | 各家利润 |
|---|---|---|---|
| 古诺（同时定产量） | q1*=q2*=30 | P*=40 | 900, 900 |
| 贝特兰德（同质，同时定价） | p1*=p2*=10 | P*=10（Q=90） | 0, 0 |

偏离检验（用(NE)式，卡内 E-6 / R段1.1.C）：
- 古诺NE处：给定q2=30，最优反应 R1(30)=30=q1* → 无单方偏离动机 ✓。
- "各产垄断一半 qm/2=(a−c)/4=22.5"的配额协议：对方产22.5时己方最优反应 R(22.5)=(90−22.5)/2=33.75=3(a−c)/8 ＞ 22.5 → **至少一方有动机偏离，非NE**（卡内 worked_example 1："合计垄断产量"协议非NE，一次性博弈必被背叛；重复博弈能否维持转 repeated-game-cooperation 卡查 δ≥9/17——卡内A2映射5）。
- 贝特兰德下任何"共同提价至p＞10"的协议：任一方稍降价即独占全部需求 → 非NE。

## 最终答案
1. **古诺均衡**：q1* = q2* = (a−c)/3 = 90/3 = **30**；Q=60；**P\* = 40**；**π1 = π2 = (a−c)²/9 = 900**。
2. **贝特兰德均衡（同质）**：**p1* = p2* = c = 10**；Q = 100−10 = 90；**π1 = π2 = 0**。
3. 两博弈各有唯一纳什均衡；"古诺/贝特兰德均衡"之称只指博弈不同（战略变量产量vs价格），均衡概念同为NE（卡内 worked_example 2 口径）。
