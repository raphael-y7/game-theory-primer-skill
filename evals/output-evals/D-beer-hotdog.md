# 任务2：啤酒-热狗博弈（Cho-Kreps）——混同于 m1(啤酒) 的均衡与直观标准

依据能力卡 `cap.gibbons-game-theory.signal-refinement-checklist`，仅按卡内 E 段程序执行。

## 收益设定（取自卡 A1 worked_example 2，类型换名、先验一般化为 q）

卡内啤酒或热狗博弈：吃自己偏好的早餐得1、避免冲突另加2；接收者与"软弱型"冲突得1、与"粗暴型"冲突得−1、不冲突得0。映射：**啤酒爱好↔粗暴型**（偏好啤酒），概率 q；**热狗爱好↔软弱型**（偏好热狗），概率 1−q。信号 m1=啤酒、m2=热狗；接收者两行动=冲突/不冲突。冲突当且仅当 P(热狗爱好|信号)>1/2。

发送者收益表：
| 类型 | m1(啤酒)+不冲突 | m1+冲突 | m2(热狗)+不冲突 | m2+冲突 |
|---|---|---|---|---|
| 啤酒爱好 | 3 | 1 | 2 | 0 |
| 热狗爱好 | 2 | 0 | 3 | 1 |

## 步骤1 前置核验（卡E.1）：混同于 m1 是否为 PBE、存在条件

候选：[(m1,m1)，(不冲突，冲突)]；路径上推断 μ(啤酒爱好|m1)=q（要求3）；路径外 μ(啤酒爱好|m2)=p。
- 接收者在 m1：冲突收益 =(1−q)(+1)+q(−1)=1−2q ≤ 0 ⟺ q≥1/2 → 不冲突为序贯理性。
- 啤酒爱好：均衡收益3；偏离 m2：冲突0 / 不冲突2，均 <3 → 不偏离。
- 热狗爱好：均衡收益2；偏离 m2：不冲突 3>2 → 必须让接收者在 m2 后冲突：需 p<1/2 → 偏离得 1<2 → 不偏离。
结论：**混同于 m1 是 PBE ⟺ q≥1/2**（配路径外推断 p<1/2）。
q<1/2 时不存在：接收者序贯理性必在 m1 后冲突；热狗爱好偏离 m2 无论对方反应（冲突得1 / 不冲突得3）都 >0（m1+冲突=0），必偏离。
（对照：**混同于 m2(热狗)** 同样 ⟺ q≥1/2 才是 PBE：路径上 μ(热狗爱好|m2)=1−q≤1/2 → 不冲突；需路径外 μ(热狗爱好|m1)>1/2 → 冲突，以吓退啤酒爱好者——否则其偏离得 3>2。）

## 步骤2 算均衡收益（卡E.2）

U\*(啤酒爱好)=3（m1 偏好+不冲突=1+2）；U\*(热狗爱好)=2（m1 非偏好+不冲突=0+2）。

## 步骤3 要求5检查（卡E.3）

m2(热狗) 对啤酒爱好劣？min_a U(啤酒爱好,m1,a)=min(3,1)=1 > max_a U(啤酒爱好,m2,a)=max(2,0)=2？1>2 否 → 非劣。
m2 对热狗爱好劣？min_a U(热狗爱好,m1,a)=min(2,0)=0 > max_a U(热狗爱好,m2,a)=max(3,1)=3？否 → 非劣。
→ 要求5不适用、零约束（印证卡B1/ce16：劣性条件取最强故排除力弱，可疑混同可满足要求5）。候选在要求5存活。

## 步骤4 要求6（直观标准）检查（卡E.4）

路径外信号 m2(热狗)，逐类型找均衡劣类型集合（max_a U_S(t_i,m2,a) < U\*(t_i)）：
- 啤酒爱好：max_a U(啤酒爱好,m2,a)=max(0,2)=2 < U\*=3 → **m2 是其均衡劣信号** → μ(啤酒爱好|m2)=0。
- 热狗爱好：max_a U(热狗爱好,m2,a)=max(1,3)=3 > U\*=2 → 非均衡劣 → 推断全部压到热狗爱好：μ(热狗爱好|m2)=1。

接收者对 μ(热狗爱好|m2)=1 的最优反应：**冲突**（与热狗爱好型冲突得+1 > 0）。
表白检验：热狗爱好若"被相信"会否受益？它确实被相信，但接收者相信它是热狗爱好后的最优反应恰是冲突（接收者喜欢与该型冲突），故热狗爱好偏离只得 1 < U\*=2 → 表白失败、偏离无利可图。
**结论：混同于 m1 与要求6相容，不被直观标准排除。**

对照（卡 worked_example 2 的本尊论证）：**混同于 m2(热狗) 的均衡在同程序下被剔除**——路径外 m1(啤酒) 处：热狗爱好 max_a U(热狗爱好,m1,a)=max(0,2)=2 < U\*=3 → 均衡劣 → μ(热狗爱好|m1)=0 → μ(啤酒爱好|m1)=1 → 接收者不冲突（−1<0）→ 啤酒爱好表白：偏离得 3 > U\*=2 → 偏离有利 → 与混同所需路径外推断 μ(热狗爱好|m1)>1/2 不相容 → 剔除。

## 步骤5 汇总存活者（卡E.5）

- 满足要求6的均衡：①分离均衡 [啤酒爱好→m1，热狗爱好→m2；接收者(不冲突，冲突)]（路径上推断 μ(啤酒爱好|m1)=1、μ(热狗爱好|m2)=1；两型各得3；两信号都在路径上、无路径外信号信息集，要求6空转地满足；偏离检验：啤酒爱好→m2 得0<3，热狗爱好→m1 得2<3）；②**混同于 m1**（存活）。混同于 m2 被剔除。
- **q≥1/2 的作用**：
  1. **存在条件**：路径上后验 P(热狗爱好|混同信号)=1−q≤1/2 时，接收者序贯理性地不冲突，两类才都不想逃——这是两个混同 PBE 共同的存在条件；
  2. **表白的相容性阈值**：剔除混同于 m2 靠的是"直观标准强制 μ(热狗爱好|m1)=0，与混同所需的 >1/2 不相容"；而混同于 m1 所需的路径外推断 μ(热狗爱好|m2)>1/2 恰与直观标准强制的 μ(热狗爱好|m2)=1 相容，故存活。
- 敏感性声明：混同于 m1 在直观标准下存活是该程序的已知边界（卡B2/ce16：满足要求5≠合乎情理，而要求6只剔除"表白不相容"者；Cho-Kreps 本人对此混同的更强质疑、稳定性判据不在卡内程序范围）；存活结论不依赖 q 的具体取值（只要 q≥1/2 候选存在）。

## 最终答案

混同于 m1(啤酒) 的均衡**存在当且仅当 q≥1/2**；它满足信号要求5（m2 对两类型均非劣信号），也满足信号要求6（直观标准）：路径外信号 m2 处唯一的非均衡劣类型是热狗爱好，推断压向它后接收者的序贯理性反应是冲突，热狗爱好偏离只得 1<U\*=2，表白不成立——**因此混同于 m1 不被直观标准排除**。被直观标准排除的是镜像的**混同于 m2(热狗)** 的均衡（热狗爱好在 m1 处均衡劣 → 推断压向啤酒爱好 → 不冲突 → 啤酒爱好表白 3>2）。q≥1/2 的作用：既是混同均衡的存在条件（路径上后验使接收者不冲突），也是"与所需路径外推断不相容则剔除"这一直观标准机制发挥作用的阈值——对 m2 混同不相容（剔除）、对 m1 混同相容（存活）。
