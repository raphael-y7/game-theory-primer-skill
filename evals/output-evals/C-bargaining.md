# 任务3｜三阶段序贯谈判的逆向归纳解 — 按逆向归纳卡执行

**所用卡**：`backward-induction.md`（E段步骤1–5；A1 worked_example 2 三阶段序贯谈判 2.1.D）

## E-1 画树/确认结构（按卡内标准模型）
卡内标准模型（worked_example 2，即Gibbons 2.1.D）：参与人1、2就蛋糕（大小1）轮流出价，贴现因子 δ∈(0,1)，若拖到第三阶段按**外生解 (s, 1−s)** 分配（1得s）。

- 阶段1：参与人1提出方案——1得 s₁、2得 1−s₁。2接受 → 按 (s₁, 1−s₁) 当期成交，结束；2拒绝 → 阶段2。
- 阶段2：参与人2出价 s₂（给1的份额），2自留 1−s₂。1接受 → 按 (s₂, 1−s₂) 成交、晚一期，现值 (δs₂, δ(1−s₂))；1拒绝 → 阶段3。
- 阶段3：外生分割 (s, 1−s)，现值 (δ²s, δ²(1−s))。

参数：蛋糕 = 1，δ = 0.9。

**符号说明**：任务文本把阶段1出价记作 s、阶段2出价记作 s'（"1接受则按(1−s')…"处截断），与卡内第三阶段外生份额 s 撞号。以下按卡内符号执行：阶段1出价 s₁、阶段2出价 s₂、第三阶段外生份额 s（任务 s↔s₁、任务 s'↔s₂）。任务文本在截断处未给第三阶段外生份额赋值，卡内标准模型将其留作外生参数，故解以 s 表示（文末附自相似数值锚）。

任务字面若把 s' 记为2自留份额（1得1−s'），与卡内 s₂ 互补（s' = 1−s₂），结果等价，见E-3换算。

终点收益齐备：阶段1成交 (s₁, 1−s₁)；阶段2成交 (δs₂, δ(1−s₂))；阶段3 (δ²s, δ²(1−s)) ✓。

## E-2 三前提检查
(i) 顺序行动 ✓（阶段1→2→3轮流出价）；(ii) 每位参与者在下一步行动前可观察此前全部行动 ✓（出价与接受/拒绝公开可见，完全且完美信息）；(iii) 收益共同知识 ✓（蛋糕、δ、外生分割共同知识）。三条满足 → 适用本卡。

## E-3 末端最优化（阶段3无决策者，末端决策在阶段2）
**1的接受规则**：1在阶段2接受 s₂ 得当期值 s₂；拒绝则阶段3所得 s 的当期（阶段2）现值只有 δs（卡内："下期所得s本期只值δs"）。接受当且仅当

s₂ ≥ δs = **0.9s**（无差异时假定接受——卡内口径）。

**2的出价**：出1恰愿接受的最小份额 **s₂* = δs = 0.9s**。2的成交所得（决策期现值口径，同卡内算法）1−s₂* = 1−0.9s；与拒绝后阶段3所得现值 δ(1−s) = 0.9−0.9s 比较：

(1−0.9s) − (0.9−0.9s) = 0.1 = 1−δ ＞ 0 → 2宁当期成交，出 s₂* = 0.9s，1接受。

（任务字面换算：2自留 s'* = 1−δs = 1−0.9s，1仍得 δs = 0.9s——与卡内 s₂*=δs 等价。）

**阶段2结果**：s₂* = 0.9s，1接受；2得 1−0.9s（阶段2现值），1得 0.9s。

## E-4 逐级回推（阶段1）
**2的接受规则**：接受 s₁ 当期得 1−s₁；拒绝 → 阶段2成交，2所得 1−s₂* = 1−0.9s（阶段2现值），贴现一期为 δ(1−0.9s) = 0.9−0.81s。接受当且仅当

1−s₁ ≥ 0.9−0.81s ⇔ **s₁ ≤ 1−δ+δ²s = 0.1+0.81s**。

**1的出价**：取2恰愿接受的最大值 **s₁* = 1−δ(1−δs) = 1−0.9+0.81s = 0.1+0.81s**（卡内公式 s1* = 1−δ(1−δs)）。

**1自身偏离核对**：若拖入阶段2，1在阶段2成交所得 s₂* = 0.9s（阶段2现值），折至阶段1为 δ·s₂* = 0.9×0.9s = 0.81s ＜ 0.1+0.81s（差 1−δ = 0.1 ＞ 0）→ 1宁当期按 s₁* 成交 ✓（卡内："1比较本阶段所得1−δ(1−δs)与拒绝后所得贴现δ·s2*=δ²s，前者更大"）。

**逆向归纳解（δ=0.9、蛋糕1）**：
- 阶段1：1提出 s₁* = 1−δ(1−δs) = 0.1+0.81s；**2立即接受，无拖延**。
- 路径外：阶段2若到达，2出 s₂* = δs = 0.9s，1接受。
- 各方所得（阶段1现值）：**1得 0.1+0.81s；2得 1−s₁* = 0.9−0.81s**（= δ(1−0.9s)，2恰在接受门槛上，按卡内约定接受）。

每级最优化唯一（接受门槛唯一、最优出价唯一）→ 解唯一（E-4完成标准）。

**先动优势与数值锚（卡内 worked_example 2 末条）**：卡内自相似无限版（Shaked-Sutton截断）给出唯一 s* = 1/(1+δ)。按"第三阶段外生份额 = 自相似续谈值 s*"截断回推（卡内 I 段：从某阶段起的子博弈与原博弈相同）：s₂* = δs*，s₁* = 1−δ+δ²s*，令 s₁* = s* ⇒ s*(1−δ²) = 1−δ ⇒

**s\* = 1/(1+δ) = 1/1.9 = 10/19 ≈ 0.5263**（2得 9/19 ≈ 0.4737）——先出价者份额严格过半，δ→1时趋对半。

卡内提示（B4）：该截断对无限博弈是非正式论证，故作为参照锚列示；三阶段标准模型的解以参数式 0.1+0.81s 为准。

## E-5 被剔除的不可置信威胁
- 阶段2中1威胁"拒绝0.9s的出价、拖到阶段3索取更多"：拒绝的当期现值至多与接受持平（δs = 0.9s），得不到更多，且按卡内约定无差异即接受 → 不可信（违背1自身利益）。
- 阶段2中2威胁"只肯给1留少于0.9s"：1必拒绝，2届时得 δ(1−s) = 0.9−0.9s ＜ 1−0.9s → 对2自身不优，不可信；2无法可信地索取高于 1−0.9s 的份额。
- 阶段1中2威胁"分我更多否则拒绝"：拒绝后所得现值至多 0.9−0.81s（与接受持平）→ 借拒绝加价的威胁不可信。
- 一般口径：逆向归纳解不含有不可置信的威胁（卡内 R 段 2.1.A）——"届时做违背自身利益之事"的威胁全部被剔除。

## 最终答案（δ=0.9，蛋糕1，按卡内标准模型）
- 阶段2（路径外）出价：s₂* = δs = **0.9s**，1接受。
- 阶段1（均衡路径）：1提出 **s₁* = 1−δ(1−δs) = 1−δ+δ²s = 0.1+0.81s**，**2立即接受，无拖延**。
- 支付：**1得 0.1+0.81s，2得 0.9−0.81s**。
- 说明：s 为第三阶段外生分割中1的份额，是卡内标准模型的外生参数（任务文本截断处未赋值）。若按卡内自相似无限版（Shaked-Sutton）锚定：**s\* = 1/(1+δ) = 10/19 ≈ 0.5263**，对应支付 (10/19, 9/19) ≈ (0.5263, 0.4737)。
