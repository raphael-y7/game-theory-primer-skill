# 任务2｜触发战略维持古诺默契的δ门槛 — 按重复博弈合作卡执行

**所用卡**：`repeated-game-cooperation.md`（E段步骤1–5；I段"门槛条件"；A1 worked_example 2 古诺共谋9/17）

## E-1 阶段博弈与NE收益
阶段博弈：古诺双头，P=100−Q、c=10（a=100）。由纳什均衡求解卡：阶段NE产量 qc=(a−c)/3=30，阶段NE收益（=触发战略的惩罚基准）

**e_i = πc = (a−c)²/9 = 90²/9 = 8100/9 = 900**（卡内 I 段：πc=(a−c)²/9）。

阶段博弈NE唯一（反应函数唯一交点）→ 满足E-1完成标准；唯一性不影响无限重复结论（卡内E-1）。

## E-2 目标合作收益x_i与最优偏离d_i
**默契（合作）产量**：每家 qm/2 = (a−c)/4 = 90/4 = **22.5**（垄断总产量 qm=(a−c)/2=45 之半）。

**垄断利润**：πm = (a−c)²/4 = 8100/4 = **2025**（卡内 I 段）。
每家合作收益 x_i = πm/2 = (a−c)²/8 = 8100/8 = **1012.5**（卡内："合谋利润 πm/2=(a−c)²/8"）。

**最优偏离**：对手守约产22.5时，偏离者取最优反应
qd = (a−q对方−c)/2 = (100−22.5−10)/2 = 33.75 = 3(a−c)/8（卡内："偏离产量 qj=3(a−c)/8"）。
偏离期市场：Q = 33.75+22.5 = 56.25，P = 100−56.25 = 43.75。
**πd = qd×(P−c) = 33.75×33.75 = 1139.0625**；
核对卡内闭式：πd = 9(a−c)²/64 = 9×8100/64 = 72900/64 = 1139.0625 ✓。

**惩罚利润 πc = 900**（E-1）。

三元组成列（E-2完成标准）：πm/2 = 1012.5，πd = 1139.0625，πc = 900。

## E-3 计算δ门槛
守约条件（卡内式2.3.2形态："继续合作的现值 ≥ 当期背离收益 + 惩罚现值"）：

(πm/2)/(1−δ) ≥ πd + δπc/(1−δ)

代入数字：

1012.5/(1−δ) ≥ 1139.0625 + 900δ/(1−δ)

两边乘(1−δ)＞0：

1012.5 ≥ 1139.0625(1−δ) + 900δ
1012.5 ≥ 1139.0625 − 1139.0625δ + 900δ
239.0625δ ≥ 1139.0625 − 1012.5 = 126.5625
**δ ≥ 126.5625/239.0625 = 0.529411…**

分数复核（按卡内"三类利润代入化简"，以(a−c)²=8100通除，即用单位利润 1/8、9/64、1/9）：
- 1/8 ≥ (9/64)(1−δ) + (1/9)δ
- 8/64 − 9/64 ≥ δ(1/9 − 9/64)
- −1/64 ≥ −(17/576)δ
- δ ≥ 576/(64×17) = **9/17 ≈ 0.5294** ✓

小数复核：126.5625×17 = 2151.5625；239.0625×9 = 2151.5625 → 商恰为 9/17 ✓。

**通用式核对**（卡内 I 段弗里德曼式 δ ≥ max_i(di−xi)/(di−ei)）：
- di−xi = 1139.0625 − 1012.5 = 126.5625；di−ei = 1139.0625 − 900 = 239.0625；比值 = 9/17 ✓。
- 对称双头，两家分量相同 → 无单侧更脆弱方（E-3完成标准：门槛+分量分解）。

**δ门槛 = 9/17 ≈ 0.5294，与卡内"δ≥9/17"完全一致（对照通过）。**

## E-4 子博弈精炼与惩罚设计
- 无限重复博弈每一子博弈等同原博弈，按历史归两类逐类核对（卡内 I 段、worked_example 1）：
  - (i) **全合作史**子博弈：战略即触发战略本身，最优性即E-3不等式（δ≥9/17时成立）→ 该类子博弈的NE；
  - (ii) **已背离史**子博弈：此后每期产古诺产量 qc=30，即每期重复阶段博弈唯一NE → 该类子博弈的NE。
  - 两类皆过 → **触发战略构成子博弈精炼纳什均衡**（δ≥9/17时）。
- 惩罚强度评级：**触发式（永久回到阶段NE）不是最严厉可信惩罚**——卡内 B1（ce13）：古诺用阿布勒两面战略（胡萝卜加大棒）在 δ=1/2 ＜ 9/17 即可达垄断产量（条件 3/8 ≤ x/(a−c) ≤ 1/2）。故 9/17 只是"该触发战略"的门槛，就"合作能否维持"而言可能被高估。
- 再谈判警示（卡内 B2/ce10）：惩罚期收益(900,900)帕累托劣于合作期(1012.5,1012.5)，事后有重谈动机；结论以此为条件。

## E-5 判定输出
- **条件式结论**：δ ≥ 9/17 ≈ 0.529 ⇒ "每家产22.5、谁背离则永久回到古诺产量30"的触发战略是子博弈精炼纳什均衡，垄断产量一半的默契可自我维持；δ ＜ 9/17 ⇒ 该触发战略不能支撑完全默契（当期背离诱惑压倒未来合作价值）。
- 门槛之下合作未全消（卡内 worked_example 2）：一般δ下触发战略可支撑产量 q* = (9−5δ)(a−c)/[3(9−δ)]，随δ单调递减——δ→0退到 qc=30，δ→9/17 达 qm/2=22.5。复核δ=9/17：9−45/17 = 108/17；3(9−9/17) = 432/17；q* = 90×(108/17)/(432/17) = 90×108/432 = 22.5 ✓。
- 现实δ映射（接单节奏、资本雄厚度、声誉价值）：任务未提供数据，不作点估计；输出条件式结论（卡内禁止把δ门槛点估计当精确预测）。
- 敏感方向：δ（未来权重）为第一敏感参数；惩罚强度为第二杠杆——换更严厉可信惩罚（两面战略）可把门槛降至1/2。

## 最终答案

| 量 | 数值 |
|---|---|
| 默契产量（每家） | qm/2 = (a−c)/4 = **22.5** |
| 垄断利润 πm | (a−c)²/4 = **2025**（每家合谋所得 πm/2 = 1012.5） |
| 背离利润 πd | 9(a−c)²/64 = **1139.0625**（偏离产量 3(a−c)/8 = 33.75） |
