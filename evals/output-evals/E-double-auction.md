# 评测输出 E-double-auction：双向拍卖线性均衡（依卡 double-auction-linear-eq.md）

执行程序：卡E段五步（机制结构→BNE条件→线性报价→交易门槛→效率定位）。

## 第1步 确认机制结构

- 战略：卖方要价 p_s(v_s)、买方出价 p_b(v_b)，均为类型→价格的函数；
- 信息：v_b、v_s 各自私人信息、独立 U[0,1]（双边私人信息成立）；
- 成交规则：同时报价，p_b ≥ p_s 则以中间价 p=(p_b+p_s)/2 成交，p_b < p_s 不成交（卡R段3.2.C原文）；
- 分布：均匀 U[0,1]（线性均衡存在的前提，卡B段3）。
- 判停点检查：估值确非共同可知→本卡适用，不退化为普通讨价还价。

## 第2步 写BNE条件

- 买方：max_{p_b} [v_b − E(p_s(v_s) | p_b ≥ p_s(v_s))] · Prob{p_b ≥ p_s(v_s)}；
- 卖方：max_{p_s} [E(p_b(v_b) | p_b(v_b) ≥ p_s) − v_s] · Prob{p_b(v_b) ≥ p_s}。
- 完成标准核对：条件期望方向正确（买方条件在 p_b ≥ p_s 上取）；"对方接受"这一事实泄露对方类型（卡I段）。

## 第3步 线性均衡报价规则并代入数值

卡内线性均衡（卡I段、A1 worked_example 2，式3.2.7/3.2.8）：

p_b(v_b) = (2/3)v_b + 1/12；p_s(v_s) = (2/3)v_s + 1/4

代入 v_b=0.9、v_s=0.6：

- 买方出价：p_b = (2/3)(0.9) + 1/12 = 0.6 + 1/12 = 36/60 + 5/60 = **41/60 ≈ 0.6833**
- 卖方要价：p_s = (2/3)(0.6) + 1/4 = 0.4 + 0.25 = **39/60 = 0.6500**

## 第4步 交易门槛判定

p_b > p_s ⇔ (2/3)v_b + 1/12 > (2/3)v_s + 1/4 ⇔ **v_b − v_s > 1/4**（卡R段引文）。

本例：v_b − v_s = 0.9 − 0.6 = 0.3 > 0.25 → **会成交**。

- 成交价 p = (p_b + p_s)/2 = (41/60 + 39/60)/2 = 40/60 = **2/3 ≈ 0.667**；
- 交叉验证：卖方最低可能要价 p_s(0)=1/4、买方最高可能出价 p_b(1)=3/4（卡A1印证条目），本例双方报价均落在可行域内，且 0.6833 > 0.6500，成交成立。

## 第5步 效率定位：为什么"没成交的交易"是结构性损失

- 有效区间是 v_b ≥ v_s；线性均衡的交易区间 v_b − v_s > 1/4 **严格小于**有效区间（卡I段"交易判据与效率"）。本例剩余 0.3 越过 1/4 门槛，均衡本身成交、无损失；凡是 0 < v_b − v_s ≤ 1/4 的类型组合（例如 v_s=0.6、v_b=0.8），在完全相同的机制下会"该成未成"。
- **结构性**的含义（卡B段1、I段）：未成交既不是当事人非理性，也不是机制设计失败——①双方各自压价/抬价以保住信息租金：买方截距 1/12 与卖方截距 1/4 之差（1/4−1/12=1/6）就是双方"保留余地"的度量（卡A2投资映射3）；②报价不仅决定能否成交，"对方接受"这一事实本身泄露对方类型（卡I段），单方面诚实报价（报 v_b、报 v_s）不是最优反应，故诚实报价不构成均衡。
- **不可消除性**（迈尔森–萨特思韦特1983，卡R段第4条引文）：支撑重叠+双方自愿参加 ⇒ 不存在"当且仅当 v_b ≥ v_s 才成交"的贝叶斯纳什均衡；且均匀分布下线性均衡的期望获益高于其他一切BNE——漏掉价值不超过 1/4 的交易是该框架内的**损失下界**，不是可以靠"换个价格规则"消掉的无谓错误（卡A2投资映射5）。
- 读法纪律（卡A2投资映射2）：观察到互利区间存在却不成交，先归因结构性交易损失，再谈内幕消息或阴谋论。

## 最终答案

1. **报价**：买方 p_b = (2/3)(0.9)+1/12 = 41/60 ≈ 0.683；卖方 p_s = (2/3)(0.6)+1/4 = 0.650。
2. **会成交**：v_b − v_s = 0.3 > 1/4，故 p_b > p_s，以中间价 p = 2/3 ≈ 0.667 成交。
3. **"没成交=结构性损失"**：该论断针对 0 < v_b − v_s ≤ 1/4 的交易——信息租金保护（截距差1/6）加"接受即泄型"使任何一方无法通过诚实报价获益；M-S定理证明双方自愿参加的任何机制都做不到"有效即成交"，故该区间的损失是结构性的，改善只能靠外部补贴或改变信息结构，把它归咎于非理性或机制设计失败都是误读。
4. **条件限定**（卡E段第5步完成标准）：以上报价函数与 1/4 门槛依赖估值独立均匀 U[0,1]、中间价成交规则、拟线性风险中性效用、双方自愿参加；换分布或换分牌规则则报价与门槛全部重算，1/4 不是普适常数（卡B段3、E段禁止输出条目）。
