# cap.gibbons-game-theory.subgame-perfection-check

## R 原文依据

> "参与者2威胁参与者1，如果他不付1000美元就引爆手雷……参与者1却不会对这一威胁信以为真，因为它不可置信：如果给参与者2一个机会，让他把威胁付诸实施，参与者2也不会选择去实施它，这样参与者1就会一分不付。"（第2章引言/2.1.A）

> "定义 扩展式博弈中的子博弈：（a）始于单节信息集的决策节n（但不包括博弈的第一个决策节）；（b）包含博弈树中n之下所有的决策节和终点节；（c）没有对任何信息集形成分割。"（2.4.B）

> "定义（塞尔滕，1965）如果参与者的战略在每一个子博弈中都构成了纳什均衡，则称纳什均衡是子博弈精炼的。"（2.3.B、2.4.B）

> "对每一个第一阶段的可行结果（a1，a2），其余部分在参与者3和4之间进行的博弈都存在惟一的纳什均衡，表示为（a3\*（a1，a2），a4\*（a1，a2））。"（2.2.A）

## I 自述

子博弈精炼纳什均衡（SPNE）判定程序回答的问题是：一个纳什均衡里的威胁或承诺，在真的轮到执行时还是不是最优？判定分四步：①按三条件列子博弈清单——起点处于单节信息集中的决策节（非整棵树的第一个决策节）、包含其下全部决策节与终点节、不切割任何信息集；条件(c)保证"博弈到此为止的进行过程"是所有参与者的共同知识，子博弈才能作为独立博弈分析。②确认候选战略组合是原博弈的纳什均衡。③把该战略限制到每个子博弈上，逐一检验是否仍是该子博弈的NE。④全部通过⇒SPNE；任一子博弈不通过⇒该均衡含不可置信威胁/承诺，剔除。

**手雷检验（威胁可信性测试）**：假设被威胁方无视威胁、博弈真实到达实施节点；站在威胁者立场解该节点的最优行动；最优≠威胁内容⇒不可置信（手雷博弈中参与者1一分不付），含此威胁的NE非SPNE应剔除；威胁内容恰为该节点最优⇒可信，可支撑威慑。关键在"是否愿意执行"，而非"是否说出"。

**两阶段博弈专用解法（逆向求解）**：前提是对每个第一阶段结果(a1,a2)，第二阶段博弈存在唯一NE(a3\*(a1,a2),a4\*(a1,a2))。程序=先解第二阶段NE，把均衡收益替入第一阶段收益函数，再解第一阶段同时行动博弈得(a1\*,a2\*)；子博弈精炼解=(a1\*,a2\*,a3\*(a1\*,a2\*),a4\*(a1\*,a2\*))。第二阶段的"威胁"若非该阶段NE则不可信。

存在性与概念区分：任何有限完全信息动态博弈都存在SPNE（可能含混合战略）；"解"=始于初始节终于终点节的预期路径，"均衡"=针对所有可能情况的完整战略组合；同时行动博弈无真子博弈，此时SPNE退化为NE。书中三大应用：银行挤提（2.2.B）、关税博弈（2.2.C）、工作竞赛（2.2.D）。

## A1 书中案例

**worked_example 1：银行挤提的两阶段逆向求解（2.2.B，戴蒙德-迪布维格1983简化版）**
两存款人各存D于长期项目：日期1提前变现共得2r（D＞r＞D/2），日期2到期共得2R（R＞D），无贴现。日期1：都提款各得r；一人提款得D、另一人得2r−D；都不提款进入日期2。日期2：都提款各得R；一人提款得2R−D、另一人得D；都不提款各得R。
- 日期2博弈：R＞D⇒2R−D＞R，"提款"严格占优，**唯一NE（提款,提款）=(R,R)**。
- 把(R,R)替入日期1"都不提"格；因r＜D⇒2r−D＜r，日期1变形博弈有**两个纯NE：（提款,提款)=(r,r)（挤提）与（不提,不提)=(R,R)（效率）**——原博弈因此有两个子博弈精炼解。
- 与囚徒困境的区别：低效率均衡不唯一。原书克制表述："这一模型并不能预测何时会发生对银行的挤提，但的确显示出挤提会作为一个均衡结果而出现。"

**worked_example 2：关税博弈与国际市场不完全竞争（2.2.C）**
两国政府同时定关税ti，两企业观测后同时选内销hi与出口ei；P=a−Q、边际成本c+关税。
- 第二阶段（企业子博弈）：对每组关税解两组古诺一阶条件，得 **hi\*=(a−c+ti)/3、ei\*=(a−c−2ti)/3**——关税抬高对手在本地市场的有效成本。
- 第一阶段（政府博弈）：把企业均衡收益代入政府福利函数，解得 **ti\*=(a−c)/3，且为占优战略**（边际成本递增等设定下则未必占优）。
- 子博弈精炼解：**t\*=t\*=(a−c)/3，h\*=h\*=4(a−c)/9，e\*=e\*=(a−c)/9**。社会最优是t=0（零关税下总产量2(a−c)/3高于均衡下5(a−c)/9）——政府间互动构成囚徒困境：惟一纳什均衡是其占优战略，但对整个社会低效率，故政府有动因签订相互承诺0关税的协定（自由贸易）。

**worked_example 3：工作竞赛的锦标赛激励（2.2.D，拉齐尔-罗森1981）**
老板（参与者1）先定奖金结构wH、wL；两工人（参与者3、4）观测后同时选努力ei；产出yi=ei+εi，收益u=w−g(e)，g递增凸。
- 第二阶段（工人子博弈）：对称NE一阶条件 **(wH−wL)∫f²dε=g′(e\*)**（式2.2.6）——奖励差距越大努力越强；正态噪声下方差σ²时 ∫f²=1/(2σ√π)，噪声越大努力越弱。
- 第一阶段（老板）：参与约束(wH+wL)/2−g(e\*)≥Ua取等得 wL=2Ua+2g(e\*)−wH（式2.2.8）；老板最大化期望利润2e\*−wH−wL ⇒ **g′(e\*)=1**，代回(2.2.6)得最优奖金差距 **wH−wL=1/∫f²dε**（正态下随σ增大而拉大）。

## A2 触发与投资映射

### 触发场景
- 互动是"先决策、后行动"的两阶段结构（先政策/规则/奖金，后市场/工人/企业），要预测终局。
- 需要检验某个均衡（或某方威胁：价格战、断供、减持、同归于尽）在真的到达执行节点时是否仍符合理性。
- 博弈树中含同时行动环节（非单节信息集），逐节逆向归纳不可用，但能用子博弈切分。

### 语言信号
- 中文："他真的敢做吗""威胁可信吗""先把规则定了大家再动""先解后面那一环""每一环都要稳""两步走""第二阶段的均衡是什么"。
- 英文："credible / incredible threat"、"subgame perfect"、"backward substitution / solve the last stage first"、"would he really carry it out"、"two-stage game"、"continuation equilibrium"。

### 相邻区分
- 与 backward-induction：后者适用全部信息集为单节的完美信息博弈（逐节回推即得解）；本卡处理含同时行动环节的非完美信息动态博弈，逆向归纳遇非单节信息集失效，改为逐子博弈检验NE。
- 与 commitment-credibility：本卡给出"威胁是否可信"的判定程序；承诺卡聚焦"先动+承诺本身如何改变均衡"（斯塔克尔贝里、货币政策时间一致性），是本卡手雷检验在承诺方向上的专题化。
- 与 repeated-game-cooperation：无限重复博弈的子博弈无穷多，须按历史归并为有限类（合作类/惩罚类）逐类验证，用δ门槛判合作可持续，而非列子博弈清单逐一检验。
- 与 pbe-verification：信息集无法构成子博弈（多节信息集被切割）时，子博弈精炼不够用，须转入精炼贝叶斯均衡（战略+推断联合自洽）。

### 投资场景映射
1. **银行/券商挤兑与流动性危机**：存款人、理财赎回、两融平仓都是(提款,提款)式的两阶段结构——先解"最后一天"的占优行动（跑），再回推今天的最优反应。结论应表述为条件剧本："若市场相信他人会跑，跑是均衡"，同时寻找改变收益的护栏（存款保险、停牌、流动性支持），而非断言挤兑一定发生。
2. **关税战与贸易摩擦**：关税博弈给出t\*=(a−c)/3的占优战略与囚徒困境结构——对出口链公司，若加税是双方占优战略，"谈判达成自贸协定"的动因内生存在；低效均衡也可以是唯一均衡，勿因"对双方都不好"就排除加税剧本。
3. **管理层激励与内部竞赛**：锦标赛模板读高管薪酬与销售排名赛——奖金差距wH−wL是否与业务噪声σ匹配（噪声越大差距须越大）；差距过小的激励结构推不出努力均衡，业绩展望可信度打折。
4. **监管先手的两阶段政策博弈**：监管定规则（关税、补贴退坡、排放配额）→企业观测后调整产量/定价。先解市场端NE替入监管端收益，再解监管均衡，识别规则公告中"不可信的部分"（届时对监管者自身不最优的条款）。
5. **威胁类公告的过筛**：股东"不排除罢免/减持到底"、公司"绝不降价"等表述先做手雷检验——假设真的到达执行节点，该行动是否仍是其最优反应；不是⇒不可置信，勿计入定价剧本。

## E 执行步骤

1. **列子博弈清单**：按三条件（单节信息集起点、含全部后续节点、不切割信息集）找出全部真子博弈；同时行动博弈无真子博弈。→ *完成标准*：每个子博弈有明确起点节点，且说明为何不切割信息集。*判停点*：整棵树找不到真子博弈→SPNE退化为NE，转静态方法。
2. **求原博弈全部NE**：用标准式/划线法/混合战略求解。→ *完成标准*：NE清单完备（含混合），无遗漏。
3. **逐子博弈做手雷检验**：对每个NE，把战略限制到每个子博弈上检验是否NE；到达威胁实施节点时，站在威胁者立场解其最优行动，与威胁内容比对。→ *完成标准*：每个NE标注"通过/不通过+哪个子博弈、哪个行动不最优"。*判停点*：子博弈内NE不唯一或求解不唯一→SPNE不足以选出唯一预测，补均衡选择论证或降级为"可能性清单"表述。
4. **两阶段专用捷径**：验证"对每个(a1,a2)第二阶段NE唯一"前提→先解第二阶段NE、替入第一阶段、解第一阶段。→ *完成标准*：前提逐字核实，得到(a1\*,a2\*,a3\*(a1\*,a2\*),a4\*(a1\*,a2\*))。*判停点*：第二阶段NE依赖第一阶段结果且不唯一→前提失效，走第3步完整程序。
5. **输出判定报告**：区分"解"（预期路径）与"均衡"（完整战略组合）；列出被剔除的NE及所含不可置信威胁；给出可信威胁清单。→ *完成标准*：结论含三件套——幸存SPNE、剔除名单、威胁可信性一句话复核。
- **输入输出契约**：输入=扩展式（参与者、时序、信息集、收益）或两阶段文字描述；中间产物=子博弈清单、全部NE、逐子博弈检验表；输出=SPNE（完整战略组合）、被剔除NE与不可置信威胁清单、条件式预测表述。禁止输出：把被剔除NE当结论、把"解"当"均衡"、对多均衡博弈给点预测。

## B 边界

1. **纳什均衡容忍不可置信威胁（ce01，手雷博弈）**：NE只要求无人愿在既定战略上独自偏离，不检验威胁在到达时是否仍最优——"付钱+引爆"也可成为均衡。凡从静态NE或未经子博弈检验的动态结论直接引用，都可能把勒索式威胁当真；本卡第3步是强制关。
2. **非完美信息下逆向归纳失效（ce23）**：博弈含非单节信息集时，"强迫参与者在某一节考虑行动"不等于"在可能发生的情况下考虑行动"；子博弈精炼虽可处理被切割的子博弈，但路径外信念需另行约束——涉及推断问题时转精炼贝叶斯均衡（第4章），子博弈精炼不是万能筛。
3. **精炼解决可信性、不解决效率（ce08/ce09）**：关税博弈的占优战略均衡t\*=(a−c)/3社会低效，里昂惕夫工会的逆向归纳解(w\*,L\*(w\*))也落在双方可同时改善的区域——"通过了可信性检验"与"结果可取"无关；效率出路在改收益结构/博弈规则（如自贸协定、重复谈判），勿劝"理性"。
4. **多均衡不能给时点预测（ce07，挤提）**：挤提与不挤提并存为两个子博弈精炼解，恐慌自我实现；模型只给"可能性"，不给"何时"。对流动性事件用条件剧本+制度护栏分析，勿据本卡输出择时。
5. **作者盲点**：理性（及"理性是共同知识"）是公理假设而非实证结论，1992年成书未纳入实验与行为偏离；多重均衡的选择无一般答案；贴现因子、收益函数等参数被假定外生可测，现实中投资者面对的对手收益结构常写不出来；金融具体制度（涨跌停、停牌、信息披露规则）不在模型范围内，套用时先核对制度参数是否改变收益矩阵。
