# cap.gibbons-game-theory.repeated-game-cooperation

## R 原文依据

> "这一战略是触发战略（trigger strategy）的一种……如果没有人选择不合作，合作将一直进行下去；一旦有人选择不合作，就会触发其后所有阶段都不再相互合作。"（2.3.B）

> "当且仅当下式成立，选择Rj为最优：4/(1−δ)≥5+δ/(1−δ)（式2.3.1），即δ≥1/4。于是，当且仅当δ≥1/4时，参与双方都采取触发战略是博弈的纳什均衡。"（2.3.B）

> "将πm、πc、πd的值带入（2.3.2）可得δ≥9/17。"（2.3.C）

> "如果对每一个参与者i有xi＞ei，且如果δ足够接近于1，则无限重复博弈G（∞，δ）存在一个子博弈精炼纳什均衡，其平均收益可达到（x1，…，xn）。"（2.3.B，弗里德曼1971定理）

## I 自述

重复博弈合作可持续性判定，核心是一句话：**"继续合作的现值 ≥ 当期背离的收益 + 惩罚的现值损失"**。

**度量工具**：给定贴现因子δ（δ=1/(1+r)，也可解释为每期以概率p终止、δ=(1−p)/(1+r)），收益序列π1,π2,…的**现值**为 Σδ^(t−1)πt；**平均收益**为 (1−δ)Σδ^(t−1)πt，即现值的(1−δ)倍。优点是可与阶段博弈收益直接比较：每期得4的序列，平均收益为4、现值为4/(1−δ)（转写稿此处印作"4(1−δ)"系OCR漏除号，按原书定义"平均收益为现值的(1−δ)倍"校订）；使平均收益最大即等同使现值最大。

**触发战略**：合作期执行合作行动；一旦有人偏离，其**后所有阶段**永久转向阶段博弈纳什均衡（惩罚）。判定分两层：先证它是纳什均衡（算δ门槛），再证子博弈精炼——无限重复博弈的子博弈均等同原博弈、按历史归并为两类（全部合作史/已有背离史），逐类验证NE。

**门槛条件**：囚徒困境（合作4、背离5、惩罚1）：4/(1−δ)≥5+δ/(1−δ) ⇒ **δ≥1/4**。古诺共谋（合谋利润πm/2=(a−c)²/8、背离利润πd=9(a−c)²/64、纳什利润πc=(a−c)²/9，偏离产量qj=3(a−c)/8）：(πm/2)/(1−δ)≥πd+δπc/(1−δ) ⇒ **δ≥9/17**。通用式（弗里德曼）：**δ≥max_i(di−xi)/(di−ei)**，其中xi为目标合作收益、di为最优偏离收益、ei为阶段NE收益；由di≥xi＞ei保证门槛＜1。

**无名氏定理逻辑**：δ越大（未来越重要）惩罚越有效，可实现均衡平均收益的集合随δ扩大——δ足够接近1时，可行收益集中优于阶段NE收益的整个区域都能被子博弈精炼均衡实现；富登伯格-马斯金(1986)把下界从NE收益ei放宽到保留收益ri。反之，**低δ=未来不重要=惩罚不痛=短视竞争**：δ小于门槛时，当期背离的好处压倒未来合作的价值，合作/默契解体。

## A1 书中案例

**worked_example 1：无限重复囚徒困境与触发战略（2.3.B）**
图2.3.6囚徒困境：不合作(L)=(1,1)、单方背离得5、合作(R)=(4,4)，无限重复、贴现δ。触发战略：第一阶段选Ri；第t阶段若前面t−1阶段结果都是(R1,R2)则选Ri，否则选Li。
- 背离收益现值：当期5+此后每期1，即 5+δ/(1−δ)；合作收益现值：V=4+δV ⇒ **V=4/(1−δ)**。
- 最优反应条件（式2.3.1）：**4/(1−δ)≥5+δ/(1−δ) ⇔ δ≥1/4**。
- 子博弈精炼论证：无限重复的每一子博弈等同原博弈，按历史归两类——(i)全合作史子博弈中战略即触发战略本身（已证是NE）；(ii)已背离史子博弈中战略只是永远重复(L1,L2)（也是NE）——两类皆过，触发战略均衡是子博弈精炼的。

**worked_example 2：古诺双头共谋与门槛9/17（2.3.C，弗里德曼1971最初例子）**
阶段博弈为古诺（P=a−Q、边际成本c、古诺产量qc=(a−c)/3）；触发战略=每期生产垄断产量之半qm/2=(a−c)/4，背离则永久回到qc。
- 利润三元组：合谋 **πm/2=(a−c)²/8**；对合谋产量的最优偏离 qj=3(a−c)/8，得 **πd=9(a−c)²/64**；古诺 **πc=(a−c)²/9**。
- 条件（式2.3.2）：**(πm/2)/(1−δ)≥πd+δπc/(1−δ) ⇒ δ≥9/17**（三类利润代入化简）；与囚徒困境同理可证子博弈精炼。
- 门槛之下合作并未消失：对一般δ，触发战略可支持的产量 q\*=(9−5δ)(a−c)/3(9−δ)，随δ单调递减——δ→9/17时达qm/2（完全共谋），δ→0时退到qc。
- 同一问题换更严厉惩罚（阿布勒胡萝卜加大棒两面战略：背离后单期共同惩罚产量x、再背离重新惩罚、守罚则恢复合作）：**δ=1/2（小于9/17）即可达垄断产量**，条件为3/8≤x/(a−c)≤1/2——惩罚强度决定门槛。

## A2 触发与投资映射

### 触发场景
- 两个或多个主体长期重复打交道（供应商—客户、竞争对手、平台—商家、基金—渠道），要判断默契合作/价格维持/互惠安排能否自我维持。
- 观察到行业里"本应打价格战却相安无事"，或"协议刚签就背叛"，需要事前参数化解释。
- 评估一次性的诱惑（抢单、跳槽、挖角、降价抢份额）与长期关系价值之间的权衡。

### 语言信号
- 中文："长期看大家都不傻""这套默契能撑多久""撕破脸划算吗""以后还要见面的""杀敌一千自损八百""关系值多少钱""报复/断供/拉黑""断人财路"。
- 英文："grim trigger / punishment phase"、"is collusion sustainable"、"discount factor / patience"、"one-shot deviation"、"repeated interaction"、"shadow of the future"、"short-termism"。

### 相邻区分
- 与 subgame-perfection-check：重复博弈的子博弈无穷多，不能逐个列举；本卡按历史归并（合作类/惩罚类）逐类验证，并用δ门槛做参数化判定。
- 与 commitment-credibility：时间一致性是本卡触发战略在货币政策上的特例（δ≥c/(2c+d²)）；本卡处理一般化的"合作可持续"门槛。
- 与 reputation-mechanism：本卡δ门槛要求参与者无限耐心且博弈无限重复；有限重复中靠"小概率非理性类型"的声誉机制（KMRW）支撑合作，是另一条互补通道。
- 与 incentive-schemes：效率工资是触发思想在序贯阶段博弈上的变体（单方重复+开除惩罚+工资升水），聚焦单向激励而非对称合作。

### 投资场景映射
1. **行业价格战与默契格局（事前判断δ类参数）**：判断行业默契（价格维持、分区而治、不挖对方客户）能否自我维持，先估三个δ类参数——**接单节奏**（重复频率越高、越看未来，δ越大）、**资本雄厚度**（谁更能熬过惩罚期，弱势方δ低易先背叛）、**声誉价值**（未来利润流占比，品牌与资质越重δ越大）。δ≥门槛（用行业利润三元组πm/2、πd、πc仿9/17算法估计）→默契均衡可持续，价格战只在"意外/误判/需求突变触发的惩罚期"出现；δ＜门槛→短视竞争为常态，份额战的赢家才有定价权。
2. **长期供应商关系**：专用资产+重复订单构成触发结构——客户拖欠/压价触发供应商断供或降质，供应商掺假触发永久除名。用"背离当期节省 vs 惩罚期失去的利润流现值"估算门槛；账期越长、专用性越强、替代供应商越少，δ类参数越 favorable，关系越稳；订单频率下降（接单节奏放缓）会悄然击穿门槛——"最后一单"心态是挤兑式的合作解体。
3. **平台与商家关系**：平台抽成与流量分配是阶段博弈，商家多平台经营（多归属）是当期背离选项；平台"封杀/降权"威胁可信性取决于其自身是否受害（子博弈精炼检验）。商家对平台依赖度（单平台GMV占比）决定其δ，平台治理规则（保证金、流量惩罚）决定惩罚强度πc的深度——两者共同决定"商家守规、平台不竭泽而渔"的双边合作区间。
4. **配额联盟与产能纪律（OPEC式）**：超额增产的当期收益πd与被惩罚后回到πc的差距决定稳定性；违反直觉的结论：盯住"谁有动力先超产"（πd−x_i最大者），那是最脆弱的环节；δ不够时靠更严厉可信惩罚（两面战略式：短期剧烈减产+恢复机制）而非口头配额。
5. **大客户依赖与单一供应商风险**：上市公司前五大客户占比高=客户δ高、公司议价弱；反之公司对单一大供应商依赖高=自己的δ被对方拿捏。触发结构的破裂（大客户转单、供应商断供）往往在门槛被击穿后一次性发生，事先可由"关系专用资产+替代选择+订单节奏"三参数预警。

## E 执行步骤

1. **写出阶段博弈与NE收益**：确定阶段博弈G（价格/产量/合作努力），解出阶段NE收益e_i（惩罚基准）。→ *完成标准*：e_i有明确数值或区间，且确认阶段博弈NE（唯一性影响有限重复结论，不影响无限重复）。*判停点*：阶段博弈收益根本写不出（对手目标函数不可知）→ 本卡不适用，改用条件剧本定性表述。
2. **确定目标合作收益x_i与最优偏离d_i**：x_i=合作安排下每期收益；d_i=对手守约时我方单期最优偏离的收益。→ *完成标准*：x_i、d_i（古诺式问题则是πm/2、πd、πc三元组）成列。
3. **计算δ门槛**：套通用式 δ≥max_i(di−xi)/(di−ei)；对称双头可直接用4/(1−δ)≥5+δ/(1−δ)或(πm/2)/(1−δ)≥πd+δπc/(1−δ)形态。→ *完成标准*：门槛数值+每个i的分量分解（找出最脆弱方）。*判停点*：某i的di≤xi→背离无诱惑，该方无条件守约，门槛由其余方决定。
4. **验证子博弈精炼与惩罚设计**：子博弈按历史归两类（合作史/惩罚史）逐类核对；若触发惩罚是"永久回到NE"，对照更严厉可信惩罚（两面战略/最严厉惩罚）检查门槛是否被高估。→ *完成标准*：两类子博弈各一句NE复核；惩罚强度评级（触发式/更严厉）。*判停点*：惩罚均衡帕累托劣于合作均衡、双方可事后重谈（再谈判问题）→ 威胁在事后会被推翻，门槛结论作废或需帕累托边界上的惩罚重算。
5. **现实δ类参数估计并输出判定**：把接单节奏（交易频率/存续概率）、资本雄厚度（熬过惩罚期的现金流）、声誉价值（未来利润流占比）映射到δ，与门槛比较。→ *完成标准*：三档结论（可持续/临界/不可持续）+敏感方向（哪个参数边际变化最危险）+条件式表述。
- **输入输出契约**：输入=阶段博弈结构与收益估计（e_i、x_i、d_i或πm/πc/πd三元组）、重复关系参数（频率、终止概率、耐心代理变量）；中间产物=δ门槛及其分解、子博弈两类验证、惩罚强度评估；输出=合作可持续性三档判定+最脆弱方+参数敏感方向+条件剧本。禁止输出：把δ门槛点估计当精确预测；把"合作不可持续"下在未核惩罚强度之前；对有限重复博弈直接套用无限重复门槛（有限次且阶段NE唯一时合作解体）。

## B 边界

1. **触发战略惩罚并非最严厉可信惩罚：δ门槛被高估（ce13）**：绝大多数博弈中"永久回到阶段NE"不是最严厉的可信惩罚——古诺用触发战略算出δ≥9/17，阿布勒胡萝卜加大棒在δ=1/2即达垄断产量；两种方法仅在ei=ri（如囚徒困境）时等价。下"合作不可维持"结论前，必须先核惩罚强度。
2. **重新谈判瓦解惩罚（ce10）**：靠"转向帕累托劣均衡"支撑的合作经不起事后重谈——惩罚同时惩罚惩罚者，双方有动机改选；子博弈精炼只查"惩罚在子博弈中是否最优"，不查"执行惩罚是否符合双方事后利益"。修复需把惩罚均衡放到阶段NE收益的帕累托边界上，否则门槛计算建立在会被推翻的威胁上。
3. **无名氏定理使均衡极多："可能"易、"哪个实现"难（ce25）**：只要δ足够接近1，优于保留收益的任意可行收益都能被子博弈精炼均衡支撑——本卡证明的是"合作可以是均衡"，不是"合作一定会实现"；均衡选择取决于焦点、惯例与制度，模型本身不回答。
4. **挤提式自实现与低效均衡（ce07/ce08）**：多均衡下恐慌自我实现（条件剧本而非时点预测）；唯一均衡也可以整体低效（关税式囚徒困境）——合作卡输出的一切"均衡"都须翻译成条件式命题再用于投资判断。
5. **作者盲点**：δ被外生给定且现实中难测（只能用频率、终止概率、耐心代理变量间接估计）；假定偏离可被完全观察（不完美监督下的价格战式触发，原书仅以格林-波特一笔带过）；理性与共同知识公理化，1992年成书未纳入有限理性与实验证据；无名氏定理的多重均衡问题只以再精炼部分回应，无一般解。
