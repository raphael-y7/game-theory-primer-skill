# 博弈类型判定与均衡概念选择

## R — 原文依据

前言（全书总纲）："在本书中，我们将讨论四种类型的博弈：完全信息静态博弈、完全信息动态博弈、不完全信息静态博弈、不完全信息动态博弈。"与四种类型相对应的是四个均衡概念：纳什均衡、子博弈精炼纳什均衡、贝叶斯纳什均衡、精炼贝叶斯均衡；并称"这四个均衡概念的条件是逐渐强化的，更为严格的概念的提出是为了弥补条件较弱的均衡概念的不足和漏洞"。四概念分别在1.1.C、2.4.B、3.1.B、4.1节正式定义。

## I — 方法论自述

本卡是全书分析的总入口：任何多方互动，动手建模与求解之前先用两问定位它属于哪个象限，再配对正确的均衡概念。

- **第1问（信息维度）**：是否有参与人不知道另一参与人的收益函数？是→不完全信息。作者的划界口径是**收益函数**是否共同知识，不是行动是否保密（拍卖中每一竞买者都不知道别人愿出多高价，即典型不完全信息）。
- **第2问（时序维度）**：行动有无先后，且后行者能否观察到此前的行动过程？有先后且可观察→动态；否则→静态。"静态"只要求**选择时不知他人选择**，不要求物理上同时。
- **四象限配概念**：完全×静态→纳什均衡（NE）；完全×动态→子博弈精炼纳什均衡（SPNE）；不完全×静态→贝叶斯纳什均衡（BNE）；不完全×动态→精炼贝叶斯均衡（PBE）。
- **递进关系**：四概念逐级强化——NE会容纳不可置信威胁，SPNE在每个子博弈上复查以剔除之；不完全信息使"行动"升格为"类型→战略"的函数（BNE）；PBE进一步把推断（信念）提到与战略同等的地位。
- **退化安全网**：较强概念在简单博弈上自动退化为较弱概念——PBE在完全信息静态下等价于NE、在完全（且完美）信息动态下等价于SPNE、在不完全信息静态下等价于BNE。因此拿不准时选较强概念永远不会误删均衡；强概念的区分力只体现在复杂博弈上。
- 判入象限后分别接：normal-form-modeling / iesda-procedure / nash-equilibrium-solver（完全静态）、backward-induction / subgame-perfection-check（完全动态）、bayesian-nash-solver（不完全静态）、pbe-verification / signaling-equilibrium（不完全动态）。

## A1 — 书中案例

**worked_example 1：古诺双头垄断的归类（1.2.A）**
输入：两企业同时定产，市场出清价P(Q)=a−Q，单位成本c（成本与需求为共同知识）。执行：两问——利润函数人人知道→信息完全；同时选择→静态。结论：完全信息静态象限，用NE求解，得q1*=q2*=(a−c)/3。

**worked_example 2：斯塔克尔贝里变体的归类（2.1.B）**
输入：同一行业改为企业1先选产量、企业2观测后再选。执行：收益仍共同知识、行动有先后且可观察→完全信息动态。结论：换用子博弈精炼，q1*=(a−c)/2、q2*=(a−c)/4。与古诺各(a−c)/3对照说明：时序与可观测性一变，象限、均衡概念与结论全部改变。

**worked_example 3：一级密封拍卖的归类（3.2.B）**
输入：拍卖中每一竞买者都不知其他竞买者愿为拍卖品出多高的价格（前言原例），同时密封出价。执行：估价是私人信息→不完全信息；同时行动→静态。结论：不完全信息静态象限，用BNE；对称线性均衡出价b(v)=v/2。

**worked_example 4：斯彭斯教育信号的归类（4.2.B）**
输入：工人知道自己的能力类型，企业只能观测其教育水平后竞争出工资。执行：能力私人信息→不完全信息；先选教育、后定工资→动态。结论：不完全信息动态象限，必须用PBE（分离/混同/杂合），推断与战略联立求解——判类正确才会引入"信念"这个要素。

## A2 — 触发与投资映射

### 触发场景
- 拿到任一多方互动（行业竞争、谈判、竞拍、公告博弈），需要先决定用哪套均衡工具再动手；
- 读研报或书稿时校验：作者用的均衡概念与其场景的时序、信息结构是否匹配；
- 同一行业出现两种版本（同时定产 vs 先宣布后定产），需要解释为何结论不同；
- 场景中"谁先动、对方看不看得到"存在争议，需要先固定观测结构再选概念。

### 语言信号
- 中文：博弈类型、信息完全/不完全、共同知识、私人信息/类型、同时行动/静态、先后出手/动态/序贯、逆向选择、信号、纳什均衡、子博弈精炼、贝叶斯纳什、精炼贝叶斯。
- 英文：game type / complete vs incomplete information / common knowledge / private information / type；static, simultaneous vs dynamic, sequential / who moves when / observed；Nash equilibrium / subgame-perfect / Bayesian Nash / perfect Bayesian。

### 与相邻能力的区分
- **normal-form-modeling / extensive-form-modeling**：本卡只判类选概念；判定后动手写模型（标准式三要素或扩展式五要素）转那两卡。
- **nash-equilibrium-solver / iesda-procedure**：判入"完全静态"象限后的求解工具；本卡不解均衡。
- **backward-induction / subgame-perfection-check**：判入"完全动态"象限后的工具。
- **bayesian-nash-solver / pbe-verification / signaling-equilibrium**：判入不完全信息两象限后的工具；公告/信号类场景由 signaling-equilibrium 接管。
- **mixed-strategy-reinterp**：NE解出混合均衡后的含义解读归该卡。

### 投资场景映射
1. 两家龙头同时定产定价、成本结构公开可查→完全信息静态→NE（古诺/贝特兰德模板）；
2. 龙头先公告扩产、跟随者观测后定产→完全信息动态→子博弈精炼，先动优势与可信性分析；
3. 土地/资产竞拍、收购竞价（各方估值互为私人信息）→不完全信息静态→BNE（拍卖出价函数）；
4. 回购、增发、股利公告——管理层掌握盈利前景私人信息、市场观测公告后反应→不完全信息动态→信号博弈PBE；
5. 央行/管理层的规则承诺（"维持零通胀""不减持"）→事后有偏离诱惑的完全信息动态→时间一致性与承诺可信度分析（接 commitment-credibility）。

## E — 执行步骤

1. **问信息**：收益函数（而非行动本身）是否所有参与者的共同知识？
   完成标准：一句话写明"谁不知道谁的什么收益/类型"。
   判停点：信息结构无法确认→按不完全信息保守处理，并把该假设写进结论。
2. **问时序**：行动有无先后？后行者能否观察到此前全部行动？
   完成标准：写出行动顺序表与观测结构；核对"静态"口径（选择时互不知情即可，不要求物理同时）。
3. **定位象限、配概念**：信息×时序→四象限之一→对应均衡概念。
   完成标准：输出"本博弈=X信息×Y时序→用Z概念"+一句话理由。
4. **强概念退化复核**：拿不准或场景成分混合时，用较强概念（最高到PBE）复核一遍。
   完成标准：确认强概念退化后不改变（或恰好剔除）弱概念的候选均衡。
   约定：报告以象限对应概念为主结论，强概念复核仅作稳健性注记，不在主结论中堆砌概念名。

输入契约：参与者清单、行动时序、信息结构（谁知道什么）、收益来源。缺时序或信息结构→先问，不猜。
输出契约：类型判定书＝两问答案→象限→均衡概念→理由→（可选）强概念退化注记；不输出均衡本身（那是下游卡的事）。

## B — 边界

1. **ce26 概念与博弈类错配是全套失效之母**：信息判定以收益函数是否共同知识为准（不是行动是否保密）；"静态"只要求选择时不知他人选择。判错象限→概念错配→后续全部结论作废，故本卡前置一切分析。
2. **ce01 不可置信威胁**：把动态博弈错当静态、只用NE，会保留"届时不会执行"的威胁（手雷威胁）；判成动态象限后仍须做可信性检验，NE不是终点。
3. **ce04 多重均衡 / ce07 银行挤提**：判对类也不保证唯一预测——性别战两个纯NE难分优劣，均衡选择无一般答案；银行挤提模型只能断言挤提"可能作为均衡出现"（自我实现的均衡之一），不能预测何时发生。输出应表述为**条件性剧本**而非点预测。
4. 强概念退化的限度：退化关系只保证"不误删"，区分力只在复杂博弈上显现；在简单博弈上坚持用PBE只是增加计算负担，不增加信息。
5. 作者盲点：1992年成书，行为博弈与实验偏离未纳入，理性是公理而非实证结论；金融具体制度（涨跌停、停牌、信息披露规则）不在原书范围，映射到投资场景时须自行补充制度参数。
