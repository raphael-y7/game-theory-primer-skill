## 1. 结构（Structural）

### 类型
方法论教科书：博弈论的标准理论框架 + 每章"理论→应用举例→理论发展→习题→参考文献"的循环结构。

### 一句话主旨
把"多人决策"问题按**信息（完全/不完全）×时序（静态/动态）**切成四类博弈，为每一类给出一个逐级强化、逐步排除不可信行为的均衡概念（纳什均衡→子博弈精炼→贝叶斯纳什→精炼贝叶斯），并用大量经济学应用演示"如何把语言描述的博弈转化为可解模型"。

### 骨架（一级论点及其关系）

1. **第1章 完全信息静态博弈**：标准式表述、重复剔除严格劣战略、纳什均衡（含混合战略与存在性定理）。给出全部后续章节共享的基线工具。
2. **第2章 完全信息动态博弈**：扩展式表述、逆向归纳、子博弈精炼；核心洞见=**可信性**（不可置信威胁必须被剔除）。应用：斯塔克尔贝里、工会工资谈判、序贯谈判、银行挤提、关税、锦标赛、重复博弈（触发战略/无名氏定理逻辑）、效率工资、时间一致性货币政策。
3. **第3章 非完全信息静态博弈**：贝叶斯博弈标准式、贝叶斯纳什均衡；应用：混合战略的再解释、一级密封拍卖、双向拍卖；显示原理作为机制分析的简化杠杆。
4. **第4章 非完全信息动态博弈**：精炼贝叶斯均衡（要求1-4）、信号博弈（分离/混同/杂合）、信号要求5/6等再精炼；应用：就业市场信号（斯彭斯）、公司投资与资本结构（Myers-Majluf）、货币政策、空谈博弈、序贯谈判、有限重复囚徒困境中的声誉。

**论点之间的关系**：递进（均衡概念逐级强化：后一概念在前一博弈类型中退化为前一概念）+ 2×2矩阵式组织（信息×时序），第4章回收前三章全部工具。

### 作者要解决的核心问题
"当几个理性人各自最优地行动且彼此预期对方的行动时，会发生什么？"——并教会读者**建模程序**：把非正式的多方互动描述转化为可分析的正式博弈，再解出并解读其均衡。

## 2. 解释（Interpretive）

### 关键术语（作者本人的用法）

| 术语 | 作者的定义/用法 | 与常识差异 |
|---|---|---|
| 标准式表述 | 参与者、战略空间、收益函数三要素 G={S1,…,Sn; u1,…,un} | 不是"表格"而是三要素组 |
| 严格劣战略 | 存在另一战略在**所有**对手战略组合下收益都更高；理性者绝不采用 | 强调"绝不"的理性公理 |
| 纳什均衡 | 一组战略使无人能独自离弃自己的既选战略（互相最优反应） | "没有人愿意独自偏离"，非"最好结果" |
| 混合战略 | 以概率分布随机选择纯战略；等价解释=对手对己方行动的不确定性（第3章正式化） | 不是"掷骰子的花招"而是信息结构 |
| 扩展式表述 | 行动时序、每次行动者的信息集、收益；博弈树 | 信息集（虚线圈）承载"知道什么" |
| 逆向归纳解 | 从博弈树的末端往前逐级选最优行动 | 只适用于完全且完美信息 |
| 子博弈精炼 | 战略组合在每个子博弈（不止整体）上都是纳什均衡 | 剔除不可置信威胁/承诺 |
| 贝叶斯纳什均衡 | 类型→战略的函数，给定对手类型分布下互为最优反应 | 战略是类型的函数，非单一行动 |
| 精炼贝叶斯均衡 | 战略+推断（信念）互推自洽，且推断在均衡路径上由贝叶斯法则决定（要求1-4） | 均衡=战略与信念的联合体 |
| 触发战略 | 一旦有人偏离便永久转向惩罚（如古诺惩罚产量） | 威胁的可信性由贴现因子门槛决定 |
| 信号要求5/6（直观标准等） | 对均衡路径外信息集的推断施加的进一步约束（劣信号/均衡劣信号应被赋零概率） | 再精炼=对"信念"的经济学约束 |
| 显示原理 | 任何均衡结果都可由一个"直接机制+实话实说"再现 | 把机制搜索空间缩小到直接机制 |

### 核心命题（用自己的话）

1. 理性参与者的互相最优反应构成纳什均衡；均衡是"预期的稳定点"，不是集体最优。
2. 重复剔除严格劣战略依赖"人人理性是共同知识"的逐层假设；其预测力有限（很多博弈剔不出唯一结果）。
3. 动态博弈中，纳什均衡会容纳不可置信的威胁；只有子博弈精炼（每个子博弈上都最优）才符合可信性逻辑（手雷威胁、斯塔克尔贝里）。
4. 重复博弈中，若"未来合作的现值 ≥ 一次性背离收益 + 惩罚的现值损失"，合作可自我维持（弗里德曼1971触发战略条件，δ≥门槛如古诺9/17、囚徒1/4）。
5. 私人信息下的均衡是"类型→战略"的函数；拍卖、双向拍卖等的均衡可由一阶条件解出（如双向拍卖线性均衡 p_b=2/3·v_b+1/12, p_s=2/3·v_s+1/4，交易区间<3/4）。
6. 信息不对称时，无成本（或低成本）的信号只有当不同类型发送它的成本不同时才能分离类型（斯彭斯教育、股利/资本结构信号、货币政策约束）。
7. 精炼贝叶斯均衡把"信念"搬上台面：均衡=战略与推断互相印证；均衡路径外的信念需要信号要求5/6类经济学约束来再精炼。
8. 声誉模型的逻辑：短视类型的存在+足够长的博弈期，可以让理性参与者伪装出合作行为（有限重复囚徒困境、KMRW）。
9. 显示原理：机制设计只需在"直接机制+实话实说"类中寻找均衡。

### 论证链
每章遵循"标准式定义 → 典型2×2例（囚徒困境/性别战/猜硬币）→ 一般定义与求解程序 → 经济应用模型逐个求解 → 习题"。应用不是装饰而是论证的一半：它们演示建模程序（作者前言明言三大理由）。

## 3. 批判（Critical）★（下游能力卡B段来源）

### 作者的时代局限
- 1992年成书：行为博弈、实验经济学（最后通牒/信任博弈的系统偏离）尚未进入教科书主线；书中"理性"是公理而非实证结论。
- 均衡选择问题（多重均衡时选哪个）仅以再精炼部分回应，未给出一般答案。
- 信息经济学应用以1990年前文献为主（信号模型的财务应用如Myers-Majluf 1984、Miller-Rock 1985），此后市场微观结构、高频与算法博弈未覆盖。

### 作者的立场盲点
- 教科书立场：默认模型化是可行的（收益函数可写出）；对"收益函数本身测不准"的现实场景（如投资者面对管理层）着墨少。
- 偏经济学应用，金融具体制度（涨跌停、停牌、信息披露规则）不在讨论范围。

### 未被证明的假设
- 理性是共同知识（重复剔除要求逐层"我知道你知道我知道"）。
- 风险中性（拍卖、锦标赛模型中多假设）。
- 均衡存在≠均衡被实行；推断（信念）在路径外的形成机制靠再精炼约定。
- 贴现因子/监督概率等参数外生给定，现实中难测。

### 最强反对意见
"真实市场参与者有限理性、有限前瞻，教科书均衡预测常被实验与市场异常证伪；且模型多重均衡使'预测'退化为'可能性清单'。"——本书的回应是逐级精炼+应用演示，但并未正面解决均衡选择；使用其结论做投资判断时，应把均衡视为**条件性剧本**而非点预测。
