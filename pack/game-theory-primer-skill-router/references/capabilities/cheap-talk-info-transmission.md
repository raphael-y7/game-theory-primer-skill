# cap.gibbons-game-theory.cheap-talk-info-transmission

## R 原文依据

> "在空谈博弈中，发送者的信号只是口头表态——既不需要成本，亦没有约束作用，也无法查证构成任何义务。"（4.3.A）
> "当参与者之间的偏好排列更为接近时，通过空谈可能达成的交流就更多，但除非参与者偏好的排列是完全一致的，无法达到完美的交流。"（4.3.A）
> "当b≥1/4时，参与者的偏好过于不一致，以致于这种非常有限的交流也无法达成。"（4.3.A）

## I 自述

空谈博弈=无成本、无约束、不可查证的信号博弈：时序与信号博弈相同（自然按p(t_i)赋类型→发送者表态→接收者观测信号选行动→结算），但收益U_S(t_i,a_k)、U_R(t_i,a_k)不含信号——信号只通过改变接收者推断间接影响收益。M=T（"什么都可以说"的模型化；4.4节再精炼处需重新考虑该假定）。PBE定义同信号要求1/2R/2S/3。

**结构事实**：混同均衡恒存在——接收者忽视一切信号、对所有信号维持先验p(t_i)、选先验最优行动a*=argmax_{a_k}Σ_{t_i}p(t_i)U_R(t_i,a_k)⇒有意思的问题只是"是否存在非混同均衡"。

**三必要条件**：①不同类型发送者对接收者行动的偏好不同（否则所有类型涌向同一信号——斯彭斯中所有工人都偏好高工资，空谈必然无效）；②接收者最优行动随类型不同（否则信息无价值）；③接收者所偏好的行动不完全遭到发送者反对（否则发送者系统性误导）。

**两类型两行动分离条件（图4.3.1，发送者收益a_L行x/y、a_H行z/w）**：分离均衡存在当且仅当x≥z且y≤w（每类型说真话不劣于说谎）；两类型偏好相同（x＞z且y＞w）必为混同。

**Crawford-Sobel连续版**：T=A=[0,1]、类型均匀分布、U_R=−(a−t)²、U_S=−[a−(t+b)]²，b＞0衡量偏好分歧。一切PBE等价于n段部分混同：段内同信号、接收者行动=段中点；相邻段长差4b（x_{k+1}−x_k=c+4b）；两段临界类型x_1=1/2−2b、需b＜1/4；n段首段长d满足n·d+n(n−1)·2b=1（4.3.1）；最大段数n*(b)=小于[1+√(1+2/b)]/2的最大整数——b≥1/4⇒n*=1（只剩混同）；b→0⇒n*→∞；一切b＞0下n*有限（除非偏好完全一致，无法完美交流）。

## A1 书中案例

**worked_example：两类型两行动分离条件与Crawford-Sobel分段均衡（4.3.A，图4.3.1/4.3.2）**
图4.3.1收益表（发送者收益,接收者收益）：a_L行(x,1)/(y,0)、a_H行(z,0)/(W,1)（右下角大写W系排印，按修正读法为小写w）。分离战略[m(t_L)=t_L，m(t_H)=t_H]配推断μ(t_L|t_L)=1、μ(t_L|t_H)=0与反应[a(t_L)=a_L，a(t_H)=a_H]，要求每类型说真话不劣于说谎⇔x≥z且y≤w。若x＞z且y＞w（两类型同偏好a_L），都想让接收者相信t=t_L→接收者无法相信任何一方→只剩混同。
Crawford-Sobel两段均衡：[0,x_1)发一种信号、[x_1,1]发另一种；接收者推断段内均匀、行动=段中点x_1/2与(x_1+1)/2。临界类型无差异要求x_1+b=两行动中点⇒x_1=1/2−2b；x_1＞0要求b＜1/4。路径外处理两法：发送者混合战略（各段区间上均匀随机，消除均衡路径外信号）或纯战略（t＜x_1发0、t≥x_1发x_1）+指定路径外信号的推断。n段推广：上段比下段长4b（临界类型无差异递推x_{k+1}−x_k=c+4b）；首段d满足n·d+n(n−1)·2b=1（4.3.1），对n(n−1)·2b＜1的任意n都存在n段均衡；n*(b)=小于[1+√(1+2/b)]/2的最大整数。

## A2 触发与投资映射

### 触发场景
- 管理层路演、业绩说明会、调研纪要里的口头指引，需要判断信息含量。
- 专家访谈/卖方交流中"对方的话值多少"需要折算。
- 要判定一条表态该按"空谈"处理还是按"有承诺成本的信号"处理。

### 语言信号
- 中文："表态""喊话""指引""口径""沟通""利益是否一致""报喜不报忧""说得再多也没用""光说不练""模糊表态"。
- 英文："cheap talk / Crawford-Sobel / babbling equilibrium / partial pooling / partition equilibrium / preference alignment / costless signal"。

### 相邻区分
- 与 signaling-equilibrium：信号有类型依存成本才有分离（斯彭斯教育、回购下限）；空谈无成本，分离只能靠偏好结构（x≥z且y≤w式利益一致）。
- 与 signal-refinement-checklist：M=T（什么都可以说）的假定在4.4需重新考虑——空谈均衡集同样受要求5/6约束。
- 与 repeated-game-cooperation / reputation-mechanism：长期关系中空谈与声誉可互补，但机制分属两卡（信息传递结构vs类型伪装动机）。

### 投资场景映射
1. **路演/调研沟通的信息含量判断（管理层与投资者偏好分歧）**：管理层最优表述总比真实状态乐观一个b（U_S=−[a−(t+b)]²）；b由治理与激励结构决定——股权激励长期绑定、无减持窗口→b小、沟通粒度可细；高位减持动机、市值管理诉求→b大、"指引"只值混同。操作=先估b档位（≈0／＜1/4／≥1/4），再按n*(b)把口头内容折算成"至多n段区间"。
2. **公告空谈vs承诺成本**：无成本表态（意向、展望、"正在评估"）按空谈处理——混同恒存在、零信息含量；一旦表态附带类型依存成本（回购下限金额、锁定期承诺、个人担保），就转入信号博弈分析（成本是否类型依存→能否分离）与再精炼筛选——空谈与信号是同一光谱的两端，判据=收益函数里有没有信号项。
3. **区间化解读而非点估计**：即使偏好接近、确有信息，均衡也只传达段区间+段中点——把"公司预计全年稳增长"读成具体增速点估计是超范围使用；均衡解读是"状态落在某段内"，段宽随b增大而变粗（相邻段长差4b）。
4. **完全利益一致才值得逐字解读**：x≥z且y≤w式的完全一致（如审计师向监管的技术性汇报）才有分离；凡存在"报喜不报忧"的结构性动机（两类都偏好同一好消息，x＞z且y＞w），话术对齐≠信息，混同话术一律按先验定价。
5. **央行/监管表态的粒度（Stein 1989联储例）**："表态能起一定作用、又不能太精确"=n*(b)有限：政策方与市场的分歧b决定表态的可用粒度；"战略模糊"本身是均衡属性而非沟通失职，勿把模糊解读为没有信息。

## E 执行步骤

1. **判定是否空谈**：检查收益函数——信号不出现在U_S、U_R中⇒空谈；出现且类型依存⇒转信号卡。→ *完成标准*：收益结构判定完成。*判停点*：非空谈（有成本信号）→换signaling-equilibrium流程。
2. **过三必要条件**：①类型间偏好差②接收者最优行动随类型变③偏好非完全反向。→ *完成标准*：三条逐条判定有据。*判停点*：任一条不成立⇒只预期混同（babbling均衡），结论到此为止。
3. **估偏好分歧b**：从治理/激励/利益结构估计发送者最优行动对接收者最优行动的系统偏离，给出定性档位（≈0／＜1/4／≥1/4）。→ *完成标准*：档位+依据（合同结构、持股与减持安排、考核方式）成文。
4. **定交流粒度**：b≥1/4⇒只混同；b＜1/4⇒用n*(b)=小于[1+√(1+2/b)]/2的最大整数定最大段数，把可得信息写成"至多n段、每段以段中点为最优解读"；n段存在域n(n−1)·2b＜1。→ *完成标准*：n段区间表。
5. **承诺成本增量检验**：若表态附带可验证成本，标注"升级为信号问题"，转信号卡与再精炼卡。→ *完成标准*：分类结论（空谈/信号）与对应预测。
- **输入输出契约**：输入=类型与行动空间、双方收益函数、偏好分歧b（或定性档位）；中间产物=三必要条件判定表、段结构要素（x_1=1/2−2b、4b递推、4.3.1式）；输出=该沟通渠道的信息含量上限（n段区间/纯混同）、逐字解读禁区标注、是否升级信号分析的结论。

## B 边界

1. **空谈失效区（ce20）**：所有类型对接收者行动偏好相同⇒全部涌向同一信号、分离自毁（只剩混同）；b≥1/4⇒连两段式有限交流都没有。沟通失败先查利益结构，勿归咎"对方不诚实"。
2. **路径外推断自由支撑均衡构造（ce15机制在本节的体现）**：纯战略分段均衡依赖自由指定路径外信号后的推断（Crawford-Sobel原法用混合战略回避之）——同一博弈可有多个合法均衡，"听懂了什么"取决于选中的均衡，单点预测不存在。
3. **三必要条件只是必要**：满足三条不保证高粒度交流——交流程度由偏好一致程度b连续决定，且分段结构限于二次损失、均匀分布设定；非线性损失下段结构会变。
4. **混同恒存在≠混同是唯一预测**：对每个n≤n*(b)都存在部分混同均衡，均衡选择问题书中无一般答案；再精炼（4.4，M=T假定需重新考虑）可能进一步筛选。
5. **作者盲点**：抽象模型刻意脱离应用细节（书中自陈"把应用作为进一步阅读"）——Stein联储表态、Matthews否决权威胁、Austen-Smith立法辩论、Farrell-Gibbons工会沟通都需配套领域模型，不能只靠本卡；M=T是"刚好够用"的建模约定；1992年成书，此后cheap talk文献（多轮对话、认证机制、实验证据）未覆盖。
