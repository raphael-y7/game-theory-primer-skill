# cap.gibbons-game-theory.signaling-equilibrium

## R 原文依据

> "发送者的战略是混同的或分离的，我们就称均衡分别为混同的或分离的。"（4.2.A）
> "斯彭斯的模型中最关键的假定是较低能力的工人发出同样的信号要比较高能力工人花费的成本高。"（4.2.B）
> "正如迈尔斯和迈卢夫所观察的结果，模型表现出的内在机制迫使企业寻求债务融资或寻找内部资金渠道。"（4.2.C）

## I 自述

信号博弈=两参与者的非完全信息动态博弈（4.2.A四步时序）：①自然按p(ti)赋类型；②发送者S观测类型后选信号mj∈M；③接收者R观测信号（不知类型）选行动ak∈A；④按us(ti,mj,ak)、ur(ti,mj,ak)结算。PBE由信号要求1/2R/2S/3定义（要求1-3的翻译：要求1=R对每个信号持推断μ(ti|mj)；2R=R按推断最大化期望效用；2S=每类型S最大化效用；3=路径上信号的后验μ(ti|mj)=p(ti)/Σ_{Tj}p(ti)；要求4对信号博弈无意义）。

**三类均衡判定**：发送者战略m(ti)决定均衡类型——**混同**（不同类型发同一信号⇒路径上推断=先验）；**分离**（不同类型不同信号⇒后验0/1）；**杂合**（一类确定、另一类随机化⇒贝叶斯式(4.2.8)反解混合概率）。求解=四候选枚举（两类型两信号：混同m1、混同m2、两种分离），逐候选"贝叶斯定推断→求R反应→逐类型查偏离动机（计入R对偏离信号的反应）→补路径外推断"。

**分离的技术前提=单交叉**：低能力发同一信号的边际成本更高，ce(L,e)>ce(H,e)（图形=低能力无差异曲线更陡）。分离水平由**低类型IC（不模仿约束）**决定：高类型必须把信号"抬到低类型不愿模仿的无差异点"；因此分离必扭曲——信号水平超过完全信息最优。杂合存在条件w_h<y(H,e_h)（⇔e_h<e_s），此时混合概率π唯一。

参数域以转写稿为准：嫉妒判别式 w*(L)−c[L,e*(L)]＜w*(H)−c[L,e*(H)]（连续能力下必为嫉妒情形）；混同水平存在域 e_p∈(e*(L),e′]。（任务书所列"1<c<2"式成本参数域在转写稿中无对应原文，不采信。）

## A1 书中案例

**worked_example 1：斯彭斯就业市场分离均衡（4.2.B，图4.2.8）**
时序：自然定能力η∈{H,L}（P(H)=q）→工人选教育e≥0→两企业观测e竞争出价→工人接受高者。收益w−c(η,e)、y(η,e)−w。市场工资=期望产出 w(e)=μ(H|e)·y(H,e)+[1−μ(H|e)]·y(L,e)（4.2.1）。嫉妒情形下分离均衡：战略[e(L)=e\*(L), e(H)=e_s]，其中e\*(L)为低能力完全信息最优、e_s=低能力过(e\*(L),w\*(L))的无差异曲线与y(H,e)的交点横坐标（低能力模仿e_s恰无差异；无差异时假定选e\*(L)，或把e_s上移一小量使其严格偏好e\*(L)）。推断μ(H|e<es)=0、μ(H|e≥es)=1；工资w(e)=y(L,e)（e<es）、y(H,e)（e≥es）。均衡多重（ê>es亦可作分离水平），唯一性靠4.4直观标准。

**worked_example 2：Myers-Majluf公司投资与资本结构（4.2.C）**
现存利润π∈{L,H}（H>L>0，P(L)=p）私人信息；项目需投资I、收益R>I(1+r)；企业家出股权份额s。投资者接受条件(4.2.11)：s[qL+(1−q)H+R]≥I(1+r)（q=市场推断π=L概率）；立项约束(4.2.12)：s≤R/(π+R)，π=H时更紧。混同均衡存在条件(4.2.13)：I(1+r)/[pL+(1−p)H+R]≤R/(H+R)——p足够接近0自动成立；p接近1需(4.2.14)（转写稿按图录作R−I(1+r)≥I(1+r)H/R·L，疑脱减号；按(4.2.13)取p→1极限与上下文，修正读法为R−I(1+r)≥I(1+r)H/R−L）。混同不可行时**分离均衡总存在**：低类型s=I(1+r)/(L+R)获融资；高类型要约s<I(1+r)/(H+R)被拒——放弃正NPV项目，投资无效率降低；"对高利润有吸引力的融资条件对低利润更有吸引力"⇒股权无法分离类型⇒内在机制迫使企业转向债务或内部资金。债务延伸：利润确定（L>0）时混同债务D=I(1+r)总被接受；R+L<I(1+r)（L足够负）或期望利润（±K波动）下L−K+R<I(1+r)时低类型违约、债务亦被拒。

**worked_example 3：维克斯货币政策约束信号（4.2.D）**
两阶段货币政策，当局类型c∈{S,W}（S>w>0，强硬/软弱），P(c=W)=p（转写稿"c=S=或W"衍一等号，按修正读法c=S或W）。c型反应函数π₂\*(π₂e,c)=d/(c+d²)·[(1−b)y\*+dπ₂e]。分离均衡：强硬选πS→雇主推断S→二期预期π₂e(0)；软弱选πW→推断W→预期π₂e(1)（一期预期转写稿"1−"后字母形似q，按先验P(c=W)=p与英文原版修正读法为π₁e=pπ_W+(1−p)π_S）。关键检验=伪装约束：软弱类型一期假装强硬可把π₂e(0)压得很低、二期用预料外通胀获利——故πS必须低到软弱类型放弃伪装；对许多参数值这使πS低于强硬类型完全信息下的选择（过度紧缩），与斯彭斯分离均衡中高能力过度投资教育同构。

## A2 触发与投资映射

### 触发场景
- 一条公告/行为被解读为"信号"，要判断它是否真能区分好/坏类型（而非空谈）。
- 要回答"弱公司为什么不模仿？"——模仿成本是什么、够不够高。
- 回购/增持/股利/增发/资本开支公告的效应需要结构化解读而非情绪化归因。

### 语言信号
- 中文："传递信号""市场解读为""表明实力/底气""可信吗""模仿/效仿成本""为什么差公司不敢跟进""过度投入""言行一致"。
- 英文："signaling / separating equilibrium / pooling / costly signal / mimicking cost / single-crossing / adverse selection / incentive compatibility"。

### 相邻区分
- 与 pbe-verification：本卡是PBE在信号博弈的特化求解（四候选枚举+信号要求1/2R/2S/3，要求4无意义）；一般树形动态博弈的"战略+推断"验证用那张卡。
- 与 signal-refinement-checklist：本卡产出均衡清单（常多重：不同e_p、不同es、不同路径外推断）；再精炼卡用信号要求5/6剔除依赖随意路径外推断的均衡（斯彭斯中唯一存活=最低成本分离e_s）。
- 与 cheap-talk-info-transmission：信号无成本即空谈；斯彭斯环境所有类型同偏好高工资→空谈必然混同，分离必须靠类型依存的信号成本。
- 与 revelation-principle：本卡问"信息优势方在给定规则下会自发做什么"；机制卡问"规则本身该怎么设计"。

### 投资场景映射
1. **回购/增持公告是否可信信号**：分离条件=弱公司模仿成本——注销式回购+溢价+长期锁定=真金白银且摊薄未来弹性，弱公司（现金流紧、融资难）模仿代价高；无成本"回购意向/增持计划"接近空谈，均衡只会是混同。检验顺序：先问"弱公司模仿它的成本是什么"，再问"成本是否类型依存（单交叉）"。
2. **股利公告的信号价值**：持续现金股利=对未来现金流的抵押，弱公司模仿须透支项目，模仿成本高→可分离；股利上调首年兑现=分离证据，言而不发或随扩股稀释=混同信号，勿按同一逻辑解读。
3. **增发折价的信息解读**：Myers-Majluf——股权融资要求高利润类型出让更大份额贱卖补贴低利润类型，故绩优公司回避股权、转债务/内部资金是均衡推论；增发公告负收益、折价深=市场推断发行方低类型概率高（q高），是均衡属性而非市场失灵；"低价增发给利益方"另需机制视角审查。
4. **承诺性资本开支**：分离必扭曲——超出当期NPV最优的大额资本开支/超规格产能可能扮演e_s角色；IC检验=弱公司模仿该开支的边际成本是否更高（融资暴露、现金流约束）；"过度"勿直判浪费，先查是否在给低类型抬门槛。
5. **货币政策式约束信号（监管/央行）**："言行一致"地忍受短期损失（紧缩、去杠杆、不救市）以换取强硬类型信誉——过度紧缩是分离成本而非政策失误；解读政策表态时看约束（伪装成本）而非措辞，无约束承诺接近空谈。

## E 执行步骤

1. **五步建模映射**：识别发送者S、接收者R、类型集T与先验p(ti)、信号集M、行动集A，写出双方收益函数。→ *完成标准*：信号要求1/2R/2S/3所需要素全部就位（S在单节信息集行动，R在每个信号对应的信息集行动）。
2. **列候选均衡**：两类型两信号=4个纯战略候选（混同m1、混同m2、分离(t1→m1,t2→m2)、分离(t1→m2,t2→m1)）；连续信号空间=列混同区间与分离对。→ *完成标准*：候选清单无遗漏。
3. **逐候选核验**：贝叶斯定路径上推断（混同→先验；分离→0/1）→求接收者最优反应→逐类型查偏离动机（必须计入接收者对偏离信号的反应）→补路径外推断并验证无偏离。→ *完成标准*：每候选给出"成立（附推断与路径外描述）"或"出局（附偏离类型与收益差）"。*判停点*：全部候选出局→查信号集/收益设定，或考虑杂合均衡。
4. **分离均衡核IC与单交叉**：低类型不模仿条件定分离水平（无差异点=分界信号）；验证信号成本类型依存（ce(L,e)>ce(H,e)型成本反转）。→ *完成标准*：IC不等式+成本反转证据各一条。*判停点*：两类成本无差异（单交叉不成立）→分离不可能，只考虑混同/杂合。
5. **杂合与多重性标注**：杂合用低类型无差异条件（4.2.9式）定工资、贝叶斯式(4.2.8)反解混合概率；列出全部存活均衡各自依赖的路径外推断。→ *完成标准*：均衡清单+每条均衡的路径外推断依赖声明（"待再精炼"标签）。
- **输入输出契约**：输入=信号博弈五要素（S/R/T与先验/M/A及双方收益）；中间产物=候选均衡核验表（推断、反应、偏离检验）、IC不等式、杂合混合概率；输出=均衡集合（混同/分离/杂合及其参数域）、各均衡的信号成本与IC条件、路径外推断依赖清单。

## B 边界

1. **路径外推断的随意性（ce15）**：斯彭斯混同均衡中"e≠ep一律视为低能力"的怪推断未被要求1-4排除（要求4对信号博弈无意义），支撑任意e_p的整族混同均衡——引用"市场会解读为"结论前，先查该解读依赖的路径外推断是否合理。
2. **混同融资无效率（ce21）**：混同权益融资中高利润类型被迫出让更大份额补贴低利润类型，可高到放弃正NPV项目；分离均衡中投资同样无效率降低——"发不出好信号"可能是均衡属性，勿直接读作公司隐瞒或市场失灵；债务/内部资金偏好是机制推论。
3. **分离信号必然扭曲（ce22）**：e_s>e\*(H)、πS低于完全信息水平——分离均衡的信号必须"浪费"到低类型不愿模仿为止；"过度"行为（超规格投入、超紧缩政策）可能是IC必要成本，解读时勿直判非理性或浪费。
4. **均衡多重、点预测消失**：不同e_p/ê的混同、ê>e_s的分离、混同与杂合并存——本卡产出是"均衡清单"而非唯一预测；书中原书均衡选择问题无一般答案，唯一性须靠信号要求5/6再精炼（另一卡），且再精炼依赖函数形式与推断假设。
5. **作者盲点**：两企业对路径外教育水平推断相同是外加假定（保证工资=期望产出对一切e成立）；e解释为"在校表现差异"以绕开中途出价的动态问题（Noldeke-Van Damme 1990：更丰富动态博弈经再精炼后与简单博弈一致）；货币政策模型书中只勾勒框架、均衡多重（细节见Vickers 1986、Barro 1986多阶段声誉模型）；结论限定于产出线性、成本凸、二次损失、风险中性的函数形式，非线性环境（多类型、非凸成本、风险规避）结论不自动平移。
