# cap.gibbons-game-theory.signal-refinement-checklist

## R 原文依据

> "如果存在另外一个信号mj′，使得ti选择mj′的最低可能收益大于ti选择mj的最高可能收益"，则mj为ti的劣信号。（4.4；按修正读法，原书排印定义式两侧均印mj未加撇号）
> "如果mj之后的信息集处于均衡路径之外，且mj为类型ti的均衡劣信号，则（在可能的情况下）接收者的推断μ（ti|mj）中分配给类型ti的概率应该等于0"（4.4，信号要求6/直观标准）
> "满足信号要求6的惟一精炼贝叶斯均衡就是图4.4.4所示的分离均衡。"（4.4）

## I 自述

精炼贝叶斯均衡（要求1-4）只约束均衡路径上的推断；路径外推断近乎自由，是混同/杂合均衡多重性的根源。再精炼（4.4节）=给路径外推断加经济学约束，工具是信号要求5与信号要求6。

**要求5（劣信号赋零概率）**：信号mj对类型ti劣 ⇔ 存在另一信号mj′使 min_{ak∈A}U_s(t_i,mj′,a_k) > max_{ak∈A}U_s(t_i,mj,a_k)（按修正读法；原书排印定义式两侧均印mj未加撇号）。若路径外信号mj对ti劣，则μ(t_i|mj)=0——除非mj对T中所有类型都劣（"在可能的情况下"的限定；图4.4.1中参与者1的收益3换成3/2时M与L皆劣即属此类）。一般版要求5以"始于信息集的严格劣战略"表述，信号版是其特化。

**要求6（直观标准，Cho-Kreps 1987）**：均衡劣信号定义：max_{ak∈A}U_S(t_i,mj,a_k) < U*(t_i)（该候选均衡下ti的均衡收益）。路径外信号若对ti均衡劣，则（可能情况下）μ(t_i|mj)=0。劣信号必为均衡劣信号⇒要求6严格强于要求5、并使其多余；其逻辑=前向归纳（解释背离时考虑"谁这么做对自己有利"）。存在性：Cho-Kreps借Kohlberg-Mertens(1986)证明所有4.2.A型信号博弈都存在满足要求6的PBE；直观标准"绝非可能的最强条件"（更强见Cho-Sobel 1990）。

**使用程序**：对每个候选均衡（重点是混同与杂合）逐个执行：算U*(t_i)→逐路径外信号判定劣性/均衡劣性→把（均衡）劣类型赋零概率→做"表白"检验（若某非劣类型被相信会受益，推断应压向它，与候选不相容即剔除）→汇总存活者。

## A1 书中案例

**worked_example 1：要求5的图4.4.1/图4.4.2演示（4.4）**
图4.4.1：参与者1可选L/M/R，M是严格劣战略（选R得2，超出M可能得到的0和1），故"1−p>0不合理"、p=1被强制——(R,R′,p≤1/2)出局，只剩(L,L′,p=1)。图4.4.2信号博弈：q≥1/2时[(L,L),(u,d),p=0.5,q]是混同PBE；但t1选R的一切战略（(R,L)与(R,R)）都是始于t1信息集的严格劣信号，且存在非劣战略(L,R)可到达同一信息集→要求5限定q=0→该混同均衡不满足要求5。变体检验：若t2选R时接收者选d得1、选u得0（与图中0/1对调），则该混同对任意q都是PBE，[...，q=0]即满足信号要求5——要求5能否杀掉均衡取决于收益细节。

**worked_example 2：啤酒或热狗（Beer & Quiche，4.4图4.4.3）——要求6排除要求5漏掉的均衡**
t1=软弱型（概率0.1）、t2=粗暴型（概率0.9）；信号=早餐（热狗/啤酒），行动=冲突/不冲突；吃自己偏好的早餐得1、避免冲突另加2；接收者与软弱型冲突得1、与粗暴型冲突得−1。[(热狗，热狗)，(不冲突，冲突)，p=0.1，q]对任意q≥1/2是混同PBE，且满足信号要求5（啤酒对两类型都不是劣信号：软弱型热狗最低收益1＜啤酒最高收益2）。但直观标准过不了：(a)软弱型均衡收益3＞啤酒最高收益2，啤酒是其均衡劣信号；(b)粗暴型均衡收益2，若被相信是粗暴型（q＜1/2→不冲突）选啤酒得3＞2——粗暴型可"表白"，推断应为q=0，与混同所需q≥1/2不相容→剔除。（类型/信号/行动换名即Milgrom-Roberts 1982进入壁垒模型。）

**worked_example 3：直观标准筛选斯彭斯均衡（4.4图4.4.4-4.4.7，嫉妒情形）**
论证链：①e＞e_s对低能力是劣信号（即便拿最高工资y(H,e)也不及选e*(L)的效用）→要求5限定μ(H|e)=1（e＞e_s）→ê＞e_s的"过度"分离均衡出局；②于是满足要求5的任何均衡中高能力效用≥y(H,e_s)−c(H,e_s)；③q低（图4.4.5）：工资函数w=q·y(H,e)+(1−q)·y(L,e)在高能力过(e_s,y(H,e_s))的无差异曲线下方→一切混同与杂合不满足要求5，唯一存活即分离均衡；④q高（图4.4.6）：（教育，工资）点落在透镜形阴影内的混同/杂合可满足要求5，但e′至e″之间的教育不是高能力的均衡劣信号（若被相信可得工资y(H,e)、福利高于混同）→要求6强制μ(H|e)=1→混同崩溃出局（图4.4.7）；⑤最终唯一存活=最低成本分离均衡[e(L)=e*(L)，e(H)=e_s]。

## A2 触发与投资映射

### 触发场景
- 研报或公告解读里出现"市场会认为/会被解读为"，需检验该路径外推断是否合乎均衡逻辑。
- 候选均衡清单多重（不同e_p、不同分离水平、混同与杂合并存），需要收敛出条件性剧本主情景。
- 一条表态被质疑"差公司也能说，凭什么信"，需要结构化的可信性检验程序。

### 语言信号
- 中文："再精炼""路径外/均衡外""劣信号""均衡劣信号""直观标准""前向归纳""谁会这么说""他为什么不发更强的信号""表白""喊了没人信"。
- 英文："refinement / off-path (out-of-equilibrium) belief / dominated signal / equilibrium-dominated / Intuitive Criterion (Cho-Kreps) / forward induction / deviator's payoff"。

### 相邻区分
- 与 signaling-equilibrium：那张卡产出均衡清单（常多重：不同e_p、不同ê、混同杂合并存）；本卡是清单之上的第二轮过滤（要求5/6），输出存活者（斯彭斯中唯一存活=最低成本分离e_s）。
- 与 pbe-verification：要求1-4是本卡前置（先有PBE再谈再精炼）；本卡专治要求4"可能情况下"留下的路径外推断自由度。
- 与 cheap-talk-info-transmission：4.3.A的M=T（什么都可以说）假定在4.4需重新考虑——空谈均衡同样受再精炼约束。
- 与 repeated-game-cooperation：那张卡精炼威胁可信性（收益结构），本卡精炼信念合理性（推断结构）。

### 投资场景映射
1. **公告空谈vs承诺成本**：无成本表态（意向、展望、"正在研究"）人人能发，混同恒存在；检验顺序=先问"哪类公司发这话是均衡劣的"——若只有高盈利公司敢承诺（低盈利发同样话会在后续业绩、监管问询中暴露，均衡收益更低），才可把该表态解读为分离信号；纯表态一律先按混同定价。
2. **回购/增持的可信性分档**：意向性回购（无下限、无期限）≈空谈；"回购下限金额+注销+按期完成"对低现金流公司是均衡劣信号（模仿成本使其均衡收益更低）→直观标准支持把推断压向好类型；"意向/下限/注销"的分档本身即再精炼程序的输出。
3. **路演口径的表白检验**：管理层下修指引后称"一次性因素"；用直观标准问：若"一次性论"被相信，哪类管理层受益？若差公司模仿该说法的后续暴露成本高（二次下修、审计问询），则"一次性论"应主要归于好类型；若两类都说同样的话且无从验证，则它不改变推断（仍是空谈）。
4. **混同公告的剔除**：全行业齐发乐观展望=混同均衡；谁先给出可验证的硬约束（回购下限、业绩承诺、担保），直观标准即要求把推断压向谁，齐呼口号者的信号价值归零——"第一个掏真金白银的"拿走分离租金。
5. **增发解读的主情景选择**：Myers-Majluf存在混同/分离多重均衡，依赖路径外推断；用本卡筛选后以"最低成本分离"为主情景（绩优公司回避股权融资、增发折价=低类型推断），把混同解读标为条件性剧本而非唯一预测。

## E 执行步骤

1. **前置核验**：确认候选均衡是满足要求1-4的PBE（战略+推断齐备）。→ *完成标准*：每个候选有完整"战略+推断"描述。
2. **算均衡收益**：对候选均衡逐类型算U*(t_i)。→ *完成标准*：U*(t_i)数值/表达式成表。
3. **要求5检查**：逐个路径外信号判劣性（存在mj′使min_a U_s(t_i,mj′,a)＞max_a U_s(t_i,mj,a)⇒mj对t_i劣）；把劣类型在该信号后的推断赋零；若信号对全部类型都劣，标注"要求5不适用"。→ *完成标准*：每条路径外信息集给出"更新后的推断"或"不适用"标注。*判停点*：候选在要求5即出局→记录出局理由，进入下一候选。
4. **要求6检查（直观标准）**：逐路径外信号找均衡劣类型集合（max_a U_S(t_i,mj,a)＜U*(t_i)）；对非均衡劣类型做表白检验——若接收者把推断全压到该类型，其最优反应是否使该类型收益＞U*(t_i)；是⇒推断应等于该类型⇒与候选所需推断不相容则剔除候选。→ *完成标准*：每候选给出"存活/出局+一句话理由"。*判停点*：全部候选出局→复查U*计算与收益设定（理论上满足要求6的PBE总存在）。
5. **汇总存活者**：输出经再精炼的均衡清单作为条件性剧本主情景，标注各自依赖的函数形式与推断假设。→ *完成标准*：存活清单+敏感性声明（结论是否依赖单交叉、线性产出/凸成本等设定）。
- **输入输出契约**：输入=候选PBE清单（战略+推断）+双方收益函数；中间产物=U*(t_i)表、路径外信号劣性/均衡劣性判定表、表白检验记录；输出=经要求5/6筛选后的均衡集合（通常大幅收敛或唯一）、每条存活均衡的推断依赖声明。

## B 边界

1. **要求5条件过强导致约束过弱（ce17）**：劣性用"始于信息集的严格劣"这一最强劣性条件定义，由此得到的排除力反而弱——图4.4.1中M是严格劣战略，(R,R′,p≤1/2)仍满足要求5存活；"满足要求5"不等于"合乎情理"。
2. **啤酒或热狗（ce16）**：明显不合理的均衡可满足信号要求5（混同均衡中q≥1/2的路径外推断可疑：粗暴型若被相信可从2升到3），必须升级到要求6——再精炼措辞细节（劣/均衡劣、min/max）直接决定取舍，跨书引用精炼结论前先核对定义口径。
3. **均衡劣性依赖候选均衡本身**：U*(t_i)随候选变，同一信号在不同候选下均衡劣性不同；本卡结论是"条件于候选清单的筛选"，不是普适的好/坏信号分级表。
4. **存在性与唯一性不是一回事**：满足要求6的PBE总存在（Kohlberg-Mertens稳定性）但不保证唯一；斯彭斯"唯一存活"依赖嫉妒情形+单交叉+线性产出/凸成本设定。
5. **作者盲点**：均衡选择问题全书无一般答案，再精炼只是部分回应；直观标准"绝非可能的最强条件"（更强的Cho-Sobel 1990、缺陷行动、稳定性未覆盖）；1992年成书，此后精炼文献争论与实验证据（真实路径外推断未必符合理性表白逻辑）不在书中。
