# cap.gibbons-game-theory.backward-induction

## R 原文依据

2.1.A："假定参与者1的这一最优化问题同样有惟一解，表示为a1*，我们称（a1*，R2（a1*））是这一博弈的逆向归纳解。逆向归纳解不含有不可置信的威胁。"同节手雷博弈例：威胁"如果他不付1000美元就引爆手雷……不可置信：如果给参与者2一个机会，让他把威胁付诸实施，参与者2也不会选择去实施它"。

## I 自述

逆向归纳法（backward induction）是完全且完美信息动态博弈的标准求解程序：**从博弈树末端逐级往回选最优**——先解最后行动者在每种前定行动下的最优反应，再把该最优反应代入倒数第二行动者的问题，如此逐级回推到第一阶段，得到的行动组合就是逆向归纳解。

适用条件（三前提，缺一不可）：
1. 行动按顺序发生；
2. 每个参与者在下一步行动前，可以观察到之前的全部行动；
3. 每一可能行动组合下的收益是共同知识。

程序要点：
- 每一步的口径是"**给定后续行动已按最优执行**，本步选什么最优"；
- 每级最优化问题有唯一解时，逆向归纳解唯一；某级出现无差异或多解时，解不唯一，须并列报告；
- 产出是"解"（唯一路径上的行动序列），不等于完整的战略组合（后者是子博弈精炼均衡，见相邻卡）；
- 核心价值：逆向归纳解自动排除不可置信威胁——每个参与者的预测是"对方将来会按自身利益行动"，因此任何"届时会做违背自身利益之事"的威胁都被剔除。

对有限多阶段博弈，从倒数第一阶段开始回推即可；对自相似的无限博弈（如轮流出价谈判），可借"从某阶段起的子博弈与原博弈相同"做截断回推，但那是非正式论证（见B段）。

## A1 书中案例

**worked_example 1：三步博弈的逆向归纳演示（2.1.A，图2.1.1）**
参与者1先选L或R：L使博弈结束，收益(2, 0)；选R则参与者2观测后选L′或R′：L′结束，收益(1, 1)；选R′则参与者1再次行动，选L″（收益3, 0）或R″（收益0, 2）。从第三阶段回推：L″(3)优于R″(0)，故L″最优；第二阶段：2预测到L″使自己得0，故L′(1)优于R′(0)；第一阶段：1预测到L′使自己得1，故L(2)优于R(1)。逆向归纳解=(L, L′)，博弈在第一阶段即结束。原书借此例强调：即使博弈预测在第一阶段结束，论证的关键部分是"若博弈不在这里结束将会怎样"。

**worked_example 2：三阶段序贯谈判（2.1.D）**
参与人1、2就一美元分配轮流出价，贴现因子δ（0<δ<1），若拖到第三阶段按外生解(s, 1−s)分配。逆向求解：
- 第二阶段：2出价s2，1接受当且仅当s2≥δs（下期所得s本期只值δs；无差异时假定接受）。2比较本阶段成交所得1−δ·s与拒绝后下期所得贴现δ(1−s)，后者更小，故s2*=δ·s，1接受。
- 第一阶段：2接受当且仅当1−s1≥δ(1−s2*)，即s1≤1−δ(1−δs)。1比较本阶段所得1−δ(1−δs)与拒绝后所得贴现δ·s2*=δ²s，前者更大，故s1*=1−δ(1−δs)。
- 均衡：1首期提出(s1*, 1−s1*)，2立即接受，无拖延。
先动者优势：无限期版（Shaked-Sutton截断法）解出唯一s*=1/(1+δ)——δ<1时先出价者份额严格过半，后出价者只得δ/(1+δ)；δ→1时份额趋对半，越没耐心先动优势越大。

**worked_example 3：斯塔克尔贝里双头垄断（2.1.B）**
时序：企业1选产量q1，企业2观测后选q2；P=a−Q，边际成本c。追随者反应函数R2(q1)=(a−q1−c)/2；领导者代入得q1*=(a−c)/2，q2*=(a−c)/4。对比古诺（同时行动）均衡各(a−c)/3：斯塔克尔贝里总产量3(a−c)/4＞2(a−c)/3，价格更低、总利润更低。但企业1本可选(a−c)/3保证古诺利润却另选了q1*，故其利润必高于古诺；总利润下降⇒企业2必恶化——这就是先动优势的定量形态。

## A2 触发与投资映射

### 触发场景
- 互动有明确先后顺序，且后行动方能观察到先行动方的选择；
- 需要判断某方放出的"威胁/承诺"到期是否真会执行；
- 需要判断"先出招"与"后出招"哪个占优、首期出价应开在什么水平。

### 语言信号
- 中文："他敢……我就……""到时候他别无选择""先发制人""我们先报价/先出牌""话放这儿了""拖下去对谁都不利"。
- 英文："threat / follow through on the threat / call the bluff"；"when push comes to shove, they will have no choice but to…"；"first mover / move first / pre-empt"；"open the bidding / opening offer / take-it-or-leave-it offer"；"they would never carry it out"。

### 相邻区分
- 与 **subgame-perfection-check** 卡：逆向归纳处理"完全且完美信息"（每步行动可见）；一旦出现同时行动阶段（非单节信息集），需改用子博弈精炼的跳越法，不属本卡。
- 与 **commitment-credibility** 卡：本卡给出斯塔克尔贝里的求解与先动优势数值；该卡进一步处理承诺装置（改变收益结构使威胁变可信）与时间一致性。
- 与 **repeated-game-cooperation** 卡：本卡是一次性有限时序的"倒推"；该卡是无限/长期关系中"未来惩罚支撑当下合作"的正推门槛（δ≥…），方向相反。
- 与 **game-type-classifier** 卡：动手回推之前，先用该卡确认博弈类型确为"完全信息×动态"象限。

### 投资场景映射
1. **要约收购两阶段出价**：收购方先报价、目标方董事会回应、潜在竞争方决定是否跟进竞价。从末端（各方可接受的底线价）回推，反推首报价的均衡水平；报价过低则预测对方按自身利益行动（拒绝或引入竞争者）。
2. **大股东增持承诺的可信性**："股价低于X元将视情况继续增持"——站在大股东立场解到期节点：若届时增持成本高于其宣称收益、且不执行无制度性代价，该承诺是逆向归纳会剔除的不可置信威胁；只有附带上限金额锁定、过户安排等改变末端收益的装置才可信。
3. **行业产能扩张的先动者**：龙头先宣布扩产、跟随者观测后定产量的斯塔克尔贝里结构：先动者份额优势（q1*=2倍于q2*），但行业总产量高于古诺、价格更低，后动者利润必受损——判断"扩产军备赛"对二线厂商的伤害先于对龙头。
4. **并购/债务重组的轮流出价谈判**：δ<1时先出价者份额过半（1/(1+δ)），且谈判每拖一期全体所得按δ贴水——僵局越长，先动优势与折价幅度越大；观测到"宁愿拖延"的行为本身在传递贴现因子或外生替代方案信息。
5. **双方对峙的"手雷结构"**：交易对手宣称"不成就要鱼死网破"（同归于尽威胁）——在末端节点检验该行动对其自身是否最优；不是则视为空言，不必为其改变自己的出价。

## E 执行步骤

1. **画树/确认结构**：写明行动顺序、每步行动者、可行行动集、终点收益。
   完成标准：每个终点节有全部参与者的收益值。
   判停点：画不出时序或某方行动集——退回扩展式建模卡（extensive-form-modeling）。
2. **检查三前提**：(i)顺序行动 (ii)行动前之前行动可观察 (iii)收益共同知识。
   完成标准：三条全部满足并逐条标注依据。
   判停点：任一条不满足→停用本卡；(i)(ii)不满足转子博弈精炼（2.2节跳越法），(iii)不满足转第3/4章贝叶斯工具（BNE/PBE）。
3. **末端最优化**：对最后行动者，就每个前定行动解 max，得最优反应R(·)。
   完成标准：每个前定行动下都有明确的最优行动（并列时全部列出）。
4. **逐级回推**：把下一级最优反应代入上一级目标函数再最优化，直至第一阶段。
   完成标准：得到完整的逆向归纳解路径及各方所得；每级最优化有唯一解（否则报告全部并列解，不强行单选）。
5. **副产品输出**：列出被剔除的不可置信威胁（树上存在、但不在解路径上且违背威胁者自身利益的行动）。

**输入输出契约**：输入=时序描述+各步行动集+收益（或参数化模型a、c、δ、s等）；输出=逆向归纳解（各阶段行动组合+各方收益）+先动/后动所得比较+不可置信威胁清单+三前提核查记录。

## B 边界

1. **逆向归纳仅适用完美信息，不完美信息需PBE**（ce01 的延伸+原文2.4节）：手雷博弈（ce01）显示纳什均衡可包含不可置信威胁，逆向归纳的价值是剔除它们——但前提是每个信息集单节。出现同时行动（如图2.4.3囚徒困境的跨节信息集）时不能逐节机械倒推，须改用子博弈精炼跳越法；若还需约束路径外信念，则转入第4章精炼贝叶斯均衡（PBE不能沿树倒推，需"战略+推断"枚举-验证，见pbe-verification卡）。
2. **ce02 信息暴露受损（斯塔克尔贝里的观测性前提）**：先动优势依赖企业2能观测到q1。若2观测不到q1，修改后序贯博弈的唯一纳什均衡退化为古诺(a−c)/3——q1*=(a−c)/2不可信，因为企业1对q2=(a−c)/4的真实最优反应是3(a−c)/8。投资含义：先查"行动是否可被观测/验证"（公告、披露、过户记录），再谈先动优势；不可观测的"先动"没有承诺价值。
3. **理性前提的脆弱性（fb02/ce18同族警告）**：观察到偏离逆向归纳路径的行动，不能直接判定对方非理性——可能是"对方理性"非共同知识（我等他犯错）、也可能是对方伪装非理性（诱我偏离）。仅当"偏离者确实非理性"最合理时，逆向归纳才失去大部分预测力。
4. **无限博弈的非正式性**：逆向归纳解对无限期博弈未正式定义，Shaked-Sutton截断法依赖"子博弈与原博弈自相似"结构，非自相似的无限博弈不适用。
5. **作者盲点**：成书于1992年，理性是公理而非实证结论——最后通牒/信任博弈实验对逆向归纳预测存在系统性偏离；δ、s等参数外生给定、现实中难测。用本卡得到的均衡应视为**条件性剧本**（在收益结构与理性假设成立时的推演），而非点预测。
