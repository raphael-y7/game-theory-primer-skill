# cap.gibbons-game-theory.revelation-principle

## R 原文依据

> "定理（显示原理） 任何贝叶斯博弈的任何贝叶斯纳什均衡，都可以重新表示为一个激励相容的直接机制。"（3.3）
> "这种类型的博弈（即每一参与者惟一的行动就是宣布自己所属类型的静态贝叶斯博弈）称为直接机制（direct mechanism）。"（3.3）
> "他们还证明所有激励相容的直接机制都不能达到交易当且仅当有效率时肯定发生的概率为1。"（3.3）

## I 自述

显示原理（revelation principle，贝叶斯博弈条件下由迈尔森1979提出，3.3）是一条"搜索空间压缩"定理：任何贝叶斯博弈的任何贝叶斯纳什均衡（BNE），都可以重新表示为一个激励相容的直接机制中的实话实说均衡。"直接机制"=每个参与者唯一的行动是宣布自己的类型τi的静态贝叶斯博弈；"激励相容（IC）"=实话实说（声明τi=真实类型ti）构成BNE；"重新表示"=对每一类型组合，新均衡下的行动和收益与旧均衡完全相同。

建模程序（把原博弈均衡战略复制进直接机制）：给定原博弈G={A;T;p;u}与BNE s*。直接机制与G有**相同的类型空间与推断**，行动空间改为Ti（声明τi）；结果函数=把声明组合τ代入原均衡战略，得s\*(τ)=(s1\*(τ1),…,sn\*(τn))，按此指定各方行动并按原博弈结算。直观表述是"合同—声明—代算—指定"四步：先签约授权设计者代为行动，再各自声明类型，设计者把声明代入s\*算出该类型均衡行动，最后指定执行。

证明要点：声明ti就等于从Ai中选择了行动si\*(ti)；若他人都实话实说，他人等于执行了均衡战略的其余部分，于是i的最优行动恰为si\*(ti)——最优声明=真实类型，实话实说成均衡。

用途=双重简化：①机制搜索空间缩小到直接机制类；②在其中只需找激励相容者，再配参与约束（每类型均衡期望收益≥拒绝参加的外部收益）。经典应用：Myerson(1981)收益最大化拍卖；Myerson-Satterthwaite(1983)双边贸易不可能性。它只压缩搜索空间、不改均衡结果集。

## A1 书中案例

**worked_example 1：直接机制的构造与实话实说均衡证明（3.3）**
给定任意贝叶斯博弈G与其BNE s\*。构造直接机制：类型空间T、推断p不变；行动空间=T（声明τi）；收益按"声明τ→执行s\*(τ)→原博弈结算"产生。验证IC：参与者i声明ti时，等于选择了行动si\*(ti)；若其他参与者都实话实说，他们等于选择了(s1\*,…,s\*(i−1),s\*(i+1),…,sn\*)；已证明此时i的最优行动为si\*(ti)，故i的最优声明=ti。对Ti中每种ti成立，实话实说构成BNE——原均衡被完整"搬进"直接机制。

**worked_example 2：拍卖机制设计的搜索压缩（3.3，接3.2.B）**
投标方估价相互独立且为各自私人信息时，Myerson(1981)计算出了什么样的直接机制有实话实说的均衡、以及哪一个均衡使卖方期望收益最大。显示原理保证没有另外的拍卖机制能带来更高期望收益：那样的机制若有更好的均衡，该均衡已被重新表示为某个IC直接机制中的实话实说均衡，而所有这样的直接机制已考虑在内。Myerson同时证明3.2.B拍卖的对称BNE就相当于收益最大化实话实说均衡。

**worked_example 3：Myerson-Satterthwaite双边贸易不可能性（3.3，接3.2.C）**
把买卖双方一切交易可能性包装为直接机制：双方同时声明τb、τs，买方支付x(τb,τs)（可正可负），以概率q(τb,τs)成交。加上参与约束——每类型均衡期望收益不低于拒绝参加的收益（拒绝时双方每类型收益均为0）。迈尔森和萨特思韦特证明：所有IC且满足参与约束的直接机制都不能实现"当且仅当有效率（vb≥vs）时交易"概率为1；显示原理再保证不存在任何双方乐于参加的讨价还价博弈能做到。对照3.2.C双向拍卖线性均衡 pb=2vb/3+1/12、ps=2vs/3+1/4，仅vb>vs+1/4成交——交易不足是一切机制的普遍性质。

## A2 触发与投资映射

### 触发场景
- 要设计或评估一条"规则/制度"：招标、询价发行、大宗转让、对赌条款——核心问题是"这条规则下人们会如实申报吗"。
- 面对拍卖/竞价/询报价制度（定增询价、土地拍卖、网下配售、司法拍卖），要判断报价行为的动机结构。
- 想论证"任何规则都做不到X"这类普遍性结论（不只是"这个机制做不到"）。

### 语言信号
- 中文："机制设计""说真话/如实申报""激励相容""愿意参加/参与约束""有没有办法设计规则让他自己暴露类型""规则会被钻空子吗"。
- 英文："revelation principle / direct mechanism / incentive compatible (IC) / participation constraint / truthful reporting / mechanism design"。

### 相邻区分
- 与 bayesian-nash-solver：后者在**给定**博弈中求均衡；本卡把"一切机制"压缩到"直接机制+实话实说"类再搜索，是设计/评估视角（评估既有规则=把它当机制求IC）。
- 与 double-auction-linear-eq：双向拍卖是一个**具体**机制；M-S定理用显示原理证明"交易不足"是一切双方自愿机制的普遍性质，而非双向拍卖的特有缺陷。
- 与 signaling-equilibrium / signal-refinement-checklist：信号博弈问"信息优势方在规则外生给定时会自发传递什么"；本卡问"规则本身该怎么设计、如实申报何时成为均衡"。
- 与 commitment-credibility：承诺卡处理"行动时序与可信性"；本卡处理"申报与结果的映射规则"，IC不等式是其判据而非威胁可信性。

### 投资场景映射
1. **定增/配股询价发行**：机构报价=声明估值类型。IC检验——底价、价格优先与配售规则、保证金约束是否让"报真实估值"成为均衡；报价系统性压价更可能是机制属性（信息租金）而非单纯操纵，据此判断询价区间的信息含量。
2. **大宗交易与询价转让折价**：折价=买方索取的逆向选择补偿与信息租金；用M-S逻辑校准"折价多深才合理"——要求"有效率才成交"本身不现实，漏掉部分有价值交易是结构性代价。
3. **业绩对赌与回购承诺条款**：对赌=直接机制，管理层"如实报告业绩类型"是否IC取决于补偿支付的刻度（线性分成 vs 一次性罚金）；条款留有说谎净收益时，谎报就是均衡——先算IC再信条款。
4. **网下打新与新股定价**：Myerson最优拍卖视角——保留价与数量分配规则直接改变报价的真实性；"总有机构报高价抬价"可能是机制均衡属性，评估新股定价效率时先审机制再指控行为。
5. **可转债下修条款博弈**：下修=公司向市场声明"股价类型差"；投资者接受回售/转股条款的参与约束与公司说真话的IC共同决定博弈终局，条款设计的松紧即机制参数。

## E 执行步骤

1. **明确机制三要素**：谁申报什么（声明空间）、结果如何定（分配/支付/成交概率函数）、拒绝参加的外部选择（参与约束基准）。→ *完成标准*：声明空间、结果函数、外部收益三件套各写一句。*判停点*：问题只是"给定博弈怎么解"（机制外生固定、不评估规则本身）→ 停止，转贝叶斯纳什求解卡，本卡无用武之地。
2. **列类型空间与先验**，写出每类型在"如实申报"与"伪报各类型"下的收益对照。→ *完成标准*：每类型一张"申报×结果"收益对照表。
3. **逐类型核IC**：他人实话实说时，真申报收益≥一切伪报收益。→ *完成标准*：每类型一个不等式结论。*判停点*：存在类型伪报严格更优→如实申报不是均衡，结论改写为"该规则下会系统性谎报+谎报方向"，不得硬说机制有效。
4. **核参与约束**：每类型均衡期望收益≥拒绝参加的外部收益。→ *完成标准*：每类型一个参与不等式；不满足者会拒绝进入（弃拍、弃购、触发回售/违约），机制在现实中空转。
5. **按适用域下结论**：正面结论=该机制内均衡；否定性结论（"任何机制都做不到X"）必须经显示原理推广——先确认已把一切可能性包装为IC直接机制（如M-S的做法）。→ *完成标准*：结论句注明"在激励相容+参与约束的直接机制类内"或"由显示原理推广到一切机制"。
- **输入输出契约**：输入=机制描述（申报什么、结果怎么定）、类型空间与先验、收益函数、外部选择；中间产物=IC不等式组+参与约束不等式组；输出=机制可行性判定（如实申报是否均衡）、谎报方向、或基于显示原理的普遍性结论。

## B 边界

1. **M-S交易不足是结构性结论（ce14）**：不存在"当且仅当有效率才交易"的双方自愿机制；做市/询报价里"漏掉有价值交易、纳入无价值交易"不是机制设计失败，而是私人信息下隐瞒估价的均衡代价——改善须补贴或改变信息结构，勿归咎于某个具体规则。
2. **显示原理只压缩搜索空间、不改均衡结果集（fa16边界）**：它不能把坏均衡变好、也不能在多重均衡中挑选；机制设计找到的仍是均衡集合，"存在IC机制"不等于"会被实行"。
3. **依赖可写出的收益函数与共同先验**：IC与参与约束每一项都需要收益刻度；收益测不准（如管理层真实效用、机构客户压力）时只能做定性方向判断，结论降级为"谎报方向"而非数值判定。
4. **静态版限定**：原书自认向动态贝叶斯博弈的扩展"十分简单"但需另行表述；多轮报价、可撤单、动态披露等机制勿直接套用本卡静态程序。
5. **作者盲点**：拍卖分析假定风险中性、估价相互独立——共同价值、风险规避、预算约束与合谋不在覆盖范围；1992年成书，金融制度细节（涨跌停、停牌、信披规则）不在讨论范围；均衡存在≠均衡被实行，用"IC机制"做投资判断时应视为条件性剧本而非点预测。
