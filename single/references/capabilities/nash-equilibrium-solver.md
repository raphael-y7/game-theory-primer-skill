# 纳什均衡求解程序（连续一阶条件法＋离散划线法＋混合无差异法）

## R — 原文依据

1.1.C（NE式与协议推论）："如果参与者之间要商定一个协议决定博弈如何进行，那么一个有效的协议中的战略组合必须是纳什均衡的战略组合，否则，至少有一个参与人会不遵守该协议。" 1.3.B（纳什定理）："在n个参与者的标准式博弈G={S1，…，Sn；u1，…，un}中，如果n是有限的，且对每个i，Si是有限的，则博弈存在至少一个纳什均衡，均衡可能包含混合战略。"

## I — 方法论自述

纳什均衡（NE）是"互为最优反应"的战略组合：(NE)式要求对每个i、∀si∈Si，ui(s1*,…,si*,…,sn*)≥ui(s1*,…,si,…,sn*)（弱不等式≥，等价于si*是给定他人均衡战略下自己收益最大化问题的解）。求解按博弈形态分三路：

- **连续型（产量/价格类，1.2.A/1.2.B）一阶条件法**：写收益函数→对己方选择变量求一阶条件→得最优反应函数→联立。古诺：P(Q)=a−Q、Ci=ciqi（c＜a）、πi=qi[a−(qi+qj)−c]，最优反应Ri(qj)=(a−qj−c)/2，联立得q1*=q2*=(a−c)/3。贝特兰德（差异化产品）：qi(pi,pj)=a−pi+b·pj（b＞0），最优反应pi*=(a+bpj*+c)/2，对称均衡p1*=p2*=(a+c)/(2−b)。
- **离散两人有限博弈（1.1.C）划线法**：对对方每一纯战略找己方最优反应并划线，双向划线的单元格=纯NE。可能无纯NE（猜硬币）也可能多个（性别战两个）。
- **混合战略无差异法（1.3.B）**：无差异/支撑原则——混合战略是对手混合战略的最优反应⇔支撑集中每个纯战略单独使用的期望收益并列最大。求混合均衡＝令对手在你支撑集上无差异，解出**你的**概率由**对手的收益**决定。基准值：猜硬币均衡(1/2,1/2)；性别战帕特(q,1−q)=(1/3,2/3)、克里斯(r,1−r)=(2/3,1/3)，各方以2/3概率选自己偏好的结果。
- **存在性（1.3.B）**：纳什定理保证有限博弈至少一个NE（可能混合）；两人各两纯战略的博弈最优反应对应必有交点，结果三类：唯一纯NE／唯一混合NE／两纯+一混合（脚注15：x=z或y=w时还可能出现两纯无混合及连续统均衡）。
- **与IESDS的关系**：NE是比重复剔除严格劣战略更强的解概念——剔剩唯一组合必是唯一NE，但留存组合不必是均衡；一般NE（纯+混合）＝最优反应对应的交点（古诺图1.2.1与猜硬币图1.3.6同构）。
- **多均衡时**：本卡只交付均衡清单，不回答"落在哪个"（均衡选择未决，见B段）。

## A1 — 书中案例

**worked_example 1：古诺双头垄断一阶条件法（1.2.A）**
输入：P(Q)=a−Q（Q≥a时P=0）、Ci=ciqi、c＜a、两企业同时选产量。执行：πi=qi[a−(qi+qj)−c]对qi求FOC得Ri(qj)=(a−qj−c)/2（边界：qj≥a−c时由P=0知最优反应为0）；联立两条反应函数得q1*=q2*=(a−c)/3。校验：垄断产量qm=(a−c)/2、垄断利润(a−c)²/4，古诺总产量更高、价格更低；"合计垄断产量"协议非NE——若对方产qm/2=(a−c)/4，己方最优反应R((a−c)/4)=3(a−c)/8＞(a−c)/4，有偏离动机。结论：(a−c)/3是唯一NE，三种解法（代数联立/图形交点/重复剔除）殊途同归。

**worked_example 2：贝特兰德差异化产品求解（1.2.B）**
输入：qi(pi,pj)=a−pi+b·pj（b＞0，替代品）、无固定成本、mc=c＜a、同时选价。执行：πi=[a−pi+bpj][pi−c]，FOC得pi*=(a+bpj*+c)/2；对称联立解p1*=p2*=(a+c)/(2−b)。口径：古诺/贝特兰德均衡之称只指博弈不同（战略空间、收益、行为不同），均衡概念同为NE；同质特例（习题1.7）均衡价p*=c。结论：战略变量从产量换为价格，求解程序不变。

**worked_example 3：划线法求纯NE（1.1.C）**
输入：图1.1.4矩阵——上(0,4)(4,0)(5,3)、中(4,0)(0,4)(5,3)、下(3,5)(3,5)(6,6)。执行：对列参与者每一纯战略找行参与者最优反应划线（如列选左时行的最优是中，4＞3＞0），对称处理列参与者。结论：仅（下，右）双划线——唯一纯NE；同法得囚徒困境(招认,招认)、图1.1.1(上,中)。注意图1.1.4中没有任何战略被IESDS剔除，划线法却给出唯一解——NE更强。

**worked_example 4：猜硬币的混合均衡（1.3.B）**
输入：±1收益的猜硬币博弈，无纯NE。执行：参与者1推断2以概率q出正面，则1出正面期望收益q(−1)+(1−q)·1=1−2q、出背面q·1+(1−q)(−1)=2q−1；q＜1/2时1的最优反应是正面、q＞1/2时是背面、q=1/2时任意r都是最优反应（最优反应对应r*(q)含整段竖线）。对称作q*(r)，两对应交点＝混合NE：若i的战略是(1/2,1/2)，j的最优反应也是(1/2,1/2)。结论：无差异条件q(−1)+(1−q)(1)=q(1)+(1−q)(−1)⇒q=1/2。

**worked_example 5：性别战的三重均衡（1.3.B）**
输入：收益(歌剧,歌剧)=(2,1)、(拳击,拳击)=(1,2)、错开=(0,0)。执行：两纯NE（歌剧，歌剧）（拳击，拳击）先由划线法得；混合侧——克里斯选歌剧期望2q、选拳击期望1−q，无差异2q=1−q⇒q=1/3；帕特选歌剧期望r、选拳击期望2(1−r)，无差异r=2(1−r)⇒r=2/3。结论：混合NE＝帕特(q,1−q)=(1/3,2/3)、克里斯(r,1−r)=(2/3,1/3)，各方以2/3概率打自己偏好的结果；共三均衡（脚注5：混合均衡收益对称但无效率，"违背了协议的原则"）。

## A2 — 触发与投资映射

### 触发场景
- 两个（或n个）主体同时选择连续变量（产量、价格、报价、仓位），需求/收益可写成参数式，问"双方都满意、谁也不愿单方面改变"的稳定点在哪；
- 拿到两人有限互动的收益矩阵，要预测结果或检验某协议/公告能否自我维持；
- 划线法找不到双划线格（无纯NE），怀疑结果本质是随机化、需转混合求解；
- 需要为下游分析提供基准值（如触发战略门槛δ计算需要阶段博弈均衡收益e_i）。

### 语言信号
- 中文：纳什均衡、最优反应、反应函数、一阶条件、无差异、划线、混合战略、概率分布、存在性、稳定点、谁也不愿单方面偏离、协议会不会被破坏。
- 英文：Nash equilibrium / best response / reaction function / first-order condition / indifference / mixed strategy / underline method / support / existence (Nash theorem) / no one wants to deviate unilaterally。

### 与相邻能力的区分
- **iesda-procedure**：剔除是预清理与特例快捷方式（剔剩唯一=唯一NE）；剔剩多个或剔不动时转本卡。本卡交付完整均衡清单。
- **mixed-strategy-reinterp**：本卡算出混合概率数字；"概率意味着什么、对手行为如何解读"归该卡。
- **game-type-classifier**：本卡默认完全信息静态；动态博弈的NE会容纳不可信威胁→subgame-perfection-check；不完全信息→bayesian-nash-solver。
- **repeated-game-cooperation**：阶段博弈NE（如古诺(a−c)/3、利润(a−c)²/9）是该卡触发战略门槛δ≥9/17中惩罚收益e_i的输入；长期关系中协议可由未来惩罚支撑，勿用一次性NE直接判"合作必崩"。
- **commitment-credibility**：先动优势与承诺分析在动态框架（斯塔克尔贝里q1*=(a−c)/2），静态NE只作对照基准。

### 投资场景映射
1. **机构调仓前的多空博弈推演**：把多空双方选择（加仓/持有/减仓）写成2×2收益矩阵（收益用相对基准超额收益近似），划线找纯NE——稳定点是"谁都不可通过单独行动获利"的持仓结构；非NE位置的仓位注定被单方面偏离，公告口径的"共识"若不在均衡清单中即不可信。
2. **跟风盘与主力的混合战略**：主力（拉抬/出货）对散户（追入/回避）常是猜硬币式严格对抗，划线无双划线格→均衡为混合型：均衡中主力行为不可预测；可由收益结构（拉升成本、出货折价）反推主力"拉抬"的均衡概率，作为事件研究的事前基准（解读见mixed-strategy-reinterp卡）。
3. **竞拍/打新出价**：一级密封拍卖是对手估价为私人信息的静态博弈，对称均衡b(v)=(n−1)/n·vi（两人情形b(v)=v/2，见bayesian-nash-solver卡）——求解入口即本卡的均衡程序；出价=对自身估价按(n−1)/n打折，n越大折扣越深。
4. **寡头行业产量/价格基准**：两巨头产能与定价竞争用古诺q*=(a−c)/3、贝特兰德p*=(a+c)/(2−b)作锚：当前行业产量/价格离均衡多远、朝哪个方向收敛；异成本推广qi*=(a−2ci+cj)/3（习题1.6）用于成本领先者份额推演。
5. **"联合减产/保价"公告稳定性检验**：用(NE)式查单方偏离动机——如两家各产qm/2=(a−c)/4的配额协议，偏离者最优3(a−c)/8＞(a−c)/4，一次性博弈中必被背叛；只有当重复博弈惩罚现值足够（δ≥9/17，转repeated-game-cooperation卡）协议才自我维持。

## E — 执行步骤

1. **确认输入G**：三要素齐备（参与者/战略空间/收益函数），连续型记下参数范围（c＜a、b＞0且b＜2等）。
   完成标准：收益函数或完整矩阵在手。
   判停点：缺收益或战略空间不明→退回normal-form-modeling卡。
2. **离散两人博弈先划线**：对每一对手纯战略找己方最优反应划线，双向划线格=纯NE。
   完成标准：每行每列均划过一遍；列出全部双划线格。
   判停点：有双划线格→仍须继续步骤4检查是否有混合均衡共存（性别战型：两纯+一混合）；全无→跳至步骤4。
3. **连续型走一阶条件法**：写收益→FOC→最优反应函数→联立。
   约定：FOC只是必要条件——须核对边界（古诺qj≥a−c时最优反应为0；贝特兰德pi≥0）与目标函数凹性；闭式解依赖线性需求+常数边际成本，换设定须重推。
   完成标准：解代回两条反应函数自洽。
4. **混合无差异法**：设对手混合(q,1−q)，令己方支撑集内各纯战略期望收益相等解出q；对称解己方概率。
   约定：概率用分数（1/2、1/3、2/3）不做小数舍入；关键口径——你的混合概率由**对手的**无差异条件决定，勿用己方收益解自己的概率。
   完成标准：概率代回后双方在支撑集上期望收益并列最大。
5. **存在性与完备性检查**：有限博弈→纳什定理保证至少一个NE（可能混合）；2×2对照三类结果（唯一纯/唯一混合/两纯+一混合；脚注15补充：x=z或y=w时可能出现两纯无混合或连续统）；无限战略空间（古诺/贝特兰德类）定理不适用，靠构造自洽。
   完成标准：均衡清单无遗漏（纯+混合全部在列）。
   判停点：怀疑有均衡漏解→回步骤2-4按最优反应对应交点法重查（任何NE都是交点）。
6. **输出与偏离检验**：列均衡清单+各自收益组合；对每个候选协议/预测用(NE)式检验单方偏离动机。
   约定：不在均衡清单中的协议/预测一律标注"至少一方有动机偏离"。

输入契约：G三要素+收益数字或参数式（含参数适用范围）。
输出契约：全部NE清单（纯+混合，概率用分数）+每项偏离验证+多重均衡时显式标注"均衡选择未决"。

## B — 边界

1. **ce05 纳什定理充分非必要**："第1.2节应用举例所分析的博弈却不在此列（因为每一参与者的战略空间都是无限的）"——古诺/贝特兰德的存在性靠构造而非定理；把"有限博弈必有均衡"当普适保证，套到连续变量模型上会失据。
2. **ce24 混合层漏检**：只在纯战略层做检验会漏——图1.3.1中B不被T、M任一纯战略严格占优，却被"T、M各1/2"以期望收益3/2＞1严格占优；求解与占优检验都必须在混合层完整执行，否则均衡清单不完整。
3. **ce04 多重均衡与无效率混合均衡**：性别战两个纯NE难分优劣，第三个混合均衡虽对称却无效率、"违背了协议的原则"——本卡只交付稳定点清单，均衡选择（落哪个点）无一般答案，需外加机制（焦点、沟通、再精炼）。
4. **ce08 唯一均衡可低效**：囚徒困境唯一NE(招认,招认)是集体次优（关税博弈2.2.C同构）——均衡≠好结果；禁止把"解出了均衡"读成"结果是有效率的"。
5. **作者盲点**：理性是公理而非实证结论（1992年成书，行为/实验对均衡的系统性偏离未纳入）；均衡存在≠均衡被实行；一次性NE逻辑直接套长期关系会漏掉重复博弈的惩罚支撑——长期互动先转repeated-game-cooperation查δ门槛。
