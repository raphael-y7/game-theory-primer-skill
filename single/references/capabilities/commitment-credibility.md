# cap.gibbons-game-theory.commitment-credibility

## R 原文依据

> "在单人决策理论中，占有更多的信息决不会对决策制定者带来不利，然而在博弈论中，了解更多的信息（或更为精确地说，是让其他参加者知道一个人掌握更多的信息）却可以让一个参与者受损。"（2.1.B）

> "在这一子博弈精炼解中，货币当局被预测到要实施通货膨胀，并且事实上也是如此，但如果它能承诺不实行通货膨胀政策就可提高其福利水平。"（2.3.E）

> "通过对（2.3.9）的简化可得δ≥c/（2c+d²）。参数c和d都起到两方面的效果……因而贴现因子的临界值也必须支持这一均衡：c/（2c+d²）随d的增大而递减，随c而递增。"（2.3.E）

## I 自述

承诺/威胁的可信性分析回答：一个事先宣布的行动（产量、零通胀、收购价、回购），因为"先说出去"而改变对手预期之后，事后还愿不愿做？判定逻辑全部来自子博弈精炼——把宣布放到博弈树的先手节点，解出无承诺时的均衡作基准，再解承诺不可撤回时的均衡，对比两者。

**无承诺基准（斯塔克尔贝里结构）**：企业1先公开选产量q1，企业2观测后反应R2(q1)=(a−q1−c)/2；领导者代入得q1\*=(a−c)/2、q2\*=(a−c)/4，领导者利润高于古诺（各(a−c)/3）。先动优势的成立依赖两件事：行动**可观察**且承诺**不可撤回**——若企业2事前观测不到q1，企业1选斯塔克尔贝里产量反而会被"占便宜"（它对(a−c)/4的最优反应是3(a−c)/8），唯一均衡退回古诺。承诺的价值=信息暴露的价值。

**时间一致性（货币政策，巴罗-戈登1983）**：雇主先定通胀预期πe，货币当局观测后选真实通胀π。阶段博弈的子博弈精炼解是πe=πs=d(1−b)y\*/c——预期被理性证实，通胀照样发生；当局"每一步都最优"合计却劣于承诺零通胀的情形（时间不一致）。承诺本身在单期内不可信：预期一旦形成，制造意外通胀的诱惑无法自除。

**重复博弈中的修复**：把关系嵌入无限重复（背离则永久回到阶段解πs），零通胀规则可成为子博弈精炼均衡，条件是(2.3.9)式⇒**δ≥c/(2c+d²)**。承诺可信度=参数条件：门槛随d（意外通胀对产出的作用）增大而递减、随c（通胀痛苦度）增大而递增。规则vs相机抉择之争由此定量化：没有足够耐心的当局（δ低），宣布的零通胀规则只是不可置信威胁。

## A1 书中案例

**worked_example 1：斯塔克尔贝里先动优势与承诺价值（2.1.B）**
P=a−Q、边际成本c。时序：企业1选q1，企业2观测q1后选q2。
- 追随者：max q2[a−q1−q2−c] ⇒ R2(q1)=(a−q1−c)/2。
- 领导者代入：max q1·(a−q1−c)/2 ⇒ **q1\*=(a−c)/2，q2\*=(a−c)/4**，总产量3(a−c)/4＞古诺2(a−c)/3。
- 先动优势论证：企业1本可选古诺产量(a−c)/3保住古诺利润却另选，故π1(斯塔克尔贝里)＞π1(古诺)；价格下降使总利润变小，企业2必然恶化——"让对手知道自己知道"反而使对手受损。
- 承诺不可撤回性检验：若q1事后可无声调整，企业1会改选对(a−c)/4的最优反应3(a−c)/8，企业2便不会相信(a−c)/2；若q1事前观测不到，唯一NE退回古诺各(a−c)/3——先动优势要求"行动可观察+不可反悔"两个条件同时成立。

**worked_example 2：货币政策时间一致性（2.3.E，巴罗-戈登1983）**
当局收益W(π,πe)=−cπ²−[(b−1)y\*+d(π−πe)]²，b<1（市场垄断力量使自然产出低于有效水平），d>0（意外通胀经实际工资提升产出）。
- 阶段博弈：对给定πe解得 π\*(πe)=d[(1−b)y\*+dπe]/(c+d²)（式2.3.8）；雇主预测到π\*(πe)并令πe使π\*=πe ⇒ **πe=πs=d(1−b)y\*/c**——理性预期被证实，通胀照样发生。
- 承诺情形：若当局能承诺且雇主持理性预期，π=0最优，W(0,0)=−(b−1)²y\*²＞W(πs,πs)——相机抉择的子博弈精炼解严格劣于承诺解。
- 无限重复修复：雇主按历史调整预期（守规则则πe=0，背离则永久πe=πs），当局按同样触发规则选π。守零通胀与诱惑π\*(0)比较得(2.3.9)：W(0,0)/(1−δ)≥W(π\*(0),0)+δW(πs,πs)/(1−δ)，简化得 **δ≥c/(2c+d²)**；临界值随d递减、随c递增（两方向作用叠加后，d、c各自的后一效果——πs随d增、随c降——占优）。

## A2 触发与投资映射

### 触发场景
- 一方先"宣布"（目标、承诺、底线、计划），需要判断宣布本身是否改变对手行为、事后是否会兑现。
- 评估"规则"（纪律、指引、章程、政策目标）与"相机抉择"（视情况而定）哪一种可信。
- 先手公告的价值评估：它锁定的是什么，靠什么机制锁住（真金白银、声誉、制度）。

### 语言信号
- 中文："他说话算数吗""这个承诺靠不靠得住""规则还是灵活处理""先亮底牌""嘴上说……真到了那一步还会做吗""时间不一致""规则可信度"。
- 英文："credible commitment"、"time consistency"、"rule vs discretion"、"tie one's hands / burn the bridges"、"announce but renege"、"promise is costly to keep"。

### 相邻区分
- 与 subgame-perfection-check：本卡不重复完整判定程序，聚焦"承诺/先动如何改变均衡"这一专题；判定手雷威胁时用那张卡的E段。
- 与 repeated-game-cooperation：时间一致性的修复机制就是那张卡的触发战略门槛δ；本卡给出(2.3.9)⇒δ≥c/(2c+d²)这一特例，通用门槛计算在合作卡。
- 与 signaling-equilibrium：承诺若无成本，可信性只能靠重复关系与δ；若有成本且不同类型成本不同，则转为信号模型（第4章分离均衡），本卡不处理类型分离。
- 与 backward-induction：斯塔克尔贝里的求解机械（反应函数代入）在逆向归纳卡；本卡取其"先动+承诺"的经济含义（信息暴露、先动优势的条件）。

### 投资场景映射
1. **央行/货币当局承诺可信度**：通胀目标、汇率先问可信性参数——当局耐心δ（任期、连任激励、声誉存量）、意外刺激的诱惑结构（类d：刺激对增长/就业的短期作用）与通胀痛苦度（类c：约束硬度、法律独立性）。δ≥c/(2c+d²)式条件不满足时，"坚决零通胀"表态按不可置信威胁处理，市场按相机抉择解（通胀照来）定价。
2. **管理层业绩承诺与回购公告**：单期口头承诺是时间不一致的——预期形成后"放鸽子"对管理层常是最优。可撤回的承诺打折；只有嵌入重复关系（再融资需求、监管记录、大股东质押压力）或不可撤回形式（注销式回购、真金白银增持）时才按承诺解定价。
3. **龙头资本开支承诺与威慑**：龙头企业宣布"产能扩张不可撤回"打击进入者/压制同行——先查两条件：开工（可观察、可验证）与沉没（不可撤回）。只签意向、无资本开支落地的扩产宣言是可反悔的空承诺，威慑力按古诺退化解估值。
4. **规则vs相机抉择的制度评估**：补贴退坡时间表、减持新规、退市制度——规则的价值在于把当局的"事后灵活性"锁掉，从而稳定预期；规则中保留大量裁量权条款（"视情况而定"）的，按阶段博弈解（预期被证实但结果次优）而非承诺解建模。
5. **并购交易中的先手报价**：首个要约价的承诺价值=让对方按它形成预期；若报价可无声撤回（无分手费、无监管锁定），对手按"可能撤回"反应，先手优势消失——分手费/锁定安排正是买断"反悔选项"的价格。

## E 执行步骤

1. **画出承诺问题的时序**：谁先宣布、对手如何形成预期、宣布者何时行动、行动是否可观察。→ *完成标准*：时序四要素（宣布/预期/行动/可观察性）各有一句事实依据。*判停点*：行动不可观察且不可验证→无承诺均衡，先动优势与宣布一并作废（斯塔克尔贝里退古诺）。
2. **解无承诺基准**：按子博弈精炼解阶段博弈（先解后手最优反应，再解先手）。→ *完成标准*：得到基准解（如πs=d(1−b)y\*/c或古诺(a−c)/3），并明确其"预期被证实"性质。
3. **解承诺不可撤回情形**：把宣布作为约束放入先手问题，重新求解。→ *完成标准*：两个均衡并列，福利/利润差异量化或定性给出。*判停点*：承诺情形收益不优于无承诺→承诺无价值（罕见），停止。
4. **检验承诺的执行结构**：逐项核对锁定机制——沉没成本、第三方执行、声誉/重复关系、不可撤回形式。→ *完成标准*：每个宣称的承诺标注锁定机制或标注"无锁定=不可置信"。*判停点*：全无锁定且无重复关系→按不可置信威胁处理，转回第2步基准解作预测。
5. **若靠重复关系支撑，算δ门槛**：识别δ类参数（耐心、声誉价值、关系存续概率）并对照门槛（如δ≥c/(2c+d²)）。→ *完成标准*：给出"可信/不可信/临界"三档结论与参数敏感方向（本例：随d递减、随c递增）。
- **输入输出契约**：输入=宣布内容、时序、当局/宣布者的目标函数与约束、重复关系参数；中间产物=无承诺基准解、承诺解、锁定机制清单、δ门槛；输出=承诺可信性三档判定+参数敏感方向+定价含义（承诺解/相机抉择解/条件可信）。禁止输出：无锁定机制的口头承诺按承诺解定价；把δ当成可精确点估计的量。

## B 边界

1. **不可置信威胁被NE容忍（ce01，手雷博弈）**：纳什均衡不检验威胁在到达时是否仍最优，"不付1000美元就引爆手雷"被静态NE容纳；承诺分析若不做子博弈精炼检验，会把空口威胁当有效承诺。本卡的每一步对比都必须建立在SPNE之上。
2. **时间不一致：相机抉择下通胀偏差、承诺反而更优（ce11）**：理性预期下每期通胀πs>0，当局福利低于承诺零通胀——"每一步都最优"合计更差；且修复依赖δ≥c/(2c+d²)的参数条件，δ不足时任何宣布都不构成承诺。勿把"当局承诺了"直接当"通胀会低"。
3. **先动优势依赖行动可观察（ce02）**：若q1事前不可观测，唯一NE退回古诺——先手承诺的全部价值以对手**看得见、信得过**为前提；评估公告类承诺先查可观察性与可验证性，再谈先动优势。
4. **精炼不解决效率，且承诺不能凭空变出（ce09）**：里昂惕夫工会谈判中子博弈精炼解(w\*,L\*(w\*))本身低效率——可信性分析给出的是"给定制度与收益结构下的均衡"，不承诺双赢；改变结果要改收益结构或博弈规则，而非要求参与者"守约"。
5. **作者盲点**：贴现因子δ与参数c、d被外生给定且假定可测，现实中"当局耐心"极难量化，δ门槛只能做方向性判断；模型未涵盖1992年后央行制度演进（通胀目标制、前瞻指引、独立性与问责机制）；把承诺技术简化为"收益结构改变"，未处理承诺成本本身的定价；理性共同知识假设同样适用于雇主与当局。
