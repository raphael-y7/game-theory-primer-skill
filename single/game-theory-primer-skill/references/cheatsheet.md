# 决策规则速查 — 博弈论基础（A Primer in Game Theory）

| 能力 | 一句话规则 |
|---|---|
| 博弈类型判定与均衡概念选择 | 用"收益是否共同知识×行动有无先后且可观察"两问定位2×2象限，为四类博弈配对四个逐级强化的均衡概念（NE/SPNE/BNE/PBE），强概念在简单博弈中退化为弱概念。 |
| 标准式建模三要素 | 把语言描述的互动转成标准式G={S1,…,Sn;u1,…,un}：参与者/战略空间/收益三问四步，附双变量矩阵画法与T＞R＞P＞S困境判别。 |
| 重复剔除严格劣战略程序 | 按(DS)式逐轮剔除严格劣战略缩小博弈，附逐层"理性是共同知识"假设与"剔剩唯一即唯一NE、留存不必均衡"的边界。 |
| 纳什均衡求解程序（一阶条件法＋划线法＋混合无差异法） | 按博弈形态三路求解纳什均衡——连续型最优反应函数联立（古诺q*=(a-c)/3、贝特兰德p*=(a+c)/(2-b)）、离散型划线法、混合型无差异法（猜硬币1/2、性别战1/3与2/3），纳什定理兜底存在性。 |
| 混合战略的正确解读：对手的不确定性与净化 | 混合战略纳什均衡的正确含义是"我对你行动的不确定性"而非对手掷骰子——豪尔绍尼净化将其正式化为对私人信息的不确定性，均衡概率由对手收益决定且随机化不可预测。 |
| 逆向归纳法：完全且完美信息动态博弈的回推求解 | 从博弈树末端逐级回推选最优（每级要求唯一解），自动剔除不可置信威胁；仅适用完全且完美信息；三阶段序贯谈判s1*=1-δ(1-δs)、斯塔克尔贝里先动优势q1*=(a-c)/2、q2*=(a-c)/4。 |
| 扩展式表述与博弈树建模：五要素、信息集与时序互动 | 用五要素（参与人/何时行动/行动空间/信息集/收益）把时序互动画成博弈树；信息集承载"知道什么"，完美信息⇔所有信息集单节。 |
| 子博弈精炼纳什均衡判定与不可置信威胁排除 | 按三条件列子博弈、逐子博弈检验NE并剔除不可置信威胁，两阶段博弈用"先解后段NE再替入前段"的逆向求解程序得SPNE。 |
| 承诺与威胁的可信性分析（先动优势与时间一致性） | 对比无承诺基准解与承诺不可撤回解，检验先动优势的可观察性与锁定机制；时间一致性问题用触发战略门槛δ≥c/(2c+d²)定量化（通胀偏差πs=d(1−b)y*/c）。 |
| 重复博弈合作可持续性判定（触发战略与贴现因子门槛） | 用"合作现值≥背离收益+惩罚现值损失"算触发战略门槛（囚徒δ≥1/4、古诺δ≥9/17、通用式δ≥max(di−xi)/(di−ei)），无名氏定理说明可实现收益集合随δ扩大。 |
| 激励结构两类模板：锦标赛与效率工资 | 努力不可观测时按相对排名付薪（锦标赛：(wH−wL)∫f²dε=g′(e*)，最优奖金差=1/∫f²dε=2σ√π）或按高工资+解雇威胁付薪（效率工资：升水=(1−δ)e/[δ(1−p)]）。 |
| 贝叶斯博弈标准式与贝叶斯纳什均衡求解程序 | 把"谁知道什么"包装为类型空间与贝叶斯推断，战略=类型→行动的函数，逐类型一阶条件联立求解BNE（非对称古诺+一级密封拍卖双算例，n人出价b(v)=(n−1)v/n）。 |
| 双向拍卖线性均衡与交易损失模板 | 双边私人信息同时报价、中间价成交的双向拍卖线性均衡pb(vb)=2/3·vb+1/12、ps(vs)=2/3·vs+1/4，当且仅当vb−vs>1/4成交——交易区间小于有效区间即交易损失，且M-S证明无"有效率才成交"的机制。 |
| 显示原理与直接机制搜索压缩 | 任何贝叶斯博弈的任何BNE都可重新表示为"报类型+实话实说"的激励相容直接机制，机制评估只需在IC类中搜索并配参与约束。 |
| 精炼贝叶斯均衡验证程序（要求1-4逐条） | PBE=满足要求1-4的"战略+推断"联合体——每信息集有推断、给定推断序贯理性、路径上推断由贝叶斯法则×均衡战略决定、路径外推断在可能情况下与之一致。 |
| 信号博弈三类均衡判定与四应用（分离/混同/杂合） | 信号博弈按发送者战略分混同/分离/杂合三类PBE（信号要求1/2R/2S/3），分离的可行性由类型依存信号成本（单交叉）与低类型IC决定，分离必扭曲。 |
| 均衡路径外推断的再精炼检查单（信号要求5/6与直观标准） | 对每个候选混同/杂合均衡逐个执行"劣信号赋零概率（要求5）→均衡劣信号赋零概率与表白检验（要求6直观标准）"，剔除依赖不合情理路径外推断的均衡后汇总存活者。 |
| KMRW声誉机制（有限重复博弈中的伪装合作） | 行参与者以概率p只能选投桃报李、1−p为理性型；偏离即暴露使理性类型有动机伪装合作，(4.3.2)-(4.3.4)成立时有限重复囚徒困境存在合作至T−2期的均衡，且坦白上限与T无关。 |
| 空谈博弈的信息传递条件（Crawford-Sobel分段交流） | 无成本信号博弈中混同均衡恒存在，信息能否传递由偏好分歧b决定——分离需利益完全一致（x≥z且y≤w），连续版均衡等价于n段部分混同，n*(b)=[1+√(1+2/b)]/2取整、b≥1/4时只剩混同。 |
