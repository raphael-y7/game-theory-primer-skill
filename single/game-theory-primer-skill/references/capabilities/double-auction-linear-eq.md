# cap.gibbons-game-theory.double-auction-linear-eq

## R 原文依据

> "卖方确定一个卖价p_s，买方同时给出一个买价p_b。如果p_b≥p_s，则交易以p=（p_b+p_s）/2的价格进行，如果p_b＜p_s，则不发生交易。"（3.2.C）

> "合并（3.2.7）和（3.2.8）的条件可知，在线性均衡中，当且仅当v_b＞v_s+（1/4）时才会有交易发生。"（3.2.C）

> "单一价格均衡漏过了一些有价值的交易……而且还包含了一些几乎没有什么价值的交易。"（3.2.C）

> "不存在这样的贝叶斯纳什均衡：交易当且仅当有效率时将会发生（即当且仅当v_b≥v_s时）。"（3.2.C，迈尔森-萨特思韦特1983）

## I 自述

双向拍卖=**双边私人信息下的同时报价交易机制**（查特吉-萨缪尔森1983）：买方估值v_b、卖方估值v_s均为私人信息、独立U[0,1]；同时报价，p_b≥p_s则以中间价(p_b+p_s)/2成交。战略=类型→价格的函数p_b(v_b)、p_s(v_s)；BNE条件（3.2.3）（3.2.4）中都含**条件期望成交价**E[p_s(v_s)|p_b≥p_s(v_s)]——报价不仅决定能否成交，还通过"对方接受"这一事实泄露对方类型信息。

**均衡谱系**：此博弈"有非常多的贝叶斯纳什均衡"。①**单一价格均衡族**：任取门槛x∈[0,1]，买方v_b≥x出x否则出0、卖方v_s≤x要x否则要1——任一方只能在"以x成交"与"不成交"间选择，互为最优反应；交易区域为矩形，价格恒为x。②**线性均衡**：猜p_s(v_s)=a_s+c_s·v_s（不限制战略空间）⇒卖价在[a_s,a_s+c_s]上均匀⇒(3.2.3)化简，FOC得p_b=(2/3)v_b+(1/3)a_s（3.2.5）；对称地p_s=(2/3)v_s+(1/3)(a_b+c_b)（3.2.6）；系数匹配c_b=c_s=2/3、a_b=a_s/3、a_s=(a_b+c_b)/3⇒**p_b(v_b)=(2/3)v_b+1/12（3.2.7）、p_s(v_s)=(2/3)v_s+1/4（3.2.8）**。

**交易判据与效率**：交易当且仅当p_b＞p_s⇔**v_b−v_s＞1/4**（v_s＞3/4或v_b＜1/4必不成交）——线性均衡交易区间**小于**有效区间（v_b≥v_s），1/4门槛即交易损失：双方为保信息租金各自压价/抬价。对比：单一价格均衡既漏掉高价值交易（v_s=0、v_b=x−ε）又纳入几无价值交易（v_s=x−ε、v_b=x+ε）；线性均衡漏掉全部价值低于1/4的交易、保留高价值交易，期望获益更高。**迈尔森-萨特思韦特(1983)**：均匀分布下线性均衡期望获益高于其他一切BNE（含但不只单一价格均衡）；且不存在"交易当且仅当有效率（v_b≥v_s）"的双方乐于参加的博弈——支撑重叠（ys＞xb且yb＞xs）时普遍成立；霍尔-拉齐尔版：不存在"当且仅当雇佣有效率（m≥v）"才达成雇佣的博弈。

## A1 书中案例

**worked_example 1：单一价格均衡族与效率缺陷（3.2.C，图3.2.1）**
对[0,1]上任意x：买方v_b≥x则出价x、否则出0；卖方v_s≤x则要价x、否则要1。给定对手战略，己方只在"以x成交"与"不成交"间选择：v_s＜x时成交优于不成交（买方对称），故构成BNE。交易区域=v_s≤x且v_b≥x的矩形（图3.2.1），价格恒为x。效率缺陷：对角线上方阴影三角形（v_b≥v_s却未交易）显示漏掉有价值交易（v_s=0、v_b=x−ε），同时纳入几无价值交易（v_s=x−ε、v_b=x+ε）——两头的错误并存。

**worked_example 2：线性均衡推导与交易损失（3.2.C，式3.2.5—3.2.8，图3.2.2/3.2.3）**
- 设p_s(v_s)=a_s+c_s·v_s⇒p_s~U[a_s,a_s+c_s]，买方问题（3.2.3）化为max_{p_b}[v_b−½{p_b+(a_s+p_b)/2}]·(p_b−a_s)/c_s，FOC⇒p_b=(2/3)v_b+(1/3)a_s（3.2.5）——对手线性则自己最优反应也线性。
- 对称地（3.2.4）化为max_{p_s}[½{p_s+(p_s+a_b+c_b)/2}−v_s]·(a_b+c_b−p_s)/c_b，FOC⇒p_s=(2/3)v_s+(1/3)(a_b+c_b)（3.2.6）。
- 系数匹配：由（3.2.5）c_b=2/3、a_b=a_s/3，由（3.2.6）c_s=2/3、a_s=(a_b+c_b)/3，解出a_b=1/12、a_s=1/4，即**p_b(v_b)=(2/3)v_b+1/12、p_s(v_s)=(2/3)v_s+1/4**（图3.2.2两条平行上升直线）。
- 交易门槛：p_b＞p_s⇔v_b＞v_s+1/4（图3.2.3）；印证：v_s＞3/4时卖价超过买方最高可能出价p_b(1)=3/4；v_b＜1/4时买价低于卖方最低可能要价p_s(0)=1/4。
- 对比与极限：线性均衡保留价值≥1/4的交易、漏掉低价值交易，期望获益优于单一价格均衡；M-S进一步证明它优于**其他一切**BNE，且"有效才成交"的机制不存在；霍尔-拉齐尔雇佣版（m≥v）同构。

## A2 触发与投资映射

### 触发场景
- 买卖双方各有私人估值/底价的议价场景：大宗交易与协议转让、定增询价、做市双边报价、并购换股谈判。
- 观察到"互利区间明明存在却不成交"，需要判断是信息摩擦还是另有隐情。
- 评估交易机制/撮合规则（固定价 vs 随估值伸缩的报价规则）的效率差异。

### 语言信号
- 中文："买卖双方都藏着底价""报价留有余地""这个价他不会卖""明明划算为什么不成交""成交价泄露信息""中间价成交""价差/点差""询价区间"。
- 英文："double auction"、"bid-ask spread"、"bid/ask quote"、"bilateral trade"、"Myerson-Satterthwaite"、"no-trade"、"price discovery"、"quote function"、"interim efficiency"。

### 相邻区分
- 与 bayesian-nash-solver：那卡是通用求解程序（类型→战略、FOC联立）；本卡是双边私人信息交易的具体机制模板+结构性效率结论（交易不足），推导只是该程序的一次应用。
- 与 revelation-principle：M-S"不存在有效率即成交的机制"的普遍性靠显示原理证明；本卡给具体机制的均衡，那卡解释为何结论能推广到一切双方自愿机制。
- 与 signaling-equilibrium：双向拍卖是同时报价、无序贯沟通，类型信息被动地藏在成交条件里；信号卡处理知情方**主动**设计信号传递类型（第4章）。
- 与 incentive-schemes：霍尔-拉齐尔雇佣谈判（交易机制）与效率工资（激励威胁）是两类不同"雇佣摩擦"，勿混用。

### 投资场景映射
1. **做市报价**：做市商双边报价是双向拍卖的机构化版本——1/4门槛映射为**最小价差/交易门槛**：对手估值差小于价差时不成交是均衡性质而非报价失误；报价函数随估值伸缩（2/3斜率+截距）提示：可存活的报价规则须随条件估值调整，死报价（单一价格式）两头吃亏——既漏真单又接毒单。
2. **大宗交易/协议转让议价**：买卖双方对公司估值都含私人信息时，"互利区间"（v_b＞v_s）内仍可能不成交——v_b−v_s≤1/4门槛的小剩余交易被均衡放弃。把大宗"折价成交"读作卖方信息劣势的定价；把"该成未成"先归因结构性交易损失，再谈内幕消息。
3. **定增/询价的双边定价**：发行方（卖方）与询价对象（买方）互有私人信息，中间价成交规则下双方都留信息租金：报价折算=2/3×条件估值+截距，两截距差（1/4−1/12=1/6）就是双方保留余地的度量——询价区间越宽，信息不对称越重。
4. **并购/雇佣谈判（霍尔-拉齐尔）**：不存在"当且仅当有效率才成交"的双方自愿机制——"战略互补却谈崩"的并购、"岗位匹配却没谈拢"的人才，可先于阴谋论解释为机制性交易损失；评估谈判时先算"剩余是否越过门槛"，再判断破裂的信息含义。
5. **交易损失与机制评估基准**：线性均衡在一切BNE中期望获益最高但仍漏掉价值低于1/4的交易——改善只能靠**补贴或改变信息结构**（M-S框架下双方自愿前提不可越过）；评估交易所/监管新规"促成交"的承诺时以此为基准线，勿信"换个价格规则就让所有互利交易成交"的说法。

## E 执行步骤

1. **确认机制结构**：是否双边私人信息？同时报价？成交规则（中间价/替代规则）？估值分布？→ *完成标准*：机制四要素（战略、信息、成交规则、分布）各一句。*判停点*：估值共同可知（无双边私人信息）→退化为普通讨价还价，本卡不适用。
2. **写BNE条件**：双方报价max问题（含条件期望成交价E[·|成交]与成交概率）。→ *完成标准*：两式齐备且条件期望方向正确（买方条件在p_b≥p_s上取）。
3. **猜线性并求最优反应**：对手线性⇒己方所见报价截断均匀⇒FOC得线性最优反应；系数匹配定截距。→ *完成标准*：p_b(v_b)、p_s(v_s)闭式，斜率截距代回互验。*判停点*：分布非均匀→线性均衡一般不存在，转一般方法或只做定性。
4. **推交易门槛并与有效区间比较**：把p_b＞p_s化为类型条件（v_b−v_s＞1/4）；对照交易区间与有效区间（图3.2.1↔图3.2.3）。→ *完成标准*：门槛数值+交易损失区间表述。
5. **效率定位与输出**：对照单一价格均衡与M-S极限，给出"该机制期望获益的位置+不可消除的损失下界"。→ *完成标准*：结论含条件式限定（分布、机制、双方自愿参加）。
- **输入输出契约**：输入=交易双方信息结构（各知道什么）、成交规则（中间价或替代规则）、估值分布参数；中间产物=两个含条件期望的max问题、线性报价函数、类型空间交易门槛；输出=报价规则、成交门槛、交易损失（机制剩余vs有效剩余）、与单一价格/效率基准的比较及条件限定。禁止输出：把1/4门槛当普适常数（随分布与机制变化）；把"交易不足"归咎当事人非理性；宣称存在"有效率即成交"的双方自愿机制改造方案。

## B 边界

1. **交易不足是结构性而非机制缺陷（ce14）**：M-S定理：支撑重叠+双方自愿参加⇒不存在"当且仅当有效率（v_b≥v_s）才成交"的BNE——信息租金与交易效率不可兼得；把某类交易稀少直接归因"机制设计失败"或"参与者不理性"都是误读，改善须补贴或改变信息结构。
2. **多重均衡，线性均衡只是被分析的一个（ce04）**：原文自认"除单一价格均衡和线性均衡之外，博弈还存在许多其他均衡"——线性均衡被挑中因其效率特性可证（均匀分布下最优），但均衡选择无一般答案，现实落在哪个均衡不由模型决定。
3. **均匀分布与拟线性效用依赖**：线性均衡的存在性依赖估值均匀分布（换分布不存在，转一般方法）；效用是交易的拟线性变化、风险中性；成交规则是外生的中间价(p_b+p_s)/2——换分牌规则，报价函数与门槛全部重算。
4. **静态一次性框架**：模型只有买方卖方、一次报价，无做市商库存约束、无重复互动学习、无市场微观结构制度（1992年成书，此后微观结构文献未覆盖）；"价差≈1/4门槛"的映射是结构性类比，不是做市定价公式。
5. **作者盲点**：真实市场的双边报价常被经纪人/做市商中介化，中介自身的激励不在模型中；"估值分布是共同知识"的假定在大宗交易（双方对对手盘几乎一无所知）中最脆弱；M-S不可能定理的"双方自愿参加"前提遇外部补贴（返佣、做市商制度）时松动，原书未展开。
