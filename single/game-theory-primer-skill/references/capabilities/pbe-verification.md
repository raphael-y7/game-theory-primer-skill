# cap.gibbons-game-theory.pbe-verification

## R 原文依据

> "满足要求1到4的战略和推断构成博弈的精炼贝叶斯均衡。"（4.1，定义）
> "要求1：在每一信息集中，应该行动的参与者必须对博弈进行到该信息集中的哪个节有一个推断。……要求2：……必须满足序贯理性（sequentially rational）的要求。……要求3：在处于均衡路径之上的信息集中，推断由贝叶斯法则及参与者的均衡战略给出。……要求4：对处于均衡路径之外的信息集，推断由贝叶斯法则以及可能情况下的参与者的均衡战略决定。"（4.1）

## I 自述

精炼贝叶斯均衡（PBE，4.1）是"战略+推断"的联合体：均衡不再只是每个参与者的一个战略，还包括他在每个应行动信息集上的推断——推断被提高到与战略同等地位（克雷普斯-威尔逊1982的关键创新）。验证一个候选均衡，就是把要求1-4逐条过一遍：

1. **要求1（推断存在）**：每一信息集上应行动的参与者必须持有推断——非单节信息集=集内各节上的概率分布（非负、和为1）；单节信息集=到达概率为1。要求1本身不约束推断的合理性，合理性由要求3/4承担。
2. **要求2（序贯理性）**：给定推断，每一信息集（不只均衡路径）上的行动及其后的完整行动计划，必须是对该推断与他人后续战略的最优反应。与子博弈精炼的区别：不要求信息集是子博弈起点、以推断为条件；等价于排除"始于任何信息集的严格劣战略"。
3. **要求3（路径上推断=贝叶斯法则×均衡战略）**：先按定义划分路径——按均衡战略以正概率到达的信息集在均衡路径上，肯定不到达的在路径外。路径上推断必须由贝叶斯法则与均衡战略共同决定；推论：混同均衡中推断=先验，偏离以q1、q2混合时p=q1/(q1+q2)。
4. **要求4（路径外推断尽量一致）**：路径外推断由贝叶斯法则及"可能情况下"的均衡战略决定——限定语是必需的，因为均衡战略可能对路径外节点不给任何概率。

要求1-3不足以保证子博弈精炼（要求4是必要防线）；要求4对信号博弈没有意义（发送者总在单节信息集行动）。概念退化：完全信息静态→NE，完全信息动态→SPNE，不完全信息静态→BNE——强概念只在复杂博弈中区别于弱概念。求解与验证一样有循环依赖（行动依赖推断、推断依赖上游行动、上游行动又依赖后续战略），一般不能沿树逆推，须用"猜测候选战略→定推断→查偏离→检验路径外支撑"的联立枚举。

## A1 书中案例

**worked_example 1：三人博弈证明要求4的必要性（4.1，图4.1.4）**
参与者1选A（终点收益(2,0,0)，顺序为参与者1、2、3）或D；D后参与者2在单节信息集选L或R；若R，参与者3在两节信息集（推断p与1−p）选L′或R′：L后L′→(1,2,1)、R′→(3,3,3)；R后L′→(0,1,2)、R′→(0,1,1)。子博弈（2、3之间）唯一NE=(L,R′)，故唯一SPNE=(D,L,R′)，配推断p=1满足要求1-4（无路径外信息集）。对照(A,L,L′)配p=0：是纳什均衡且满足要求1-3（3据p=0选L′得2>1），但非子博弈精炼——症结是p=0与2的战略L不一致。要求4强制：2的战略为L⇒p=1；p=1⇒要求2强制3选R′。(A,L,L′)+p=0不满足要求1-4，出局。

**worked_example 2：无子博弈的博弈中要求2单独干活（4.1，图4.1.1）**
1选L、M或R（R直接结束）；L或M后2在两节信息集选L′或R′。该博弈没有子博弈，（R,R′）与(L,L′)都是NE且都是"子博弈精炼"。但给定2的推断p与1−p：选L′期望收益p·1+(1−p)·2=2−p，选R′期望p·0+(1−p)·1=1−p，对任意p均有2−p>1−p——要求2排除R′，(R,R′)出局。PBE在无子博弈处也能完成SPNE想做而做不到的可信性检查。

**worked_example 3：图4.1.5——"可能情况下"的含糊（4.1，修正读法）**
在图4.1.4中给参与者2增加第三行动A′（令博弈直接结束，图略收益）。若1的均衡战略为A，3的信息集在路径外：若2的战略为A′，要求4对3的推断无任何限制；若2以q1、q2的概率混合L、R，则要求4限定p=q1/(q1+q2)。注：转写稿按图录作"其中q1+q2=0"，系排印之误——按候选验证官修正读法，应区分两情形：q1+q2＞0（2以正概率到达L/R）时p=q1/(q1+q2)；q1=q2=0（2确定选A′，博弈在3之前结束）时推断不受约束。这一含糊由第4.4节信号要求5/6再精炼处理。

## A2 触发与投资映射

### 触发场景
- 拿到一个"市场推断+各方行为"的剧本，要检验信念与行为是否互证自洽。
- 分析公告、偏离事件后投资者推断应如何更新（谁偏离、偏离意味着什么类型）。
- 面对多重均衡剧本，要标注哪些结论依赖随意指定的路径外信念。

### 语言信号
- 中文："市场推断/市场以为""贝叶斯更新""信念与行为自洽""均衡路径上/路径外""偏离后市场会怎么想""这个解释经得起推敲吗"。
- 英文："belief / posterior / Bayesian updating / on/off the equilibrium path / sequentially rational / consistency of beliefs and strategies"。

### 相邻区分
- 与 signaling-equilibrium：信号博弈是PBE的特化——信号要求1/2R/2S/3正是要求1-3的翻译（要求4无意义）；一般树形动态博弈用本卡，两类型两信号信号博弈直接用四候选枚举卡。
- 与 signal-refinement-checklist：本卡产出"满足要求1-4的均衡清单"；再精炼卡（信号要求5/6、直观标准）对路径外推断施加经济学约束，二者是"先验证、再精炼"的接力。
- 与 subgame-perfection-check：完全信息时用后者；要求1-3并不保证子博弈精炼（图4.1.4），PBE以推断为条件把可信性检查推广到无子博弈的博弈。
- 与 backward-induction：全单节信息集的完美信息博弈无需推断，逐级回推即可；出现任何非单节信息集，本卡接管。

### 投资场景映射
1. **回购公告的推断链检验**：均衡路径上"公告→市场推断低估"须由公告行动+贝叶斯法则支撑；若公告后公司并未足额执行（偏离事件），市场新推断应与"谁、在什么动机下偏离"一致（要求4式追问），而非随意贴"护盘失败/作秀"标签。
2. **业绩预告"变脸"的归因**：变脸=路径外事件。要求4式检验要求把偏离归因于与该公司类型相容的战略（如一贯的盈余管理惯性），推断与行为互证后才能用作投资判断；每日更换解释=推断不满足一致性。
3. **增发公告被读作利空**：检验市场推断"增发=管理层认为股价高估"是否与Myers-Majluf分离均衡的推断一致（绩优公司回避股权融资）；推断与均衡战略互证，"增发利空"才可作解读依据，否则只是路径外随意信念。
4. **大股东减持方式的信息含量**：集中竞价/大宗/协议转让是三种"信号"，市场在每种信号后形成不同后验；逐个检验后验与减持者后续行为（是否质押、有无锁定承诺）互洽——互洽的后验才有信息含量。
5. **停牌重组失败的剧本审计**：列出市场叙事依赖的路径外推断（"若真有重组，早该……"），区分哪些由贝叶斯法则+行为支撑、哪些是自由指定——依赖随意推断的"必然利空"结论不可靠。

## E 执行步骤

1. **画树、列信息集**：标出每个信息集的行动者、单节/非单节。→ *完成标准*：信息集清单完整（含每个非单节集的节点数）。*判停点*：全部信息集为单节且完全信息→退回逆向归纳/子博弈精炼卡，无需推断。
2. **提出候选战略组合，划分路径**：对给定候选，标出每个信息集"均衡路径上/路径外"。→ *完成标准*：每个信息集贴上标签。
3. **要求3核验**：路径上信息集的推断=贝叶斯法则×均衡战略（混同→先验；偏离以q1、q2混合→p=q1/(q1+q2)）。→ *完成标准*：每个路径上信息集的推断数值化。*判停点*：推断与候选战略不相容→候选出局。
4. **要求1+2核验**：每个信息集（含路径外）指定推断；给定推断，行动者在该信息集的行动及其后完整计划最优。→ *完成标准*：逐信息集"推断→最优反应"核对表，无偏离动机。*判停点*：任一信息集存在更优偏离→候选出局；因循环依赖枚举推不动→改用混同/分离/杂合候选联立枚举。
5. **要求4核验**：路径外推断与偏离者战略一致（可能情况下）；不受约束处显式注明"自由推断"。→ *完成标准*：每个路径外信息集有一致性论证或"自由"标注。*判停点*：均衡结论依赖"自由"推断→加警告标签，转信号要求5/6再精炼。
- **输入输出契约**：输入=扩展式博弈（树、信息集、收益）+候选战略组合；中间产物=路径划分表、推断赋值表、逐信息集最优反应核对表；输出=PBE判定（通过/出局+违反哪条要求），或"通过但依赖路径外推断"的警告清单。

## B 边界

1. **非完美信息下逆向归纳失效（ce23）**：博弈含非单节信息集时，行动者不知自己身处哪一节，"强迫参与者考虑如何行动，并不等于让其考虑在一个可能发生的情况下他将如何行动"——单节点逐级逆推得无意义的"解"；必须战略与推断联立求解，本卡即该联立检验的逐条程序。
2. **路径外推断的随意性（ce15）**：要求4对信号博弈无意义，"e≠ep一律视为低能力"这类怪推断合法存活并支撑整族混同均衡——凡引用均衡结论，先查其路径外推断依赖；随意推断支撑的"均衡"不可直接当预测。
3. **精炼措辞细节决定取舍（ce17）**：要求5的教训——"始于信息集的严格劣战略"多于"整个博弈的严格劣战略"，条件取得过强则约束过弱；(A,L,L′)+p=0能过要求1-3正说明逐条措辞差一点就放过坏均衡；本卡的每条"要求"都不可省略或替换措辞。
4. **要求4自身不彻底**：若偏离者把正概率放在令博弈直接结束的行动上（图4.1.5的A′），路径外推断不受要求4约束——"可能情况下"的含糊在复杂博弈中原书未完全解决，须靠再精炼；本卡只能标注、不能消除这种自由度。
5. **作者盲点**：不同学者PBE定义不同（都含要求1-3、绝大多数含要求4），本书取要求1-4为定义，跨教材比较结论时先对定义；推断是均衡的组成部分而非外生数据——把"市场信念"当输入硬塞进模型会自相矛盾；1992年成书，信念的学习/演化形成机制不覆盖，市场情绪类信念不满足贝叶斯一致性时本卡全部结论失效。
