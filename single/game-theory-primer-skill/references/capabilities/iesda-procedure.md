# 重复剔除严格劣战略程序

## R — 原文依据

1.1.B定义："如果对其他参与者每一个可能的战略组合，i选择s'i的收益都小于其选择s″i的收益，则称战略s'i相对于战略s″i是严格劣战略"；"理性的参与者不会选择严格劣战略，因为他（对其他人选择的战略）无法作出这样的推断，使这一战略成为他的最优反应"。同节警告："如果我们要把这一过程应用到任意多步，就需要假定'参与者是理性的'是共同知识。"

## I — 方法论自述

IESDS（重复剔除严格劣战略）是用"理性者绝不选严格劣战略"这一条公理逐轮缩小博弈的预清理程序。

- **判据（(DS)式）**：s'i严格劣于s″i ⇔ 对其他参与者**每一组**可能的战略组合，ui(…,s'i,…)＜ui(…,s″i,…)都成立——"每一组"缺一不可，只在部分对手选择下更差不算严格劣。
- **程序**：找某参与者的严格劣战略→剔除→在缩小后的博弈中重复→直至无可剔。剔除的立足点：严格劣战略无法成为任何推断下的最优反应，理性者绝不采用。
- **与NE的关系（附录1.1.C）**：命题A——剔剩唯一战略组合{s*}，它就是唯一纳什均衡；命题B——纳什均衡永不被剔除（混合版：均衡中正概率的战略不会被剔除，习题1.14）。逆不成立：留存组合不必是均衡。故IESDS只是NE的特例快捷方式，NE是更强的解概念。
- **逐层理性假设**：第1轮剔除只需"该参与者是理性的"；第2轮需要"对手知道他理性"；第3轮需要"对手知道对手知道他理性"……任意多轮⇒"人人理性"是共同知识，以至无穷（正式定义见奥曼1976）。
- **升级路径**：剔不干净不是失败而是信号——转划线法/混合求解（nash-equilibrium-solver卡）。
- **混合层**：占优检验要在混合战略层做——纯战略可以被某个混合战略严格占优。

## A1 — 书中案例

**worked_example 1：囚徒困境的一轮剔除（1.1.B）**
输入：1.1.A矩阵——沉默/沉默=(-1,-1)；沉默/招认=(-9,0)；招认/沉默=(0,-9)；招认/招认=(-6,-6)。执行：对囚徒i，若对方招认，沉默得-9＜招认得-6；若对方沉默，沉默得-1＜招认得0——沉默在对方的**每一**战略下都更差，严格劣，剔除。结论：一轮即得(招认,招认)；收益数字换成任意满足T＞R＞P＞S的T、R、P、S，结论不变。

**worked_example 2：图1.1.1的三轮剔除（1.1.B）**
输入：S1={上,下}、S2={左,中,右}；上(1,0)(1,2)(0,1)、下(0,3)(0,1)(2,0)。执行：第1轮，参与人2的"右"严格劣于"中"（2＞1且1＞0）→剔右；第2轮，缩小的博弈（图1.1.2）中参与人1的"下"严格劣于"上"（1＞0且1＞0）→剔下；第3轮，"左"严格劣于"中"（0＜2）→剔左。结论：仅剩(上,中)；三轮剔除分别要求不同层级的相互知识假设。

**worked_example 3：古诺模型的前两步与极限（1.2.A）**
输入：P(Q)=a−Q、πi=qi[a−(qi+qj)−c]。执行：第1步，超过垄断产量qm=(a−c)/2的产量严格劣——对任意x＞0、任意qj≥0，πi(qm+x,qj)=πi(qm,qj)−x(x+qj)＜πi(qm,qj)；第2步，qj∈[0,(a−c)/2]时低于(a−c)/4的产量严格劣；重复至无穷，剩余区间收缩为点(a−c)/3。结论：据命题A，(a−c)/3是唯一NE，与代数解一致。

**worked_example 4：3企业古诺的失效与图1.1.4的反差（1.2.A、1.1.B/1.1.C）**
输入：3企业时除i外的总产量Q−i∈[0,a−c]；图1.1.4矩阵上(0,4)(4,0)(5,3)、中(4,0)(0,4)(5,3)、下(3,5)(3,5)(6,6)。执行：3企业情形下，对任意qi∈[0,(a−c)/2]都存在Q−i=a−c−2qi使其成为最优反应→无战略可剔；图1.1.4中所有战略都经得住重复剔除。结论：前者只剩"每家产量不超过垄断产量"的粗预测，后者IESDS对结果毫无预测力——而划线法对图1.1.4给出唯一NE（下，右），其余留存组合（如上/左）与均衡无关。

## A2 — 触发与投资映射

### 触发场景
- 拿到收益矩阵，求解前先快速刮掉"无论对手如何都不划算"的选项；
- 需要论证"某方绝不会做X"（X在对手所有选择下都更差）；
- 快速判断一个博弈是否"占优可解"，能否跳过均衡求解直接给结论；
- 检验某策略选项是否在任何情形下都有一席之地。

### 语言信号
- 中文：劣战略/严格劣势、占优/优超、理性人绝不会、无论如何都不划算、全场景更差、剔除、缩小范围、逐层、共同知识。
- 英文：strictly dominated / dominated strategy / iterated elimination / dominance solvable / rationality is common knowledge / never choose / worse under every contingency。

### 与相邻能力的区分
- **nash-equilibrium-solver**：本卡是预清理+特例快捷方式（剔剩唯一=唯一NE）；剔剩多个或剔不动时转该卡划线/混合求解。NE是更强的解概念。
- **mixed-strategy-reinterp**：占优检验与求解都要在混合层做；混合均衡的含义（对手的不确定性）解读归该卡。
- **game-type-classifier**：本卡默认完全信息静态（或扩展式的完全信息部分）；判类先行。
- **subgame-perfection-check**：动态博弈中"不可信威胁"的剔除是另一套逻辑（子博弈层面最优），不归本卡。
- **repeated-game-cooperation**：重复博弈中合作可由未来惩罚支撑，一次性劣战略剔除会误判"合作必崩"，长期关系转该卡。

### 投资场景映射
1. 预清理行业博弈矩阵：两/三家企业对峙时先剔除全场景劣势选项（如"无论对手如何应对都亏损的产能翻倍"），缩小需认真比较的战略组合；
2. 审读公告式全场景承诺："无论竞争对手如何应对，我们都将……"——只有"在对手每一选择下都更差"的行动才可断言理性者不会执行；仅部分情形更差的承诺不在此列；
3. 检查自己的投资决策清单：某操作在所有市场情景下收益都低于另一操作→从清单剔除，缩小决策树；
4. 快速识别"囚徒困境式"行业（T＞R＞P＞S结构）：一次性博弈中默契合作不可维持，为长期关系分析（重复博弈门槛δ）预留接口。

## E — 执行步骤

1. **确认输入G**：三要素齐备（转自normal-form-modeling卡）。
   完成标准：矩阵或收益函数完整。
   判停点：未建模→退回建模卡。
2. **逐战略查严格劣（含混合层）**：对每个参与者的每个战略s'i，寻找另一战略s″i（纯或混合），核对(DS)式在对手**每一**剩余战略组合下成立。
   完成标准：剔除记录表=轮次/参与者/被剔战略/占优它的战略/逐格收益对照。
   判停点：一轮都剔不动→本卡无产出，转 nash-equilibrium-solver。
3. **在缩小的博弈中重复**：每轮重新核对（原博弈中不劣的战略，缩小后可能变劣）。
   完成标准：终止于无可剔；记录总轮数k。
   约定：第k轮剔除隐含k阶"我知道你知道……你是理性的"假设，结论中注明层级。
4. **解读与升级**：剔剩唯一组合→按命题A报告"唯一NE"；剔剩多个→报告"IESDS预测力不足"，列出留存集并升级求解。
   约定：留存≠会发生（NE才是稳定点）；下"无可剔"结论前须确认混合层检验已做。

输入契约：G三要素+收益数字/参数式；缺收益→先问。
输出契约：剔除记录表+最终留存集+二选一结论（唯一NE / 升级求解）+理性假设层级注记。

## B — 边界

1. **ce03 两大缺陷（原书自认）**：①逐层共同知识回归——任意多轮剔除要求"理性是共同知识"以至无穷，市场参与者难以满足；②预测经常不精确——3企业古诺只剩"产量≤垄断产量"，图1.1.4什么都剔不掉。
2. **ce24 混合层漏检**：只比对纯战略会漏——图1.3.1中B不被T、M任一纯战略严格占优，却被"T、M各1/2"以期望收益3/2＞1严格占优；下"无可剔"结论前必须在混合层完整执行。
3. **逆命题陷阱（附录1.1.C/图1.1.4）**：留存组合不必是均衡——图1.1.4没有任何组合被剔除，但唯一NE是（下，右）；"没被剔除"≠"会实现"。
4. **ce04/ce05 相邻警告**：剔除不唯一时（性别战类）均衡选择无一般答案；命题A/B的证明假定有限博弈，无限战略空间（古诺类）靠构造与收敛论证补足。
5. 作者盲点：理性是公理而非实证结论（1992年成书，行为/实验对"绝不选严格劣战略"的系统性偏离未纳入）；一次性博弈逻辑直接套到长期关系会误判合作不可维持——重复博弈中的合作由后续机制支撑（接 repeated-game-cooperation）。
