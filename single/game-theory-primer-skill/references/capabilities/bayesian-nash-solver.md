# cap.gibbons-game-theory.bayesian-nash-solver

## R 原文依据

> "一个n人静态贝叶斯博弈的标准式表述包括：参与者的行动空间A1，…，An，它们的类型空间T1，…，Tn，他们的推断p1，…，pn以及他们的收益函数u1，…，un。"（3.1.B）

> "（1）自然赋予博弈各方的类型向量t=（t1，…，tn）……（2）自然告知参与者i自己的类型ti，却不告诉其他参与者的类型；（3）参与者同时选择行动……（4）各方得到收益。"（3.1.B）

> "参与者i的一个战略是一个函数s_i(t_i)，其中对T_i中的每一类型t_i，s_i(t_i)包含了自然赋予i的类型为t_i时，i将从可行集A_i中选择的行动。"（3.1.C）

> "没有参与者愿意改变自己的战略，即使这种改变只涉及一种类型下的一个行动。"（3.1.C）

> "如果我们的均衡概念要求企业1的战略是企业2战略的最优反应，则2的战略必须是一对产量，分别对应于两种可能的成本类型，否则企业1就无法计算它的战略是否确实是企业2战略的最优反应。"（3.1.C）

## I 自述

贝叶斯博弈求解器=**把"谁知道什么"包装成类型，再把纳什均衡逐类型化**。

**第一步 建模（3.1.B，豪尔绍尼1967）**：四要素G={A_1,…,A_n; T_1,…,T_n; p_1,…,p_n; u_1,…,u_n}——类型t_i∈T_i决定收益函数u_i(a_1,…,a_n;t_i)（类型也可代表行动集差异：不可行行动赋收益−∞）；推断p_i(t_{−i}|t_i)=p(t_{−i},t_i)/Σ_{t_{−i}∈T_{−i}}p(t_{−i},t_i)，由共同先验p(t)经贝叶斯法则导出；时序"自然抽类型→私有告知→同时行动→按类型结算"把不完全信息转化为非完美信息。类型独立时p_i(t_{−i}|t_i)退化为与t_i无关的边缘分布（绝大多数应用；类型相关如技术竞赛须保留条件推断）。

**第二步 定战略（3.1.C）**：战略=函数s_i:T_i→A_i，必须覆盖**每一种类型**——否则对手无法计算其最优反应，纳什均衡概念对贝叶斯博弈失效（与动态博弈"战略须是完整计划"同理）。分离战略/混同战略是构建出的战略集中两个极端。

**第三步 定义并求BNE（3.1.C）**：s\*是纯战略BNE⇔对每个i的每种t_i，s_i\*(t_i)满足max_{a_i∈A_i}Σ_{t_{−i}∈T_{−i}}u_i(s_1\*(t_1),…,a_i,…,s_n\*(t_n);t)·p_i(t_{−i}|t_i)——**逐类型无利可改**（哪怕只改一个类型下的一个行动）。**求解程序**：每类型写期望收益→每类型一阶条件→联立所有类型的FOC（类型依赖反应函数+不知情者的期望利润FOC）。对拍卖类再配两招：**猜线性法**（不限制战略空间，只看是否存在线性均衡）与**对称均衡ODE法**。有限静态贝叶斯博弈存在BNE（可能混合），证明与有限博弈混合NE平行。

## A1 书中案例

**worked_example 1：非对称成本古诺（3.1.A）——类型依赖一阶条件的联立**
企业1成本c（共同知识）；企业2以θ的概率为c_H、以1−θ为c_L（c_L＜c_H），只有企业2自己知道。
- 三个最优化问题：企业2两种类型各自max[(a−q_1\*−q_2)−c_H]q_2、max[(a−q_1\*−q_2)−c_L]q_2；企业1期望利润max θ[(a−q_1−q_2\*(c_H))−c]q_1+(1−θ)[(a−q_1−q_2\*(c_L))−c]q_1。
- 三个一阶条件：q_2\*(c_H)=(a−q_1\*−c_H)/2、q_2\*(c_L)=(a−q_1\*−c_L)/2、q_1\*=[θ(a−q_2\*(c_H)−c)+(1−θ)(a−q_2\*(c_L)−c)]/2（第三式第二括号转写稿印作q_1\*(c_L)并标【辨识存疑】，按修正读法应为q_2\*(c_L)——企业1期望利润中出现的只能是企业2的产量）。
- 解：q_2\*(c_H)=(a−2c_H+c)/3+(1−θ)(c_H−c_L)/6、q_2\*(c_L)=(a−2c_L+c)/3−θ(c_H−c_L)/6、q_1\*=(a−2c+θc_H+(1−θ)c_L)/3。
- 信息效应：q_2\*(c_H)高于对应完全信息古诺值、q_2\*(c_L)低于之——知情者不仅按自身成本调产量，还预期不知情者按期望行动（双重调整）。**巧合警示（原文明示）**：q_1\*恰等于两完全信息产量期望值是本线性例特有，一般不成立（如成本c_i·q_i²）。

**worked_example 2：一级密封拍卖（3.2.B）——猜线性+ODE两法**
两投标人估价独立U[0,1]、风险中性、最高价中标付己价、平价掷硬币。
- 猜线性：设b_i(v_i)=a_i+c_i·v_i（不限制战略空间）；给定对手战略，Prob{b_i>b_j}=(b_i−a_j)/c_j，最优反应分段：b_i(v_i)=(v_i+a_j)/2（v_i≥a_j）、a_j（v_i＜a_j）；排除0＜a_j＜1（最优反应非线性）、a_j≥1（意味着b_j(v_j)≥v_j必非最优）⇒a_j≤0，联立a_i=a_j/2、c_i=1/2得a_i=a_j=0、c_i=c_j=1/2，即**b_i(v_i)=v_i/2**（存在且唯一）。基本权衡：出价越高中标率越高、中标净收益越低。
- 附录ODE法：设对称严格递增可微b(·)，FOC−b^{−1}(b_i)+(v_i−b_i)·d[b^{−1}(b_i)]/db_i=0，代入b_i=b(v_i)得微分方程b′(v_i)v_i+b(v_i)=v_i（左边恰为d[b(v_i)v_i]/dv_i），积分b(v_i)v_i=v_i²/2+k（转写稿印作大写V_i²并注明疑为v_i²之误），边界条件b(0)=0（无人出高于估价的价+出价非负——经济学理性而非数学假定）定k=0⇒b(v)=v/2，且为唯一对称均衡。
- n人推广（习题3.6）：b(v_i)=(n−1)/n·v_i；线性均衡依赖均匀分布——估价服从任何其他分布时线性均衡不存在，须用附录方法。

## A2 触发与投资映射

### 触发场景
- 任何"对手有私人信息、同时行动"的竞价/竞争场景：打新与定增询价、大宗与协议受让出价、土地/资产竞拍、并购竞标、招投标。
- 竞争对手成本/需求类型不确定时决定自己的产能、产量或价格（新进入者成本未知、对手新技术进展未知）。
- 研究框架自检：对"对手的可能类型"是逐一定价，还是只按最可能类型点估计。

### 语言信号
- 中文："他知道自己成本/估值，我们不知道""按概率加权""对手会怎么报价""折价报价""中标率与收益的权衡""对手是高成本还是低成本""期望利润最大化""多重类型"。
- 英文："Bayesian Nash equilibrium"、"type space / belief"、"first-price sealed-bid"、"bid shading"、"bid function b(v)"、"type-contingent strategy"、"incomplete information"、"expected profit maximization"。

### 相邻区分
- 与 mixed-strategy-reinterp：净化定理把混合NE解释为BNE的极限（3.2.A）——本卡提供求解工具，那卡提供"混合=对手不确定性"的解读，同一数学对象两个视角。
- 与 double-auction-linear-eq：本卡是通用求解程序；双向拍卖是双边私人信息的具体机制，其线性均衡推导即"猜线性+FOC"的一次应用。
- 与 revelation-principle：本卡在给定机制内求均衡；显示原理把机制搜索压缩到"直接机制+实话实说"，是设计视角的配套工具。
- 与 signaling-equilibrium / pbe-verification：本卡限**静态**（类型→行动一步完成）；序贯行动下推断随行动修正，须换精炼贝叶斯均衡工具（第4章）。

### 投资场景映射
1. **打新/定增询价出价折算**：一级市场询价即一级密封拍卖——对标的估值v，报价按b(v)=(n−1)/n·v折算（n=有效竞价主体数）；竞争对手越多折价越小、报价越贴近估值。用法：①自己的报价纪律（不因情绪顶格）；②发行端视角"扩大询价对象池"推高报价中枢，n是发行方最重要的可控变量。
2. **大宗交易/并购竞标出价**：v/2与(n−1)/n·v是"折价锚"——折价幅度是中标率与中标净收益的均衡权衡；对手估值分布的假设直接改变折价幅度，且换分布后线性报价规则不存在、须重新推导——把v/2照抄到对手分布陡峭的场景是典型误用。
3. **对手成本类型推断（非对称古诺）**：行业里"对手是高成本还是低成本"（旧产能/新产能、老技术/新技术）不确定时，知情方按类型定产量，不知情方按期望最优——均衡中高成本对手产量**高于**其完全信息水平（它知道你会按期望行动而少产），低成本时**低于**完全信息水平。映射：价格战中把对手温和放量误读为"成本高、外强中干"之前，先按信息效应修正基准。
4. **逐类型完备性纪律**：BNE要求战略覆盖每种类型——研究纪律上即"对对手/管理层的每一种可能类型都算最优反应与自己的应对"，禁止只按最可能类型点估计（遗漏类型=均衡概念失效，预测必然漏掉尾部场景）。
5. **存在性与多重性前置检查**：套用任何BNE结论前先查①均衡是否已构造/证明（无限战略空间的拍卖/古诺类不在一般存在性定理覆盖内）；②是否多重均衡——多重时输出条件剧本而非唯一点预测。

## E 执行步骤

1. **判定信息结构**：谁拥有什么私人信息；私人信息是否影响收益（构成类型）；类型分布/先验是否共同知识；类型独立还是相关。→ *完成标准*：一句话表述"i的类型t_i∈T_i，i知道t_i，j持推断p_j"。*判停点*：行动序贯且可观测→属第4章精炼贝叶斯范围，本卡只解静态。
2. **写标准式**：列G={A;T;p;u}四要素，行动集差异用"不可行行动收益−∞"处理。→ *完成标准*：四要素齐备，收益写成u_i(a;t)形式。
3. **定战略空间并写各类型期望收益**：战略=类型→行动函数；每类型按p_i(t_{−i}|t_i)加权写期望收益max问题。→ *完成标准*：每类型一个max问题，无遗漏类型。
4. **逐类型FOC并联立求解**：类型依赖反应函数+不知情者期望FOC；拍卖类先猜线性，类内排除后再解系数；对称问题转ODE法（积分+经济边界条件）。→ *完成标准*：解出类型依赖战略并代回核验互为最优反应。*判停点*：FOC组无内点解→查角点解与存在性，勿硬解。
5. **验证与输出**：逐类型无利可改复核；存在性/多重性声明；比较静态（类型概率θ、分布形状、人数n）。→ *完成标准*：均衡战略+信息效应方向+条件限定一并列出。
- **输入输出契约**：输入=参与者集合与信息分布（谁知道什么）、类型空间与先验、行动空间与收益函数；中间产物=各类型期望收益max问题、FOC方程组、（拍卖类）线性系数或ODE积分；输出=类型依赖均衡战略（如b(v)、q_2\*(c)）、信息效应方向、n/θ敏感性、存在性与多重性声明。禁止输出：对无限战略空间直接引用存在性定理；把单一点预测替代条件剧本；把线性均衡外推到非均匀分布。

## B 边界

1. **存在性定理不覆盖无限战略空间（ce05）**：有限贝叶斯博弈必有BNE（证明与混合NE平行），但拍卖、古诺类战略空间无限，不在一般保证之列——书中靠逐例构造（猜线性+附录ODE并证唯一）补足。套结论前先确认均衡已在模型类内构造出来。
2. **多重均衡使预测退化为可能性清单（ce04）**：许多贝叶斯博弈均衡不唯一（双向拍卖"还存在许多其他均衡"）；线性均衡被选作分析对象是因其效率特性可证，不代表现实中实现的就是它——均衡选择无一般答案。
3. **猜线性法的类内局限**：猜线性只证明"存在线性均衡"；均匀分布下它恰是唯一对称均衡，其他分布下线性均衡不存在、须转ODE一般法，且结论限"严格递增+可微"类——换分布照抄b(v)=v/2是越界。
4. **类型独立与共同先验假定**：推断由共同先验经贝叶斯法则导出；类型相关（技术竞赛）时必须保留条件推断p_i(t_{−i}|t_i)，边缘分布口径失效；风险中性贯穿拍卖推导，风险厌恶会系统性改变出价函数（原书未展开）。
5. **作者盲点**：q_1\*等于完全信息产量期望值的"巧合"作者自警不可外推，但θ、δ等参数的现实估计仍无着落；共同先验假定（人人对"对手类型分布"看法一致）在多空分歧巨大的市场里最可疑；1992年成书，赢家诅咒等拍卖行为证据仅以进一步阅读提及（McAfee-McMillan综述），未进入正文模型。
