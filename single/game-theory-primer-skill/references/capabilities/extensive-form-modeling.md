# cap.gibbons-game-theory.extensive-form-modeling

## R 原文依据

2.4.A定义："一个博弈的扩展式表述包括：（1）博弈中的参与人；（2a）每一参与者在何时行动；（2b）每次轮到某一参与者行动时，可供他选择的行动；（2c）每次轮到某一参与者行动时，他所了解的信息；及（3）与参与者可能选择的每一行动组合相对应的各个参与者的收益。"信息集定义："(i)在此信息集中的每一个节都轮到该参与者行动，且(ii)……应该行动的参与者并不知道达到了……信息集中的哪一个节。"

## I 自述

扩展式表述（extensive form）是把**时序性互动**完整写成的规范结构，博弈树是它的图形表示：根到叶子是一条可能的博弈进程，决策节标注行动者与行动集，终点节标注各方收益，信息集用虚线连接。它回答五个问题——参与者有谁、谁在何时行动、每次能选什么、当时知道什么、各行动组合下各得什么。

关键构件是**信息集**（information set）：决策节的集合，满足(i)集内每节都轮到同一参与者行动，(ii)达到其中一节时行动者不知道到达了哪一节。信息集承载的是"**知道什么**"：
- 完美信息 ⇔ 所有信息集都是单节——树上每个决策节都代表参与者确切遇到的局面；
- 非完美信息 ⇔ 至少存在一个多节信息集；
- 同时行动的静态博弈也可用扩展式表示：后行者处于跨节信息集（"知道对方已行动，但不知道怎么行动的"）。

由此引出**战略≠行动**：战略是完整应变计划，须覆盖参与者可能遇到的每一种情况。图2.4.1的参与者2有2个行动却有4个战略（对1的每个可能选择各给一个应对）；战略若不覆盖全部情况，对手就无法计算最优反应，纳什均衡概念无从使用。

建模程序（2.4.A）：①列参与人 → ②(2a)定行动时序、(2b)列每步可行行动集、(2c)定当时知道什么（画信息集）→ ③终点节标收益 → ④自检：同一信息集内各节的可行行动集必须完全相同——否则该参与者可凭行动集差异反推到达了哪一节，违反定义(ii)。

标准式与扩展式可以互译（任何博弈两种表述皆可，只是方便程度不同）：静态博弈用标准式更紧凑，动态博弈用扩展式更直观；把动态博弈翻译成标准式时，行列不再是"行动"而是"战略"（应变计划）。

## A1 书中案例

**worked_example 1：手雷博弈的博弈树（第2章开篇，习题2.21）**
参与者1选择"支付1000美元"或"一分不给"；参与者2观测后决定是否"引爆手雷把两人一块儿炸死"。画成树：根=参与者1的两分支（付/不付），每支后接参与者2的一个决策节（引爆/不引爆），四个终点节标双方收益。威胁"不付就引爆"在树上是一条真实存在的枝，但站在末端节点看，引爆对参与者2自身并非最优——逆向归纳解为"一分不付、不引爆"。该例演示：树上画得出的威胁不等于会执行的威胁，建模时先把结构画对，可信性留给求解阶段。

**worked_example 2：图2.4.1两阶段博弈与战略计数（2.4.A）**
参与者1从A1={L, R}选a1；参与者2观测a1后从A2={L′, R′}选a2；收益u1(a1,a2)、u2(a1,a2)。树：根（参与者1）→ 两个中间决策节（均为参与者2）→ 四个终点节。参与者1行动时只面临一种情况，故战略=行动，共2个；参与者2有2个行动却有4个战略：(L′,L′)、(L′,R′)、(R′,L′)、(R′,R′)——括号内依次为"观测到L时的选择、观测到R时的选择"。以此战略为行列建收益矩阵（图2.4.2），即得该动态博弈的标准式。

**worked_example 3：信息集的两个对照（图2.4.3与图2.4.4，2.4.A）**
- 囚徒困境的扩展式（图2.4.3）：囚徒1的决策节在上，囚徒2的两个决策节用虚线连成**一个含两节的信息集**——表示2知道1已行动，但不知道1怎么行动的。这一"跨节信息集"就是同时行动在扩展式中的写法。
- 完全非完美信息博弈（图2.4.4）：参与者1选L/R、参与者2选L′/R′后轮到参与者3。参与者3有两个信息集：(R,R′)之后的单节信息集，以及其余三个决策节连成的三节信息集——3所能观测到的只是(a1,a2)是否等于(R,R′)。此例同时是子博弈定义中条件(c)"不得切割信息集"的反例素材：参与者2的两个决策节下都不构成子博弈。

## A2 触发与投资映射

### 触发场景
- 需要在纸面上固化多方互动："谁先动、谁后动、谁决策时知道什么、各得什么"尚无明确结构；
- 某方声称"若你不……我就……"，需要把威胁落成树上的具体枝才能检验可信性；
- 事件有时间线（宣布→回应→执行），且某些环节存在"看不到对方做了什么"的环节。

### 语言信号
- 中文："谁先动、谁后动""他知道/不知道……就做了决定""在……之前/之后行动""同时宣布""他看到的只是……""事后才知道"。
- 英文："move first / move second / order of play"；"observes / cannot observe / is not told whether…"；"before/after … moves"；"simultaneously announce/submit"；"decides after observing…"；"the market only learns whether…"。

### 相邻区分
- 与 **normal-form-modeling** 卡：静态同时行动用标准式三要素更方便；本卡处理含时序与信息集的结构。注意同时行动也可写成扩展式（跨节信息集），两套表述等价、可互译，选表述看方便。
- 与 **backward-induction** 卡：本卡只负责"画对树"（五要素+信息集自检），不求解；单节信息集全树才可逆向归纳。
- 与 **subgame-perfection-check** 卡：子博弈要求"始于单节信息集、不切割任何信息集"——建模时信息集画法直接决定后续有无子博弈可找。
- 与 **signaling-equilibrium** 卡（第4章）：信号博弈中信息集还承载概率推断（接收者的信念）；本卡的信息集只承载"知道什么"，不写信念。

### 投资场景映射
1. **要约收购时间线建模**：首次报价→目标董事会回应→白衣骑士/竞争性报价→股东表决，每一步画成一个决策节；"董事会是否知道竞争方已接触管理层"画成信息集——树的形状决定后面能用什么均衡概念。
2. **大股东增持与散户观测**：大股东先行动（增持/不增持），散户看公告后决定是否跟随——公告可观测=单节信息集（完美信息树）；若通过大宗交易进行、散户只能猜测，则散户处于多节信息集（非完美信息，需贝叶斯工具）。
3. **增发/回购的"宣布"与"执行"两节点**：宣布（可观测、即时）与实际执行（可拖延、可变卦）必须画成两个不同决策节——许多"承诺不可信"的判断，根源在于把两节点混画成一个。
4. **做市商与知情交易者序列**：知情者先观测私人信号→提交订单→做市商定价。做市商观测不到信号内容=非单节信息集——这张树为第3/4章贝叶斯纳什/精炼贝叶斯分析铺路。
5. **集合竞价的扩展式写法**：双方同时提交订单可改写为"一方先交单、另一方不知其内容"的跨节信息集——由此看清为何竞价均衡要用标准式/贝叶斯工具而非逐节倒推。

## E 执行步骤

1. **列参与人**（含随机因素时的"自然"）。
   完成标准：参与人清单无遗漏，每人后续在树上有明确决策节。
2. **(2a)定行动时序**：谁在第几步行动。
   完成标准：时序写成编号步骤，无"同时"字样——同时行动改写为"顺序行动+跨节信息集"。
3. **(2b)列每步可行行动集**。
   完成标准：每个决策节旁有明确的行动集合。
4. **(2c)定信息集**：把"当时不知道是哪种情况"的各决策节用虚线连成同一信息集。
   完成标准：每个决策节属于且仅属于一个信息集；**自检通过——同一信息集内各节可行行动集完全相同**（否则行动者可凭行动集差异反推节点，违反定义(ii)）。
5. **(3)标收益**：每个终点节写全各参与者的收益。
   完成标准：无空收益的终点节。
6. **类型诊断输出**：所有信息集单节→完全且完美信息（可走逆向归纳卡）；存在非单节信息集→非完美信息（静态部分转标准式求解，动态转子博弈精炼跳越法或第4章PBE）；数出每参与者的战略数（=应变计划数，≠行动数）。

**输入输出契约**：输入=文字描述的时序性互动（含谁在何时知道什么）；输出=五要素齐备的博弈树（图形或文字化）+信息集清单+"完美/非完美信息"诊断+每参与者战略计数。判停点：某参与者在某节的行动集或收益写不出→建模暂停，先补尽调（这本身说明对博弈结构了解不足，不要硬填假设当事实）。

## B 边界

1. **ce01 不可置信威胁：建模正确≠预测正确**。扩展式只是把互动写清楚的工具，树上画出的威胁枝不因画在树上而变得可信（手雷博弈）；画完树必须再经逆向归纳/子博弈精炼检验。且本卡的信息集只承载"知道什么"，不承载概率推断——路径外信念要到第4章PBE才有位置；**逆向归纳仅适用完美信息，不完美信息需PBE**。
2. **ce15同族提醒（信息集画法决定结论）**：把"可观测"误画成信息集内多节、或把"不可观测"误画成单节信息集，会直接改变子博弈的有无与均衡概念的选择——画信息集前先核对证据：该行动是否公开、可验证。信息集画错属于建模错误，后续全错（task-02的核心风险）。
3. **同时行动结构无真子博弈**（fb22，图2.4.3）：纯同时行动博弈的扩展式不存在子博弈，不要在其上套逆向归纳或子博弈精炼；两阶段博弈中子博弈能否成立还受"不切割信息集"限制（图2.4.4中参与者2的决策节下无子博弈）。
4. **作者盲点**：教科书立场默认收益函数可以写出——现实投资者面对管理层或对手时，收益函数本身测不准，"五问"可能问不出可靠答案；书中也不涵盖金融制度细节（涨跌停、停牌、信披规则），把本卡用于具体市场时须自行补上制度约束（如披露时点决定信息集形状）。信息集的正式理论见Kreps-Wilson(1982)，书内未展开。
