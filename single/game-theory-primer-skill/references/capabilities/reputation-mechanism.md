# cap.gibbons-game-theory.reputation-mechanism

## R 原文依据

> "克雷普斯、米尔格龙和威尔逊（1982）证明声誉模型（reputation model）可为此现象提供合理的解释。"（4.3.C）
> "存在一个阶段数的上限，在这之内双方的均衡行为都是坦白，这一上限决定于p的大小和阶段博弈的收益情况，而与重复博弈中的阶段数无关。"（4.3.C）
> "这种类型的单方非对称信息并不能成为导致合作均衡的充分条件，而且每一阶段都会出现坦白。"（4.3.C）

## I 自述

问题背景：完全信息下，阶段博弈有唯一NE⇒有限重复博弈有唯一子博弈精炼解=逐期重复该均衡（2.3.A定理），与"有限重复囚徒困境中距结束尚远的阶段常见合作"的经验证据（Axelrod 1981）冲突。KMRW用类型不确定性修补：不确定性放在可行战略集而非收益上。

**设定（4.3.C）**：行参与者以概率p只能选"投桃报李"（TFT：始于合作、此后模仿对方上一阶段行动），以概率1−p是"理性的"（可选完全信息重复博弈中任意战略）；列参与者对行类型持先验p。此表达的优点：理性型一旦偏离TFT，"行参与者是理性的"即成共同知识。等价设定：双方均可任意选战略，但行的收益为私人信息、TFT严格最优的概率为p。

**机制两步**：(i) 偏离TFT即暴露⇒此后无人再合作⇒理性的行参与者有动机伪装TFT赚取声誉；(ii) 收益设定a＞1、b＜0、a+b＜2保证对TFT的最优反应是持续合作直至最后阶段（不在合作与坦白之间摇摆）。

**短期合作条件（以转写稿为准）**：阶段收益CC=(1,1)、CF=(b,a)、FC=(a,b)、FF=(0,0)。T=2：列第一期合作当且仅当 p+(1−p)b≥0（4.3.2）。T=3：再加 1+pa≥a（4.3.3）与 a+b≤1（4.3.4）；参数域=图4.3.9阴影：a≥1、b≥−p/(1−p)、a+b≤1，p→0时域消失。三式成立⇒对任意有限T＞3存在合作均衡：理性行与列合作至T−2期，T−1、T期按图4.3.5路径（附录4.3.C归纳法证明）。

**KMRW长期定理**：存在一个坦白阶段数的上限，由p与阶段收益决定、与重复阶段数T无关⇒T足够长时任何均衡中合作阶段占比都大；p非常小也有效。p大到足以支持短期博弈合作⇒当然能支持长期合作。

## A1 书中案例

**worked_example：KMRW两阶段与三阶段合作均衡（4.3.C，图4.3.4—4.3.9）**
T=2：列选X=C得第一期p·1+(1−p)·b、第二期p·a（若第一期行动不同，列在第二期开始时即知行类型）；X=F得第一期p·a、第二期0。故列第一期合作当且仅当p+(1−p)b≥0（4.3.2）。第二阶段坦白严格优于合作（理性行与列皆然）→理性行第一期也无理由合作，唯一待定的是列的X。
T=3（图4.3.6路径：TFT=CCC、理性行=CFF、列=CCF）：理性行均衡收益1+a＞第一期坦白所得a，无偏离动机。列第一期坦白的两种后续：图4.3.7（坦白到底）收益a，均衡期望收益1+p+(1−p)b+pa≥a，给定(4.3.2)的充分条件即1+pa≥a（4.3.3）；图4.3.8（第一期坦白、第二期改合作）收益a+b+pa，均衡收益≥之的充分条件即a+b≤1（4.3.4）。图4.3.9阴影=a≥1、b≥−p/(1−p)、a+b≤1。推广：三式成立⇒任意有限T＞3存在"合作至T−2期、末两期坦白"的均衡（附录4.3.C归纳法：理性行在任意t＜T−1期坦白得a、其后为0，劣于均衡收益(T−t−1)+a；列的各类坦白路径收益均低于(4.3.5)式）。

## A2 触发与投资映射

### 触发场景
- 评估有明确期限的关系（专户合同期、考核周期、保本承诺期、锁定期）内对方会否维持合作/稳健行为。
- 对手表现"异常合作/异常保守"，要区分是真类型还是伪装收益使然。
- 新管理人/新产品早期行为与临近末段行为的连续性判断。

### 语言信号
- 中文："声誉""人设""伪装""装""晚期变脸""到期前冒险""末日效应""最后一年冲业绩""口碑""宁可信其有"。
- 英文："reputation / KMRW / tit-for-tat / mimicry / last-period problem / end-game effect / type uncertainty / glow"。

### 相邻区分
- 与 repeated-game-cooperation：那张卡=完全信息下威胁/惩罚支撑合作（贴现因子δ门槛，承诺型）；本卡=不完全信息下类型伪装支撑合作（先验概率p，声誉型）。论证"长期关系会自我维持"前先分清机制。
- 与 signaling-equilibrium（维克斯货币政策）：那是声誉的"分离"用法（强硬类型压低πS切断软弱型伪装）；本卡是声誉的"混同"用法（理性类型模仿TFT维持混同）。
- 与 commitment-credibility：承诺卡问"威胁是否可信"（收益结构），本卡问"类型是否未知"（信息结构）。

### 投资场景映射
1. **基金经理声誉机制（新基金假装保守）**：新基金早期，即使经理风险偏好高也会伪装稳健——偏离稳健风格即暴露类型、失去后续申购与资金方信任这份"合作"收益；伪装期长度由类型先验p与剩余期限T决定（p越高、T越长，伪装越久）；临近清盘线、考核期末（T−1、T期）转向冒险是均衡推论而非"人格突变"，尽调应以剩余期限定位其所处阶段。
2. **披露节奏的"末段变脸"预判**：专户/对冲基金在封闭期末段提升换手、加杠杆、追单季排名，符合"最后几期坦白"路径；把合同期日历叠加到持仓行为上，可提前识别风格漂移窗口。
3. **老牌机构的守约定价**：核心做市商/老牌机构对小客户也守规矩，可读作维持"合作类型"先验的投资——一次暴露（违约、老鼠仓）即令p归零、惩罚近似永久，其守约价差（声誉溢价）有博弈论基础；先验p只能从长期行为记录估计，且"暴露即归零重估"。
4. **谈判中的TFT式开局**：与产业方、供应商的长期重复博弈中，首轮善意+此后模仿对方上期行为（TFT）是稳健开局（Axelrod竞赛优胜战略）；对一次性博弈对手（散单、快进快出资金）不适用——它们没有可经营的类型先验。

## E 执行步骤

1. **识别类型不确定**：谁对谁的类型不确定？先验概率p多大？什么行动会暴露类型（本模型=偏离TFT）？→ *完成标准*：p、类型集、暴露机制三要素写清。*判停点*：仅单方存在类型不确定（ce19结构）→不预期声誉合作，按完全信息逐期坦白推演。
2. **核对阶段收益结构**：映射到CC=(1,1)、CF=(b,a)、FC=(a,b)、FF=(0,0)式结构，验证a＞1、b＜0、a+b＜2。→ *完成标准*：三个不等式核验通过或指出不满足。*判停点*：对TFT的最优反应不是持续合作→先修收益设定，再谈声誉机制。
3. **核对门槛条件**：短期（T=2/3）用(4.3.2)p+(1−p)b≥0、(4.3.3)1+pa≥a、(4.3.4)a+b≤1及图4.3.9参数域（a≥1、b≥−p/(1−p)、a+b≤1）；长期用定性定理（坦白上限与T无关）。→ *完成标准*：给出"合作可/不可维持"及条件依据；注意(4.3.3)(4.3.4)为充分条件。
4. **定位剩余期限与分期剧本**：把当前时点映射到T中的位置（伪装期t≤T−2／末段T−1、T），输出分期行为剧本（前段伪装合作、末段坦白/暴露）。→ *完成标准*：剧本含每阶段预期行为与触发暴露的行动清单。
- **输入输出契约**：输入=类型先验p、阶段收益参数（a,b）、剩余期数/合同期日历、暴露机制；中间产物=单双侧不确定判定、三式与参数域核验表；输出=分期行为剧本（伪装期/末段）、合作可持续性判断、p更新规则（暴露即归零重估）。

## B 边界

1. **单方声誉不足以产生合作（ce19）**：KMRW明示——单方非对称信息不是导致合作均衡的充分条件，每一阶段都会坦白、与完全信息相同；必须双方存在相同的类型不确定性。用"声誉"论证合作前，先核不确定性的双边性。
2. **理论预测全背叛vs经验合作（ce18）**：完全信息下唯一NE⇒有限重复逐期背叛的定理与大量经验证据冲突，KMRW是对该定理的修补而非否定——结构里没有类型不确定性时，勿直接搬声誉结论。
3. **"声誉"=对类型的不了解**：书中声誉特指"可能只能选TFT"的战略集不确定性（或等价的收益私有信息设定），与品牌声誉、ESG声誉等日常语义不同；把本卡结论直接套到"公司爱惜羽毛"类叙事是过度引申。
4. **定性定理无可算上限**：坦白阶段上限存在但书中无显式公式（由p与阶段收益决定），给定p、T只能定性判断"合作占比大"，勿假装能算出"还剩几期开始变脸"。
5. **作者盲点**：合作均衡只是众多均衡之一（存在≠被实行，均衡选择未解决）；理性是公理而非实证结论；p与收益参数现实难测（全书批判点）；KMRW原文在序贯均衡条件下表述（书中论证同样适用于精炼贝叶斯均衡）；1992年成书，此后声誉理论进展（多阶段信号声誉、声誉极限定理）未覆盖。
